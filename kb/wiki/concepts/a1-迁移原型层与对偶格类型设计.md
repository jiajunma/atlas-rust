# A1 迁移原型层与对偶格类型设计

A1 迁移原型层位于 `crates/atlas-real-group/src/lib.rs`，其中的类型全部为 `pub(crate)`，实现注释标明待替换（pending replacement）。所属 crate 提供实约化群的结构性数学值，不包含 Atlas 语法或输出策略，是解释器未来 domain values 的适配边界，参见 [[atlas-real-group 的 crate 门面与数学值边界]]。^[lib-root.md:10-14, lib-root.md:30-49]

## 对偶格类型的迁移方向

原型以 `LatticeVector(Vec<i32>)` 表示格向量；这个 newtype 本身不进行校验。其文档声明将由 `Weight`／`Coweight` 的编译期对偶格区分取代。这是待替换原型的设计方向，来源未声明这一替换已经完成。^[lib-root.md:30-33]

原型 `RootDatum` 与 `root_datum` 模块中的 [[BasedRootDatum：带基根数据与构造不变量|BasedRootDatum]] 是不同类型。原型构造器会调用 `BasedRootDatum::standard` 进行校验，但这种调用关系不意味着二者是同一个类型。^[lib-root.md:34-38, lib-root.md:55-58]

## 根数据构造与配对约定

原型 `RootDatum::new` 的校验顺序为 `EmptyRootDatum` → `BasedRootDatum::standard(...)?` → `NonSquareCartan` → `InvalidCartanMatrix`。外部校验器的错误先于原型自身的形状检查传播；后续 Cartan 条目检查要求对角元为 2、非对角元不大于 0。详见 [[原型 RootDatum 的构造校验与配对约定]]。^[lib-root.md:34-38]

在单根基坐标下，单根为 \(e_i\)，单余根为 Cartan 矩阵的第 \(j\) **列**。`from_basis` 先逐个检查维度，不符时报 `RankMismatch`，再按行主序核对 \(\langle \mathrm{root}_i,\mathrm{coroot}_j\rangle=\mathrm{cartan}[i][j]\)，不一致时报 `RootPairingMismatch`。^[lib-root.md:37-38]

## 原型算法与资源边界

`roots()` 以正负单根播种，通过 FIFO BFS 构造反射闭包。算术采用 `i128` 中间精度并收窄至 `i32`，溢出时报 `ArithmeticOverflow`；第 4097 个互异向量触发 `RootSystemTooLarge`，对应 `LIMIT = 4096`。输出按坐标字典序排序，以保持确定性。^[lib-root.md:39-41]

`PrototypeWeylGroup` 通过 BFS 枚举，以元素对全部单根的作用像为键。处理新元素时，以 `elements.len() >= 65_536` 为容量检查条件，超限时报 `WeylGroupTooLarge`；成功构造的群阶至多为 65,536。`act_on_root` 按词的逆序施加反射，参见 [[原型 Weyl 群的作用像枚举]]。^[lib-root.md:42-44]

## 对合、根类型与 grading

原型 `CartanInvolution` 校验 \(M^2=I\) 以及单根像属于根系，但 `compact_imaginary` 标志只是未经校验的调用方断言。来源明确标明该标志已被 `Grading` 取代；这一已替换状态应与 `LatticeVector` 的待替换方向区分。相关主题见 [[Grading 的位向量类型纪律]]。^[lib-root.md:30-33, lib-root.md:45-47]

`RootType` 包含 `CompactImaginary`、`NoncompactImaginary`、`Real` 和 `Complex` 四种分类。`RealReductiveGroup::classify_simple_root` 根据根的像等于自身、等于负根或属于其他情况进行分类；`simple_real_rank` 的含义刻意窄于 real rank。^[lib-root.md:45-49]

## 测试与证据范围

本文件包含三个测试锚点：A1 反射取负、固定根按标志判为非紧虚根，以及 `i32::MAX` 坐标的配对恰报 `ArithmeticOverflow` 而非回绕。最后一项还间接要求 `StructureError: PartialEq`。参见 [[原型层的测试锚点与证据边界]]。^[lib-root.md:51-54]

来源仅覆盖 crate 门面与原型层，其他模块的实现不在本包范围内。材料经过维护者对照源码核对，但属于结构性阅读，不声称数学验收；本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[lib-root.md:9-14, lib-root.md:55-58, lib-root.md:62-66]
