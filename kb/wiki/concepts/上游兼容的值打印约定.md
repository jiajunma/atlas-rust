# 上游兼容的值打印约定

Atlas 值层在 `value.rs` 与 `linear_values.rs` 中规定字符串、复合值、有理数、函数值和线性代数载荷的打印形式。来源记录了上游格式的移植约定，但属于结构性阅读，不声称语言或数学验收；实际值打印兼容性以 HPC 语料门为准。^[atlas-core-value-layer.md:9-11, atlas-core-value-layer.md:13-52, atlas-core-value-layer.md:71-74]

## 字节保留与复合值

`AtlasString(Vec<u8>)` 保存原始字节，其 `Display` 仅提供 Unicode 编辑或调试预览，不能作为字节内容的权威表示。`Value::atlas_text` 与 `append_atlas_text` 提供不经过 Unicode 转换的打印路径：字符串原始字节置于引号内，Tuple 与 List 递归打印，Union 打印为 `value.injectorname`。相关约定见 [[AtlasString 字节保留串与原始字节打印]]。^[atlas-core-value-layer.md:20-24]

## 有理数与函数值

`Display for Value` 对 `Rational` 单独处理符号，因为 Malachite 将符号与非负分子分开存储。负值打印为 `-num/den`；即使分母为 1，也保留分母。^[atlas-core-value-layer.md:25-26]

闭包的 `Display` 只输出 `Function defined` 头部，因为此处无法取得源名表。完整多行形式由 `typed.rs` 中的 `closure_trace_string` 在回溯帧转储时渲染，来源将其对应到上游 `axis.w:3254-3271`。内建函数打印为 `{print_name}`。^[atlas-core-value-layer.md:27-29]

## 向量、矩阵与有理向量

`Vec32(Vec<i32>)` 保存机器 32 位整数项。向量与有理向量的分子部分共用 `write_bracketed`：各项按“最大项宽 + 1”右对齐，以逗号分隔，末项后接 `" ]"`，空时打印为 `"[ ]"`。有理向量在方括号部分后追加 `/denominator`；来源将这些打印格式对应到上游 `global.w:2107-2158`。^[atlas-core-value-layer.md:45-52]

`Matrix` 以列主序保存整数项，打印时按列定宽，并使用 `"|"` 作为边框。当行数或列数为 0 时，采用 `The {}x{} matrix` 格式表示矩阵尺寸。^[atlas-core-value-layer.md:46-47]

`RatVec` 使用 `i64` 分子与 `u64` 分母，构造时对全部分子和分母取 gcd 进行规范化；分母为 0 时返回 `None`。因此，其打印所用的分子与分母受构造阶段的规范化约束。^[atlas-core-value-layer.md:48-52]

## 验证与证据边界

来源列出 11 个测试，其中 `value` 4 个、`linear_values` 3 个、`formula` 4 个。这是三个支撑模块的测试总数，并非打印兼容性验收结果。上游行号引用属于实现方的移植陈述，值打印兼容性仍以 HPC 语料门为准；相关主题见 [[HPC 验收证据链]]。^[atlas-core-value-layer.md:71-74]

来源同时保留了 `linear_values.rs` 关于“将在 phase-B stage B2 嵌入 `Value`”的模块自述，并在 `Value` 变体清单中列出 `Vector(Vec32)`、`Matrix` 与 `RatVector(RatVec)`。这两处记载存在时态差异，来源未进一步解释其集成时间关系。^[atlas-core-value-layer.md:15-19, atlas-core-value-layer.md:53-53]
