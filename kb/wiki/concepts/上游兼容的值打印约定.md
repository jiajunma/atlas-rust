# 上游兼容的值打印约定

Atlas 值层在 `value.rs` 与 `linear_values.rs` 中规定求值结果的打印形式，包括字节串、复合值、有理数及线性代数载荷。源材料记录了对应的上游格式与移植依据，但其证据等级是结构性阅读；值打印兼容性仍以 HPC 语料门为准。^[atlas-core-value-layer.md:9-11, atlas-core-value-layer.md:69-74]

## 字节保留与复合值

`AtlasString(Vec<u8>)` 是字节保留串，其 `Display` 仅用于 Unicode 编辑或调试预览，不能作为原始字节的权威表示。`Value::atlas_text` 与 `append_atlas_text` 提供不经过 Unicode 转换边界的打印路径：字符串的原始字节置于引号内，Tuple 与 List 递归打印，Union 打印为 `value.injectorname`。相关纪律见 [[AtlasString 字节保留串与原始字节打印]]。^[atlas-core-value-layer.md:20-24]

## 标量与函数值

`Display for Value` 对 `Rational` 单独处理符号，因为 Malachite 将符号与非负分子分开存储。负值打印为 `-num/den`，即使分母为 1，也保留分母。^[atlas-core-value-layer.md:25-26]

闭包的 `Display` 只输出 `Function defined` 头部，因为此处无法取得源名表。完整多行形式由 `typed.rs` 中的 `closure_trace_string` 在回溯帧转储时渲染；内建函数则打印为 `{print_name}`。^[atlas-core-value-layer.md:27-29]

## 向量、矩阵与有理向量

`Vec32(Vec<i32>)` 保存机器 32 位整数项。向量与有理向量的分子部分共用 `write_bracketed`：各项按“最大项宽 + 1”右对齐，以逗号分隔，末项后接 `" ]"`，空向量打印为 `"[ ]"`。有理向量在方括号部分后追加 `/denominator`；源材料将这些格式对应到上游 `global.w:2107-2158`。^[atlas-core-value-layer.md:45-52]

`Matrix` 以列主序保存整数项，打印时按列定宽，并使用 `"|"` 作为边框。当行数或列数为 0 时，采用 `The {}x{} matrix` 格式表示矩阵尺寸。^[atlas-core-value-layer.md:46-47]

`RatVec` 使用 i64 分子与 u64 分母，构造时即对全部分子和分母取 gcd 进行规范化；分母为 0 时返回 `None`。因此，有理向量的打印基于构造阶段已规范化的载荷。^[atlas-core-value-layer.md:48-52]

## 验证与证据边界

源材料列出 11 个测试，其中 `value` 4 个、`linear_values` 3 个、`formula` 4 个；这一数量不能直接视为打印兼容性的完整证明。上游行号引用属于实现方的移植陈述，实际值打印兼容性以 HPC 语料门为准，参见 [[HPC 验收证据链]]。^[atlas-core-value-layer.md:69-74]
