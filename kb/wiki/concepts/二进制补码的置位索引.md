# 二进制补码的置位索引

二进制补码的置位索引由 `nth_set_bit` 提供，对应上游 `bigint.cpp` 的 `index_of_set_bit`。它查找二进制补码串中第 n 个置位，采用 0 基计数。^[atlas-core-builtin-registry.md:52-54]

## 非负值与负值

对于非负值，置位数量有限；若不足以找到所请求的第 n 个置位，结果为 `-1`。对于负值，二进制补码串具有无穷多个置位，因此实现通过其补码中的有限清位进行处理。两者的关键区别在于：非负值可能耗尽置位，负值则按无限补码串解释。^[atlas-core-builtin-registry.md:52-54]

## 实现位置与证据边界

该操作属于内建注册表源码包记录的求值期辅助契约，可结合 [[内建函数元数据与实现分发]] 理解其所在层次。源码包覆盖 `typed.rs` 的内建接口、实现分发及注册表组织，但不逐项说明全部注册条目的语义。^[atlas-core-builtin-registry.md:9-13, atlas-core-builtin-registry.md:46-54, atlas-core-builtin-registry.md:75-78]
