# 交互式与非交互式输入分流

Atlas CLI 根据 stdin 是否连接终端选择输入方式：非终端输入读入后执行，终端输入进入 `run_interactive`。文件参数作为普通命令流处理；这些输入通过会话帧运行共享会话，相关架构见 [[会话帧驱动的 CLI 执行模型]]。^[atlas-cli-main.md:9-13, atlas-cli-main.md:30-34]

## 输入路径

**非交互式输入**包括文件参数和非终端 stdin。文件参数刻意按普通命令流处理；上游文件参数的 prelude-capture 语义不属于当前实现目标。stdin 非终端时，CLI 读入内容并运行。^[atlas-cli-main.md:30-32]

**交互式输入**在 stdin 连接终端时启用。`run_interactive` 显示启动横幅，然后进入以 `atlas> ` 为提示符的循环。横幅标明 Atlas 版本 `1.1.1`、axis language 版本 `1.1`，以及使用 Rust 编译、readline 已禁用。^[atlas-cli-main.md:31-34]

## 参数解析与文件包含

命令行中的 `--path=DIR` 加入 `search_path`，其余参数视为文件参数。`--path` 可以重复指定；会话中的 `<file` 包含先按这些路径前缀、再按工作目录解析，具体机制见 [[包含文件的搜索路径解析]]。^[atlas-cli-main.md:10-13, atlas-cli-main.md:28-29]

文件系统提供者 `FsProvider` 使用有损 UTF-8 解码：由于上游读取字节，游离的非 UTF-8 字节不得被当作文件打开失败。^[atlas-cli-main.md:18-19]

## 会话输出与结束

会话机器位于 `atlas-core`。CLI 将文本输出与报告写到 stdout，字节事件保留原始字节；诊断通过 `frame.describe_bytes` 将出处、源行和 caret 标记写到 stderr。顶层值显示为 `Value: …`，会话以 `Bye.` 结束。相关输出约定见 [[CLI 事件输出与源码诊断]]。^[atlas-cli-main.md:10-13, atlas-cli-main.md:22-25, atlas-cli-main.md:41-43]

`quit` 可以提前结束会话。退出状态依据上游 clean 标志：语法、类型或运行时错误导致非零退出状态，缺少包含文件本身则不会将会话标记为不 clean。详见 [[clean 标志与 CLI 退出状态]]。^[atlas-cli-main.md:35-37]
