# 交互式与非交互式输入分流

Atlas CLI 根据 stdin 是否连接终端选择输入方式：非终端输入读入后执行，终端输入进入 `run_interactive`。文件参数则作为普通命令流输入；这些入口通过会话帧运行共享会话。^[atlas-cli-main.md:9-13, atlas-cli-main.md:30-34]

## 输入路径

文件参数刻意按普通命令流处理。上游文件参数的 prelude-capture 语义不属于当前实现目标，因此不能据此认定两者的文件参数行为完全兼容。^[atlas-cli-main.md:30-31]

stdin 非终端时，CLI 读入内容并运行；stdin 连接终端时，CLI 显示启动横幅，再进入以 `atlas> ` 为提示符的交互循环。横幅标明 Atlas 版本 `1.1.1`、axis language 版本 `1.1`，以及使用 Rust 编译、readline 已禁用。^[atlas-cli-main.md:31-34]

## 参数与会话控制

命令行中的 `--path=DIR` 加入 `search_path`，其余参数视为文件参数。`--path` 可以重复指定；会话中的 `<file` 包含先按这些路径前缀、再按工作目录解析。相关机制见 [[包含文件的搜索路径解析]]。^[atlas-cli-main.md:10-13, atlas-cli-main.md:28-29]

输入入口由 CLI 分流，会话机器位于 `atlas-core`，可结合 [[会话帧驱动的 CLI 执行模型]] 理解。`quit` 可以提前结束会话；退出状态依据上游 clean 标志，语法、类型或运行时错误导致非零退出状态，缺少包含文件本身则不将该标志置为不 clean。相关约定见 [[clean 标志与 CLI 退出状态]]。^[atlas-cli-main.md:35-43]

## 证据边界

本说明依据 `crates/atlas-cli/src/main.rs` 的完整结构性阅读，不代表语言验收。该文件自身没有测试，行为由 HPC 语料门覆盖；CLI 兼容性也以该语料门为准，参见 [[CLI 兼容性的证据边界]]。^[atlas-cli-main.md:9-14, atlas-cli-main.md:41-44]
