# 会话循环与文件会话帧的职责边界

`session.rs` 负责有状态的逐命令执行，`session_frame.rs` 负责文件包含与输出重定向。Atlas 的词法分类依赖先前命令留下的状态，因此会话模块拥有外层循环，永不预先切分整个源文件。^[atlas-core-session.md:9-14, atlas-core-session.md:72-74]

## 会话循环与命令缓冲

`run_source` 为每个源创建全新的 `TypedContext`；`run_source_with_context` 使用调用方持有的上下文。循环遇到 `Newline` 时调用 `execute_tokens`，遇到 `Eof` 时执行剩余缓冲并退出；其余普通 token 加入命令缓冲。^[atlas-core-session.md:29-40]

换行触发解析，但不保证命令已经完整。`execute_tokens` 仅在终止符为 `Newline` 时设置 `allow_more`；若 `parse_command_fragment_in(.., context.types(), allow_more)` 返回 `Ok(None)`，便保留前缀、不求值、不产生诊断，让后续输入继续累积。原始源输入与文件会话共用这条[[多行命令的增量解析]]路径。^[atlas-core-session.md:47-50]

`next_session_token` 在消费 token 时调用 `context.note_completion_token` 记录标识符，以保留被包含文件与后续命令之间的首次使用顺序。相关纪律见[[会话补全顺序与名字可见性分离]]。^[atlas-core-session.md:44-46]

对于 `Command::SetType`，执行辅助逻辑使用真实词法终止符重建命令跨度；终止符为换行时，将其列位置加一，以匹配上游将命令换行计入跨度的约定，而不猜测语义 token 之后的列位置。详见 [[SetType 命令的词法终止符跨度重建]]。^[atlas-core-session.md:51-53]

## 文件会话帧与相邻模块

会话循环自身拒绝文件包含指令。遇到 `Directive(_)` 时，它产生 Io 诊断 `"file inclusion is only available through a session frame"`；文件包含由 `session_frame.rs` 处理，输出重定向也归该模块负责。相关主题见 [[SessionFrame 会话帧与文件包含语义]]。^[atlas-core-session.md:37-39, atlas-core-session.md:72-74]

转换与求值位于 `typed.rs`，词法处理位于 `lex.rs`，文法适配位于 `syntax.rs`，领域内建位于 `domain_builtins.rs`。`session.rs` 组织逐命令处理，并通过 `context.execute` 进入执行环节。^[atlas-core-session.md:29-40, atlas-core-session.md:54-56, atlas-core-session.md:72-74]

## 输出事件与错误处理

会话层通过 [[SessionEvent 与字节保留输出|SessionEvent]] 承载值、文本、原始字节和诊断，六个变体均携带 `SourceSpan`。其中 `Value` 保留由 `type_.is_void()` 得到的 void 标志；`SessionEvent::output()` 先尝试 UTF-8 转换，合法文本进入 `Output`，非法字节以 `AtlasString` 保留在 `OutputBytes` 中，不以替换字符改写。诊断直接透传。^[atlas-core-session.md:16-27]

循环遇到 `Unsupported(_)` 时，产生 Syntax 诊断 `"unexpected token"`，随后调用 `lexer.recover_command()`；词法错误则直接进入事件流。这与文件包含指令触发的 Io 诊断属于不同处理分支。^[atlas-core-session.md:34-40]

若 `context.execute` 失败，`execute_tokens` 先调用 `drain_failed_printed(span)` 排空已经打印的内容，再发出诊断，使求值中途产生的 stdout 在运行时错误后仍然保留。该顺序属于[[打印、字符串转换与运行时错误的输出契约]]。^[atlas-core-session.md:54-56]

## 证据边界

来源属于对 `session.rs` 的结构性阅读，不据此宣称语言或数学验收。对文件会话帧的说明限于文件包含、输出重定向的职责归属，以及会话循环拒绝包含指令的行为；相邻模块的内部实现不在本包覆盖范围内。^[atlas-core-session.md:9-14, atlas-core-session.md:37-39, atlas-core-session.md:70-74]

文件头与注释中的上游行号属于实现方的移植陈述，语义等值以 HPC 差分门为准。来源所引用的 Weyl owner/dual 验收范围限定于 A1；测试名称、家族计数与快照哈希标识特定版本的字节，哈希本身不证明正确性。^[atlas-core-session.md:75-80]
