# 余根限制映射与对合的格基转运

`topology.rs` 通过格基转运构造单连通覆盖一侧的对合，再以余根限制映射连接两侧的 `dualPi0` 子商。诱导映射的核给出对偶分量群；对实形式的最分裂 Cartan，该核消失当且仅当实形式连通。^[topology-form-name.md:18-23]

## 格基与对合转运

设 \(B\) 的列依次为简单余根与余权格 radical 的一组基。对合 \(\theta\) 转运到单连通覆盖权格后的矩阵为
\[
i_{\mathrm{sw}}=B^t\theta B^{-t}.
\]
源码注释给出的上游表达式是 `theta.transposed().on_basis(basis).transposed()`；列的构造顺序固定为先简单余根、后 radical 基。^[topology-form-name.md:18-21, topology-form-name.md:31-34]

实现先检查形状，再计算 radical；无根 datum 的 radical 取全格。组装 \(B\) 时，各分量经 `i32::try_from` 转换。随后使用 `invert_rational` 与两次 `rational_product` 进行有理运算，并用 `integral_entry` 逐项检查转运结果的整性。^[topology-form-name.md:31-35]

## 模二余根限制映射

令 \(B_z\) 为将 \(B\) 中的 radical 列清零所得的矩阵。私有类型 `CorootRestriction` 实现 `ModTwoAmbientMap`，定义环境模二空间上的映射
\[
x\longmapsto B_z^t x\pmod 2.
\]
实现按输出列累加奇偶性；清零 radical 列是这一限制映射的构造步骤。^[topology-form-name.md:21-23, topology-form-name.md:29-30]

私有函数 `dual_pi0` 构造的子商为
\[
\operatorname{dualPi0}(\eta)
=
\frac{\ker_{\mathbf F_2}(\eta+1)}
{\text{饱和 }+1\text{ 特征格的模二像}},
\]
其中 \(\eta\) 分别取 \(\theta\) 与 \(i_{\mathrm{sw}}\)。实现建立两侧子商后，调用 `validate_induced_map_to` 检查环境映射能否下降为子商间的诱导映射，参见 [[环面对合的 dualPi0 子商构造]] 与 [[线性映射下降到子商的条件验证]]。^[topology-form-name.md:27-36]

## 核、秩与连通性

对偶分量群是诱导映射
\[
\operatorname{dualPi0}(\theta)
\longrightarrow
\operatorname{dualPi0}(i_{\mathrm{sw}})
\]
的核。实现逐一映射源子商的基代表并计算像秩，因此核的维数为“源维数减像秩”。在最分裂 Cartan 上，核为零等价于诱导映射单射，也等价于实形式连通，参见 [[对偶分量群与实形式连通性]]。^[topology-form-name.md:18-23, topology-form-name.md:35-38]

`dual_component_group_trivial` 是 `pub(crate)` 接口，返回“像秩等于源维数”；公开接口 `dual_component_group_rank` 返回“源维数减像秩”。来源指出，两函数复制了同一整段计算管线，仅末行不同，存在同步漂移风险。^[topology-form-name.md:31-40]

## 示例与覆盖边界

单连通 split A1 的测试锚点使用 \(B=\begin{pmatrix}1\end{pmatrix}\)，限制映射为恒等，对应连通情形。adjoint split A1 使用 \(B=\begin{pmatrix}2\end{pmatrix}\)，限制映射模二后消失，对应 \(\mathrm{PGL}(2,\mathbb R)\) 的两个连通分量。GL(2) 样式的 split 示例中，环面坐标被清零，得到秩一对偶分量群。^[topology-form-name.md:42-45]

其他测试锚点包括单连通 compact A1（\(\theta=+1\)，子商分子为零）与 adjoint compact B2。`dual_component_group_rank` 没有直接测试，无根 datum 分支也未覆盖。此外，`topology.rs` 不校验 \(\theta\) 是否为对合，该前提由调用方保证。^[topology-form-name.md:42-46, topology-form-name.md:85-87]
