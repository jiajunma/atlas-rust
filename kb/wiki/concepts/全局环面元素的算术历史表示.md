# 全局环面元素的算术历史表示

`GlobalTorusElement` 是全局 KGB 实现中的私有类型，以 `numerator: Vec<i64>` 和 `denominator: i64` 表示 \(\exp(i\pi\,\mathrm{numerator}/\mathrm{denominator})\)，坐标按模 \(2\mathbb Z^{\mathrm{rank}}\) 理解。其核心约定是**构造入口约化、反射后不再约化**，因此表示与打印形式保留算术历史，而不始终采用规范代表元。^[global-kgb.md:17-29]

## 构造、反射与加法

`reduce_raw`、`exp_pi` 和 `exp_2pi` 使用 `rem_euclid`，将分子坐标约化到 \([0,2\cdot\mathrm{denominator})\)。`simple_reflect` 在对偶侧预根 datum 上执行 \(\mathrm{numer}\leftarrow\mathrm{numer}-\langle\mathrm{numer},\alpha\rangle\alpha^\vee\)，但有意省略事后约化。负分子因此可以进入打印输出；B2 元素 15 的标签 `[0,-1]/2` 是这一行为的具体锚点。^[global-kgb.md:19-25]

`add` 通过最小公倍数合并分母、最大公约数归一化，随后对每个坐标至多执行一次条件减法。这一修正只纠正落在 \([2,4)\) 的和，非规范加数原样通过，并非全面的模约化。`log_2pi` 返回分子除以两倍分母，也仅作最大公约数归一化。^[global-kgb.md:25-29]

## 根求值与交叉作用

`negative_at` 要求根配对为整数，否则返回 `KgbInvariantViolation "integral root evaluation"`；配对为奇数时判为紧。非紧情形下，`imaginary_cross_act` 使用由 `coroot·(denominator − remainder)` 构造的 `exp_2pi` 加数进行平移。^[global-kgb.md:26-29]

在 [[GlobalKgb 的分阶段广度优先构造]] 的 cross/Cayley 闭包阶段，长度差必须为偶数；半长度差非零时调用 `simple_reflect`，并将状态设为 `Complex`。虚根情形调用 `imaginary_cross_act`，紧或非紧由 `negative_at` 判定。Cayley 链接仅针对 `ImaginaryNoncompact` 元素，其环面部分原样克隆。^[global-kgb.md:67-74]

## 去重与打印

去重使用独立的 `fingerprint`：将 `log_2pi` 分子投影到 \(\theta+I\) 饱和像的适应基各列，对分母取 `rem_euclid`，仅保留 `diagonal.len()` 个分量。源码注释以同一饱和像的两组基相差幺模变换、该变换模分母仍可逆来说明无损性，详见 [[基于饱和像适应基的 KGB 去重指纹]]。^[global-kgb.md:31-36]

查询与打印对错误的处理不同：`torus_label()` 将 `log_2pi` 的错误转为 `None`，而 `print_layout` 传播同一错误。相关接口见 [[GlobalKgb 查询接口与 print_X 布局兼容]]。^[global-kgb.md:84-88]

SC A1、adjoint A1 和 SC B2 均有逐字节打印匹配测试，对照 `tests/reference/domain/print_x.events.json` 中的三个 `print_X` 块。其中 SC B2 的 17 行输出包含负分子标签 `[0,-1]/2`，为保留非规范分子的可观测行为提供回归锚点。^[global-kgb.md:96-100]

## 前置条件与证据边界

实现依赖维度匹配、`denominator != 0` 和直接下标索引有效等隐式前置条件，违反时会 panic。`reduce_raw`、`evaluate_at` 等位置的 `2 * denominator` 使用普通乘法，溢出时在 debug 模式下 panic，在 release 模式下回绕。^[global-kgb.md:103-105]

现有测试未覆盖错误分支；半单秩 0 的平凡群与一维环面也有意未测，因为共享内类机制在空生成元集合上会 panic，修复超出该模块范围。更多覆盖限制见 [[GlobalKgb 的回归测试与证据边界]]。^[global-kgb.md:94-105]
