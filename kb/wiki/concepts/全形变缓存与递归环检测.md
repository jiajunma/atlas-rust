# 全形变缓存与递归环检测

全形变机器以 canonical 单元为缓存对象，通过短时加锁、显式递归环检测和完整结果缓存来管理递归计算。相关实现位于 `crates/atlas-core/src/domain_builtins.rs`，包括 `full_deform_key`、`cached_deformation`、`store_deformation` 和 `full_deformation_terms`。^[atlas-core-deformation-cache.md:9-27]

## 缓存键与锁纪律

缓存键为 `FullDeformKey = (x, y_bits, gamma)`，表示 canonical 单元，而非顶层参数键。缓存只保存完整且经过 canonical 排序的结果。^[atlas-core-deformation-cache.md:19-25]

`cached_deformation` 与 `store_deformation` 使用 `Mutex<DeformationCache>`，锁仅在缓存读取或写入的瞬间持有；缓存锁和块属主锁都不跨递归调用持有。^[atlas-core-deformation-cache.md:20-22]

## 处理顺序与递归环检测

`full_deformation_terms` 在分母超过 alcove 界时，先调用 `domain_alcove_center` 取中；随后按“查缓存 → 加入 active 集 → 递归 → 排序 → 写入缓存”的顺序处理。分母检查的相关概念见 [[Alcove 分母界守卫]]。^[atlas-core-deformation-cache.md:34-35]

`active: HashSet<FullDeformKey>` 显式跟踪递归中的活动参数。再次访问仍处于活动状态的键时，报告错误 `full deformation recursion revisited an active parameter`，以识别递归环。^[atlas-core-deformation-cache.md:23-25]

## 完整结果的递归语义

普通全形变遍历每个可约点，采用递推式 \(F(z)=L(z)+\sum_t c_t(1-s)F(t)\)。由于 \((1-s)^2=2(1-s)\)，源材料将其对应于原版整数递推 \(D(z)\mathrel{+}=c_tL(t)+2c_tD(t)\)。^[atlas-core-deformation-cache.md:29-33]

`full_deformation_uncached` 的 scale-zero 基底保留全部 final 项。每个子项依次经过 `scale`、`deform_readjust`、`rep lookup` 和 `common_deformation_terms`；后者使用块修饰符、原始行与 gamma，再以 \(c(1-s)\) 因子递归。若停在前一点并将其化为单个 K 型，会丢失 Split 因子及后代，参见 [[全形变中的 Split 因子与后代保留]]。^[atlas-core-deformation-cache.md:36-40]

顶层 `compute_full_deform` 对参数的每个 final 组分分别形变，按其系数缩放后合并，并按 canonical `KTypePol` 项序排序。相关聚合过程见 [[全形变参数规范化与结果聚合]]。^[atlas-core-deformation-cache.md:41-42]

## 协作截止

`deadline_expired` 在阶段之间检查截止条件，超限时返回 `None`，不缓存部分结果。这与“仅缓存完整结果”的纪律一致，参见 [[形变计算的协作式截止]]。^[atlas-core-deformation-cache.md:23-27]

扭曲全形变另有计时边界：`compute_twisted_full_deform` 先执行 `distinguished_twist`、构造 `ExtRepContext` 并完成 `extended_finalise`，之后才开始计时，因此这些 setup 成本不计入协作截止。相关流程见 [[扭曲全形变计算流程]]。^[atlas-core-deformation-cache.md:44-50]
