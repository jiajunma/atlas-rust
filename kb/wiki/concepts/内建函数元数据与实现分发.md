# 内建函数元数据与实现分发

内建函数通过 `Builtin` 统一描述名称、类型、求值控制与实现入口，再由 `BuiltinImpl` 区分标量运算、领域调用、打印、关系及泛型操作。该结构将注册元数据与实现分发结合起来。^[atlas-core-builtin-registry.md:15-37]

## 元数据结构

`Builtin` 包含以下字段：

```rust
{
    name: &'static str,
    arg_type: Type,
    result: Type,
    hunger: u8,
    overload_visible: bool,
    implementation: BuiltinImpl,
}
```

`name`、`arg_type` 和 `result` 分别记录名称、参数类型与结果类型；`implementation` 指向实现分支。`hunger` 字节对应上游的饥饿求值位，与 `HungryBuiltinCall` 配对；`overload_visible` 控制内建函数是否出现在重载解析与补全中。相关求值结构见 [[TypedExpr 可执行表达式树]]。^[atlas-core-builtin-registry.md:17-21]

## 实现分发

`Scalar(ScalarOp)` 表示标量运算；`Domain { name, no_value: DomainNoValue }` 将领域调用桥接到 `domain_builtins.rs`，并携带无值求值策略；`DomainRelation(Relation)` 表示领域关系。相关调用机制见 [[函数调用分派与内建参数解包]]。^[atlas-core-builtin-registry.md:23-31]

`DomainPrinter { name }` 是领域打印包装器：两个求值级别都写报告，在 `single_value` 级别产出空元组，且无值门之前没有诊断。`Completions` 对应 `readline_completions`，按前缀过滤命令层保存在求值上下文中的补全候选快照。^[atlas-core-builtin-registry.md:28-33]

泛型分支包括 `Prints`、`Print`、`ToString` 和 `Error`。`Prints` 按所引用的上游实现装成普通 `T -> void` scheme；`Print` 对应 `print@@T`，逐字打印、为字符串保留引号，并在要值级别原样返回；`ToString` 返回剥离后的拼接串值；`Error` 将该拼接文本作为运行时错误抛出。^[atlas-core-builtin-registry.md:34-37]

其中，`prints`、`to_string` 和 `error` 的文本辅助逻辑对变参元组中的字符串分量省略引号，其余分量按 `print` 打印。`prints` 在文本后添加一个换行，`to_string` 与 `error` 不添加换行。相关输出约定见 [[打印、字符串转换与运行时错误的输出契约]]。^[atlas-core-builtin-registry.md:61-64]

## 无值求值策略

`DomainNoValue` 决定领域调用在 `NoValue` 级别执行多少工作：`Skip` 跳过调用，`Validate` 执行校验，`BuildAndDrop` 完整构造结果后丢弃。补全名称清单不能用作无值策略清单，例如 `orientation_nr` 注册为 `BuildAndDrop`，而非 `Skip`。这一差异关联 [[BuildAndDrop 领域内建验证策略]]。^[atlas-core-builtin-registry.md:39-44]

## 注册表与证据边界

`builtin_registry()` 使用 `OnceLock<Vec<Builtin>>` 一次构建，源材料记录了 321 个条目、170 个不同名称。条目按主题分节，并在各节注释中标注上游出处；相对于上游完整启动清单，注册表仍不完整，缺口由 `docs/REMAINING_BUILTINS.md` 跟踪。详见 [[内建注册表的启动清单与覆盖边界]]。^[atlas-core-builtin-registry.md:66-73]

本页依据的是结构性阅读，不能据此宣称语言或数学验收完成。源材料未覆盖全部 321 个分支的逐条语义，也未展开 `TypedExpr` 求值实现及其 133 个测试；上游行号引用属于实现方的移植陈述，行为兼容仍以 HPC 语料门为准。^[atlas-core-builtin-registry.md:9-13, atlas-core-builtin-registry.md:75-80]
