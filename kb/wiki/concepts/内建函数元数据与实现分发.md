# 内建函数元数据与实现分发

内建函数通过 `Builtin` 统一描述名称、类型、求值控制与实现入口，再由 `BuiltinImpl` 区分标量运算、领域调用、打印、关系、补全及泛型操作。^[atlas-core-builtin-registry.md:18-40]

## 元数据结构

`Builtin` 包含名称 `name: &'static str`、参数类型 `arg_type: Type`、结果类型 `result: Type`、饥饿求值位 `hunger: u8`、重载可见性 `overload_visible: bool` 和实现入口 `implementation: BuiltinImpl`。^[atlas-core-builtin-registry.md:20-24]

`hunger` 字节对应上游的饥饿求值位，与 `HungryBuiltinCall` 配对；`overload_visible` 控制内建函数是否出现在重载解析与补全中。相关表达式结构见 [[TypedExpr 可执行表达式树]]。^[atlas-core-builtin-registry.md:20-24]

## 实现分发

`Scalar(ScalarOp)` 表示标量运算；`Domain { name, no_value: DomainNoValue }` 将领域调用桥接到 `domain_builtins.rs`，并携带无值求值策略；`DomainRelation(Relation)` 表示领域关系。相关机制见 [[函数调用分派与内建参数解包]]。^[atlas-core-builtin-registry.md:28-34]

`DomainPrinter { name }` 是领域打印包装器：两个求值级别都写报告，在 `single_value` 级别产出空元组，且无值门之前没有诊断。^[atlas-core-builtin-registry.md:31-33]

`Completions` 对应 `readline_completions`，按前缀过滤命令层保存在求值上下文中的补全候选快照。详见 [[readline_completions 的补全快照前缀过滤]]。^[atlas-core-builtin-registry.md:35-36]

### 泛型打印、字符串转换与错误

泛型分支包括 `Prints`、`Print`、`ToString` 和 `Error`。`Prints` 按所引用的上游实现装成普通 `T -> void` 类型方案；`Print` 对应 `print@@T`，逐字打印、为字符串保留引号，并在要值级别原样返回；`ToString` 对应 `to_string@@T`，返回剥离后的拼接串值；`Error` 对应 `error@@T`，将剥离后的拼接文本作为运行时错误抛出。^[atlas-core-builtin-registry.md:37-40]

`prints`、`to_string` 和 `error` 使用的 `to_string_aux` 对变参元组中的字符串分量省略引号，其余分量按 `print` 打印。`prints` 在文本后添加一个换行，`to_string` 与 `error` 不添加换行。详见 [[打印、字符串转换与运行时错误的输出契约]]。^[atlas-core-builtin-registry.md:64-67]

## 无值求值策略

`DomainNoValue` 决定领域调用在 `NoValue` 级别执行多少工作：`Skip` 跳过，`Validate` 执行校验，`BuildAndDrop` 完整构造后丢弃结果。相关概念见 [[领域调用的无值门策略]]。^[atlas-core-builtin-registry.md:42-47]

补全名称清单不能用作无值策略清单。例如，`orientation_nr` 注册为 `BuildAndDrop`，而非 `Skip`；其策略应按注册内容判断。参见 [[BuildAndDrop 领域内建验证策略]]。^[atlas-core-builtin-registry.md:44-47]

## 注册表与覆盖边界

`builtin_registry()` 使用 `OnceLock<Vec<Builtin>>` 一次构建。源材料记录了 **479 个条目、240 个不同名称**，条目按主题分节，各节注释给出上游出处。按构造器家族统计，条目数／不同名称数分别为：`scalar` 167／59、`domain` 154／119、`domain_validate` 86／58、`domain_skip` 29／19、`domain_printer` 21／19、`domain_relation` 22／2。^[atlas-core-builtin-registry.md:12-15, atlas-core-builtin-registry.md:69-73]

注册表相对于上游完整启动清单仍不完整，缺口由 `docs/REMAINING_BUILTINS.md` 跟踪。补全侧的 `STARTUP_COMPLETION_NAMES` 则包含按上游哈希序排列的 309 个启动名，并显式固定注册缺口。详见 [[内建注册表的启动清单与覆盖边界]]。^[atlas-core-builtin-registry.md:71-76]

## 证据边界

本页依据的是结构性阅读，不构成语言或数学验收。源材料未逐条展开全部 479 个实现分支的语义，`TypedExpr` 求值实现及其 133 个测试也待另行分包；上游行号引用属于实现方的移植陈述，行为兼容仍以 HPC 语料门为准。参见 [[HPC 验收证据链]]。^[atlas-core-builtin-registry.md:9-16, atlas-core-builtin-registry.md:78-83]
