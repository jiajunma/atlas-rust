# 内类字母的字节解析与规范化

`checked_inner_class_letters` 将内类符号串解析为规范化字母序列，供[[单连通群基本权基上的逐字母对合表]]使用。它位于 `primitive_involution.rs`，属于 primitive `involution` 包装器背后的纯表实现，不涉及 root datum、Weyl group 或完整 inner-class 管线。^[primitive-involution.md:17-25, primitive-involution.md:86-91]

## 字节读取与因子消费

函数接收 `symbols: impl AsRef<[u8]>` 和 `factors: &[(char, usize)]`，返回 `Result<Vec<char>, InnerClassLetterError>`。符号通过 `char::from(u8)` 按字节解释，不进行 UTF-8 解码或替换；未知符号保留为对应字节值的字符，进入 `UnknownSymbol` 诊断。^[primitive-involution.md:39-40, primitive-involution.md:65-69]

每次读取符号前，`skip_punctuation` 跳过 ASCII 标点与空白。允许的符号集合为 `"Ccesu"`，大小写有区别：通常一个符号消耗一个因子，大写 `'C'` 则要求并消耗两个类型与秩均相同的连续因子。^[primitive-involution.md:65-75]

## 规范化规则

解析器根据当前因子的类型与秩规范化符号；`'e'` 是 `'c'` 的同义词，不会出现在输出中。下表列出因子存在时的分派规则。^[primitive-involution.md:71-82]

| 输入符号 | 条件 | 结果 |
| --- | --- | --- |
| `'C'` | 下一因子与当前因子的类型、秩均相同 | 保留 `'C'`，消耗两个因子 |
| `'C'` | 下一因子不存在或不相同 | 返回 `ComplexPair` |
| `'c'`、`'e'` | 任意当前因子 | 输出 `'c'` |
| `'s'` | A 型且秩 ≥ 2、奇秩 D 型、E6 或 T 型 | 保留 `'s'` |
| `'s'` | 其他情形 | 输出 `'c'` |
| `'u'` | 偶秩 D 型 | 保留 `'u'` |
| `'u'` | 奇秩 D 型、A 型且秩 ≥ 2、E6 或 T 型 | 输出 `'s'` |
| `'u'` | 其他情形 | 返回 `MeaninglessUnequalRank { letter, rank }` |

源码文档将 `'s'` 坍缩为 `'c'` 的条件解释为：恰在 \(-1\) 属于 Weyl 群时发生，列出的类型包括 A1、B、C、偶秩 D、E7、E8、F、G。这是来源转录的代码文档说明，上游文件字节尚未独立核对。^[primitive-involution.md:77-81, primitive-involution.md:11-13]

## 诊断顺序

解析器先检查符号是否属于 `"Ccesu"`，再检查是否还有可消费的因子。因此，即使因子已经耗尽，未知符号仍优先触发 `UnknownSymbol`；合法但多余的符号才触发 `TooManySymbols`。输入结束后若仍有因子未消费，则返回 `TooFewSymbols`。这一顺序是[[内类字母解析的错误模型与诊断顺序]]中的可观测约定。^[primitive-involution.md:71-82]

对于 `'C'`，缺少第二个因子与相邻因子不相同都会触发 `ComplexPair`。对于 `'u'`，不支持 unequal-rank 类的因子触发 `MeaninglessUnequalRank`，错误携带因子的类型字母与秩；例如 A1 的文案为 `Unequal rank class is meaningless for type A1`。^[primitive-involution.md:60-61, primitive-involution.md:74-81, primitive-involution.md:119-121]

## 与对合查表的衔接

`layout_involution` 要求 `letters` 来自上述检查过程，并要求 `perm` 是 `0..rank` 的排列。`perm` 指定扁平化单根的矩阵下标，表示用户提供的 Bourbaki 重编号，由包装器侧验证，参见[[Bourbaki 重编号与对合矩阵下标映射]]。查表函数不返回 `Result`，违反前置条件可能导致下标越界 panic 或进入 `unreachable!`。^[primitive-involution.md:23-25, primitive-involution.md:86-91]

遵守解析前置条件时，B、C、E7、E8、F、G 上的 `'s'` 已在解析期坍缩为 `'c'`，不会进入查表中对应的 `'s'` 默认分支；这些分支只对绕过解析的输入起防御作用。^[primitive-involution.md:138-139]

## 测试与证据边界

测试锚点覆盖 `'s'` 在 A1、B2、C3、D4、D6、E7、E8、F4、G2 上坍缩为 `'c'`，以及在 A2、A5、D5、E6、T1 上保留。对于 `'u'`，测试覆盖 D4、D6 上保留，A2、D5、E6、T1 上转为 `'s'`，以及 A1、B2、C2、E7、F4、G2 上报错。^[primitive-involution.md:117-121]

来源属于结构性源码阅读，不构成数学或正确性验收。相关测试缺口包括 `TooManySymbols`、`TooFewSymbols` 的 `Display` 文案以及退化空输入；本次知识维护未执行 Atlas、Cargo、测试或 benchmark。更多限制见[[对合查表实现的证据范围与测试缺口]]。^[primitive-involution.md:134-141, primitive-involution.md:145-149]
