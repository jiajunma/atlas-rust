# 内类字母解析的错误模型与诊断顺序

`checked_inner_class_letters` 按单因子解析内类符号，返回 `Result<Vec<char>, InnerClassLetterError>`。错误模型涵盖符号过多、符号过少、未知符号、复型因子配对失败，以及无意义的不等秩（unequal-rank）请求。源材料记载，其 `Display` 实现逐字节复刻上游 `runtime_error` 文案。^[primitive-involution.md:30-40, primitive-involution.md:50-61]

## 错误类型与精确文案

五种错误的触发条件与输出如下。`UnknownSymbol` 文案使用反引号开启符号、单引号结束；`MeaninglessUnequalRank` 中的 `letter` 与 `rank` 表示因子类型和秩，例如 `A1`。数量错误的触发时机遵循后述诊断顺序。^[primitive-involution.md:55-61, primitive-involution.md:71-82]

| 变体 | 触发条件 | `Display` 输出 |
| --- | --- | --- |
| `TooManySymbols` | 读到合法符号，但已无剩余因子 | `Too many inner class symbols` |
| `TooFewSymbols` | 输入结束后仍有未处理因子 | `Too few inner class symbols` |
| `UnknownSymbol(char)` | 跳过标点与空白后，符号不属于 `Ccesu` | ``Unknown inner class symbol `{symbol}'`` |
| `ComplexPair` | `'C'` 无法匹配两个相同的连续因子 | `Complex inner class needs two identical consecutive types` |
| `MeaninglessUnequalRank { letter, rank }` | 当前因子不支持请求的 `'u'` 类 | `Unequal rank class is meaningless for type {letter}{rank}` |

## 字节语义与诊断优先级

解析器取符号前通过 `skip_punctuation` 跳过 ASCII 标点与空白。符号按字节处理，以 `char::from(u8)` 转为字符；它不进行 UTF-8 解码或替换，未知输入的字节值保留在 `UnknownSymbol` 中。相关规范化规则见[[内类字母的字节解析与规范化]]。^[primitive-involution.md:65-69]

每次取得符号后，解析器**先检查是否属于 `Ccesu`，再检查是否还有对应因子**。即使因子已经耗尽，未知符号仍优先触发 `UnknownSymbol`；只有合法符号才会在这一位置触发 `TooManySymbols`。源材料记录的测试注释明确固定了“未知符号先于因子计数报告”的顺序。^[primitive-involution.md:71-72]

通过这两项检查后，解析器执行具体字母的语义检查与规范化。输入结束时，若 `index < factors.len()`，则返回 `TooFewSymbols`。因子数量不能直接与符号数量比较，因为 `'C'` 一次消耗两个因子。^[primitive-involution.md:65-66, primitive-involution.md:74-82]

## 语义错误与合法规范化

`'C'` 要求下一个因子的类型和秩与当前因子完全相同，即 `factors.get(index + 1) == Some(&(letter, rank))`。不满足时返回 `ComplexPair`，包括当前因子已位于末尾的情况；成功时执行 `index += 2`。因此，末尾单个因子上的 `'C'` 在配对检查阶段失败。^[primitive-involution.md:74-75]

`'u'` 在偶秩 D 上保留为 `'u'`，在奇秩 D 上规范化为 `'s'`；A（秩至少为 2）、E6 和 T 也规范化为 `'s'`。其余情况返回 `MeaninglessUnequalRank { letter, rank }`。^[primitive-involution.md:80-81]

另外两类规范化不会产生上述语义错误：`'e'` 是 `'c'` 的同义词，输出统一为 `'c'`；`'s'` 仅在 A（秩至少为 2）、奇秩 D、E6 和 T 上保留，其余情况坍缩为 `'c'`。因此，同一因子上的 `'s'` 请求可能合法坍缩，而 `'u'` 请求可能被拒绝。^[primitive-involution.md:76-81]

## 调用边界

后续 `layout_involution` 要求 `letters` 来自此解析器，且 `perm` 是 `0..rank` 的排列。该函数不返回 `Result`；违反前置条件可能导致下标越界 panic 或进入 `unreachable!`。结构化的字母错误诊断应由解析阶段完成，相关表构造见[[单连通群基本权基上的逐字母对合表]]。^[primitive-involution.md:84-91]

## 测试与证据范围

源材料列出的测试覆盖 `'u'` 在 D4、D6 上保留，在 A2、D5、E6、T1 上规范化，以及在 A1、B2、C2、E7、F4、G2 上拒绝；其中精确断言 A1 的错误文案为 `Unequal rank class is meaningless for type A1`。未覆盖的项目包括 `TooManySymbols`、`TooFewSymbols` 的 `Display` 文案及退化空输入。^[primitive-involution.md:119-121, primitive-involution.md:140-141]
