# 内类布局与限制根系的接口边界

`layout.rs` 与 `restricted_roots.rs` 互不调用。前者生成内类的 Lie type、内类字母和 Bourbaki 置换，后者生成限制根及其纤维；两者在对合来源、构造校验、输出语义和资源预算上具有不同的接口约定。^[layout-restricted-roots.md:68-75]

## 对合来源与构造校验

[[内类布局（InnerClassLayout）|InnerClassLayout]] 使用 `InnerClass::distinguished_involution()`。其 `build` 依次计算单根上的 `twist_permutation`、进行 Dynkin 分类、确定内类字母，再处理中心环面。单根置换通过逐根查找、求像、回查与去重建立，其中任何一步失败都返回 `LayoutInvariantViolation`。^[layout-restricted-roots.md:24-27, layout-restricted-roots.md:70-72]

`RestrictedRootSystem` 使用 `RootInvolutionData::involution()`。其 `build` 先检查 datum 一致性与格秩，不符时分别返回 `DatumMismatch` 和 `RankMismatch`；通过检查后，才按根系枚举序遍历并聚合限制根纤维。^[layout-restricted-roots.md:57-62, layout-restricted-roots.md:70-72]

## 输出语义

内类布局中的半单因子按打印序排列，Complex 对相邻，随后每个中心环面维度对应一个 `T1`。每个内类条目对应一个字母，其中 `'C'` 消耗两个 type 因子。Bourbaki 置换满足：`perm[k]` 是规范化序下第 \(k\) 个单根的 datum 下标，相关约定见 [[Bourbaki 顶点排序与置换语义]]。^[layout-restricted-roots.md:17-22]

限制根层使用 `RestrictedWeight` 表示商格 \(X^*/\ker(1-\theta)\) 中的类，以 \((1-\theta)(\mathrm{weight})\) 的坐标编码。这是商到像格的单射表示，不能直接解读为原权的环境坐标。例如 split A1 中，\(\alpha\) 的类编码为 \(2\alpha\)，但并不等于 \(2\alpha\) 的类。^[layout-restricted-roots.md:48-55]

限制根构造跳过限制为零的根，将其余根按 `RestrictedWeight` 键聚合到 `BTreeMap` 中。输出的限制根按编码坐标的字典序升序排列，`root(weight)` 使用二分查找。`rank` 取自对合的 `anti_invariant_rank`，即负特征空间秩，而不是纤维计数；可结合 [[对合的反不变秩]] 阅读。`is_multipliable(weight)` 判断二倍类本身是否也是一个限制根的类。^[layout-restricted-roots.md:57-62]

## 资源预算与算术边界

布局构造接收 `IntegerLatticeBudget`，但它只约束中心环面字母背后的 Smith 基计算，半单数据不使用该预算。中心环面分支通过 `adapted_basis` 从根格的 Smith 基读出商对合，再对 `inv + I` 调用 `classify_plus_identity`，得到 compact、complex、split 因子计数，并按 `'c'`、`'C'`、`'s'` 的顺序追加字母，参见 [[中心环面的商对合分类]]。^[layout-restricted-roots.md:17-22, layout-restricted-roots.md:37-41, layout-restricted-roots.md:70-72]

限制根构造不接收预算，但坐标运算使用检查算术：`restrict` 逐坐标执行 `checked_sub`；仅供 `is_multipliable` 使用的私有 `doubled` 逐坐标执行 `checked_mul(2)`。^[layout-restricted-roots.md:50-55, layout-restricted-roots.md:70-72]

## 概念关系与证据范围

概念上，可以把两层理解为同一 `InnerClass` 的并行消费者：一层提供布局，另一层提供限制根及纤维。这是对数据流水线的解释性推断，源码并未编码这种关系，不能据此认定两层之间存在调用或转换接口。

来源属于结构性源码阅读，不构成两层的数学验收。包内上游引用仅转录自代码注释，未核对上游字节；本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[layout-restricted-roots.md:9-13, layout-restricted-roots.md:89-93]

现有测试锚点包括布局层的 A1、twisted A2、A1.A1 交换、D4 叉尖交换、GL(2) 样式中心环面和 A1.B2.A1 重排。限制根层则覆盖 split A1 的 rank 1、两个限制根及不可乘情形，compact A1 的无限制根情形，以及 A2 中 rank 1、纤维 multiplicity 2 且可乘的情形。上述内容描述已有测试，不代表本次执行结果。^[layout-restricted-roots.md:43-46, layout-restricted-roots.md:64-66, layout-restricted-roots.md:91-93]

两文件的错误分支均缺少失败路径测试。布局层尚无夹具覆盖 Complex 对跨越多个不同秩中间因子时的特殊移位顺序，中心环面 `'c'`、`'C'` 字母也没有测试锚点。限制根层未断言 `rank` 与限制根条数的一致性，也未断言可乘性与 BC 型非约化根系等数学性质的关系。^[layout-restricted-roots.md:29-35, layout-restricted-roots.md:77-85]
