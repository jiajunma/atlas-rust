# 列填充的完整性不变式与错误传播

扩展（twisted）KLV 多项式表的 `fill_columns` 保持列完整性不变式：`column[y]` 要么为空，要么完整。计算某列失败时，Rust 实现清空出错列并传播错误，使该列不保留部分填充的数据。^[extended-kl.md:82-87]

## 列存储与填充范围

`ExtKlTable<'a>` 为每个块元素 `y` 保存一列多项式池索引，并按 `x` 相对于 `y` 的 descent set 的 primitive 位置寻址。列的具体布局见 [[扩展 KLV 多项式表的逐列存储]]。^[extended-kl.md:70-80]

`fill_columns(limit)` 计算所有满足 `y < limit` 的列；`limit == 0` 是特殊约定，表示填满整块。^[extended-kl.md:84-85]

## 失败处理与完整性不变式

错误处理以出错列为清理单位：清空该列，再向调用方传播错误，从而保持“为空或完整”的状态约束。来源规定的是出错列的处理，未说明整个填充调用具有全表回滚语义。^[extended-kl.md:84-87]

这是 Rust 移植中的有意偏离。上游对应路径使用 `catch(...)` 吞掉错误，Rust 则将错误传出；因此，失败时的错误传播行为必须单独保留，不能概括为与上游完全相同。其他移植取舍见 [[扩展 KLV 的 Rust 移植边界与有意偏离]]。^[extended-kl.md:84-87, extended-kl.md:89-98]
