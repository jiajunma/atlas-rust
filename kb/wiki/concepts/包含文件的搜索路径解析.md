# 包含文件的搜索路径解析

Atlas CLI 将可重复指定的 `--path=DIR` 参数收集为 `search_path`，由会话帧解析命令流中的 `<file` 包含请求。搜索依次使用这些目录前缀，最后才尝试工作目录。CLI 负责参数配置，具体包含逻辑位于 `atlas-core` 的 [[SessionFrame 会话帧与文件包含语义]]。^[atlas-cli-main.md:9-13, atlas-cli-main.md:26-29, atlas-cli-main.md:41-43]

## 搜索顺序与后缀补全

`SessionFrame` 保存的每条搜索前缀均以 `/` 结尾；空前缀表示工作目录，并放在最后。`resolve` 按 `search_path` 的顺序逐个处理前缀：在每个前缀下先尝试原名，若名字不带 `.at`，再尝试追加 `.at` 的名字，然后才进入下一个前缀。目录优先级因此先于跨目录的后缀尝试。^[atlas-core-session-frame.md:29-33, atlas-core-session-frame.md:41-42]

## 解析与包含状态

包含处理同时使用 `completed` 集合与 `active` 栈：前者记录已完成文件以实现 include-once，后者承担循环守卫、深度检查与回溯命名。`<file` 支持包含去重，`<<file` 则用于强制重读。^[atlas-core-session-frame.md:11-15, atlas-core-session-frame.md:29-35]

普通包含首先检查用户输入的名字是否已在 `completed` 中；若已完成，便静默跳过，不打开文件，也不打印框架行。否则执行路径解析，再检查解析后的路径是否已完成；这使包含去重在解析前后各有一道检查。^[atlas-core-session-frame.md:36-40]

若解析后的文件已在 `active` 栈中，包含请求会静默跳过并视为成功，以阻止递归包含。通过循环与深度检查后，会话帧打印 `Starting` 框架行、压栈并递归执行输入流；正常完成时记录到 `completed`，再打印 `Completely` 框架行。包含深度上限为 `MAX_INCLUDE_DEPTH = 64`，用于限制循环守卫之外的病态 provider。^[atlas-core-session-frame.md:34-40]

## 文件读取与失败语义

文件接口为 `FileProvider::read(path) -> Option<String>`，其中 `None` 表示打开失败。CLI 的文件系统实现 `FsProvider` 使用有损 UTF-8 读取，游离的非 UTF-8 字节不得因此被判为文件打开失败。^[atlas-core-session-frame.md:20-22, atlas-cli-main.md:18-19]

路径解析失败会产生 Io 诊断 `failed to open input file …` 并返回 `Abort`。打开失败及其引起的 abandon 级联刻意不将会话置为 dirty；缺失包含文件的测试仍断言 `is_clean()` 为真。包含栈的中止与会话退出状态是不同层面的行为，相关说明见 [[嵌套包含的 abandon 级联]] 与 [[clean 标志与 CLI 退出状态]]。^[atlas-core-session-frame.md:36-46]

CLI 的退出状态取决于会话的 `clean` 标志。语法、类型或运行时错误使退出状态非零，缺失包含文件本身不会造成这一变化。^[atlas-cli-main.md:35-37]

## 与顶层输入的关系

`main` 将 `--path=DIR` 以外的参数作为文件参数，并刻意将其作为普通命令流执行；上游文件参数的 prelude-capture 语义不在此实现目标内。stdin 非终端时读入后执行，连接终端时进入 `run_interactive` 的 `atlas> ` 循环，参见 [[会话帧驱动的 CLI 执行模型]]。^[atlas-cli-main.md:26-34]

## 证据边界

来源属于结构性阅读，不声称语言或数学验收。CLI 文件自身没有测试；会话帧文件中的 18 个测试提供了包含解析顺序、once/force、缺失中止、循环静默等单元级行为锚点。端到端文件命令兼容性仍以 HPC 语料门为准，上游行号对应关系属于实现方的移植陈述。^[atlas-cli-main.md:9-14, atlas-cli-main.md:41-44, atlas-core-session-frame.md:9-16, atlas-core-session-frame.md:81-97]
