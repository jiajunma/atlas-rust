# 单连通群基本权基上的逐字母对合表

`layout_involution` 根据单因子类型、规范化内类字母和 Bourbaki 重编号，构造单连通群基本权基上的对合矩阵。它属于 primitive `involution(LieType,[int],string)` 与 `involution(LieType,mat,string)` 包装器背后的纯查表实现，不涉及 root datum、Weyl group 或 inner-class 构造管线。^[primitive-involution.md:17-25]

## 输入与坐标约定

函数接收 `factors: &[(char, usize)]`、`letters: &[char]` 和 `perm: &[usize]`，返回行主序矩阵 `Vec<Vec<i32>>`。`perm[k]` 表示第 `k` 个扁平化单根对应的矩阵下标，表中的顶点操作据此写入输出坐标；详见 [[Bourbaki 重编号与对合矩阵下标映射]]。^[primitive-involution.md:39-43, primitive-involution.md:86-89]

`letters` 必须来自 `checked_inner_class_letters`，`perm` 必须是 `0..rank` 的排列。排列由包装器侧的 `checked_permutation` 验证，查表函数本身不提供完整的输入校验。^[primitive-involution.md:23-25, primitive-involution.md:86-91]

## 查表前的字母规范化

[[内类字母的字节解析与规范化]] 将 `'e'` 转为 `'c'`；`'s'` 仅在秩至少为 2 的 A 型、奇秩 D、E6 和 T 上保留，其余坍缩为 `'c'`。`'u'` 在偶秩 D 上保留，在奇秩 D、秩至少为 2 的 A 型、E6 和 T 上转为 `'s'`，其余情况报 `MeaninglessUnequalRank`。`'C'` 要求两个相同的连续因子，并一次消耗这两个因子。^[primitive-involution.md:74-82]

因此，规范化后的字母数不必等于因子数：一个 `'C'` 对应一对因子。实现分别用 `r` 跟踪扁平图位置、用 `pos` 跟踪因子位置。^[primitive-involution.md:65-66, primitive-involution.md:93-101]

## 逐字母分派

查表按下列规则构造各矩阵块。E6 的顶点下标从 0 开始；`compact` 表示块恒等，`flip_last_two` 表示交换末两个顶点。^[primitive-involution.md:93-102]

| 字母 | 因子类型 | 对合作用 |
| --- | --- | --- |
| `'c'` | 任意 | 块恒等 |
| `'s'` | A | 反对角置 1，反转顶点次序 |
| `'s'` | 奇秩 D | 交换末两个顶点 |
| `'s'` | 偶秩 D | 块恒等 |
| `'s'` | E6 | 固定 1、3，交换 0↔5、2↔4 |
| `'s'` | 其他 E 型及 B、C、F、G | 块恒等 |
| `'s'` | T | 负恒等，对角置 −1 |
| `'C'` | 两个相同的连续因子 | 平行交换两因子的对应顶点 |
| `'u'` | 经规范化保留的偶秩 D | 交换末两个顶点 |

`'C'` 分支将当前因子的 `rs` 个顶点与紧随其后的 `rs` 个顶点平行互换，并额外执行 `pos += 1; r += rs`，以消耗第二个因子。两因子相同的条件由字母解析器保证。^[primitive-involution.md:100-101]

遵守解析前置条件时，B、C、E7、E8、F、G 上的 `'s'` 已经坍缩为 `'c'`，不会进入表中对应的 `'s'` 默认分支；这些分支仅对绕过解析的输入起防御作用。^[primitive-involution.md:138-139]

## 前置条件与失败边界

`layout_involution` 不返回 `Result`。函数中的两道 `debug_assert_eq!` 分别检查 `perm.len() == rank` 和结束时的 `r == rank`；它们不能替代字母解析与排列验证。违反前置条件可能导致下标越界 panic 或命中两个 `unreachable!` 分支之一。^[primitive-involution.md:86-91]

## 与格基换基的衔接

查表结果处于单连通群基本权基上。`on_basis` 随后可计算 \(B^{-1}MB\)，通过有理逆、两次有理矩阵乘法及逐项整性检查，将矩阵转到给定基上。非方阵、奇异基、非整结果及 `i32` 转换失败均折叠为 `None`，包装器将其统一标记为不兼容格；参见 [[有理运算实现的整数矩阵精确换基]] 与 [[换基失败的统一不兼容格语义]]。^[primitive-involution.md:104-113]

## 测试锚点与证据范围

源包记录的测试中，A1 的 `'c'` 与坍缩后的 `'s'` 均给出 \(\begin{pmatrix}1\end{pmatrix}\)；A2 的 `'s'` 与 `'u'` 均给出 \(\begin{pmatrix}0&1\\1&0\end{pmatrix}\)，且在 `perm [1,0]` 下不变；B2 的 `'s'` 给出单位阵。^[primitive-involution.md:122-123]

两个 A1 的 `'C'` 测试锚定因子互换；D4 的 `'u'` 交换末两个顶点，而 `'s'` 给出单位阵。D5、E6 和 T1 的测试分别锚定末两顶点交换、指定顶点交换及 \(\begin{pmatrix}-1\end{pmatrix}\)。混合因子 `[A1,A2]`、字母 `"cs"` 与 `perm [2,0,1]` 的测试锚定重编号对输出的作用。^[primitive-involution.md:124-127]

测试尚未覆盖 `'C'` 在非恒等 `perm` 下的行为及退化空输入。相关缺口见 [[对合查表实现的证据范围与测试缺口]]。^[primitive-involution.md:140-141]
