# 单连通群基本权基上的逐字母对合表

`layout_involution` 根据单因子类型、规范化内类字母和 Bourbaki 重编号，构造单连通群基本权基上的对合矩阵。它属于 primitive `involution(LieType,[int],string)` 与 `involution(LieType,mat,string)` 包装器背后的纯查表实现，不涉及 root datum、Weyl group 或 inner-class 构造管线。^[primitive-involution.md:17-25]

## 输入与坐标约定

函数接收 `factors: &[(char, usize)]`、`letters: &[char]` 和 `perm: &[usize]`，返回行主序 `i32` 矩阵 `Vec<Vec<i32>>`。`perm[k]` 表示第 `k` 个扁平化单根对应的矩阵下标，顶点操作按该映射写入输出坐标，参见 [[Bourbaki 重编号与对合矩阵下标映射]]。^[primitive-involution.md:39-43, primitive-involution.md:86-89]

调用方必须保证 `letters` 来自 `checked_inner_class_letters`，且 `perm` 是 `0..rank` 的排列。包装器侧使用 `checked_permutation` 验证排列；查表函数本身不提供完整输入校验。^[primitive-involution.md:23-25, primitive-involution.md:86-91]

## 查表前的字母规范化

[[内类字母的字节解析与规范化]] 将 `'e'` 转为 `'c'`。`'s'` 仅在秩至少为 2 的 A 型、奇秩 D、E6 和 T 上保留，其余坍缩为 `'c'`。`'u'` 在偶秩 D 上保留，在奇秩 D、秩至少为 2 的 A 型、E6 和 T 上转为 `'s'`，其余情况报 `MeaninglessUnequalRank`。`'C'` 要求两个相同的连续因子，并一次消耗这两个因子。^[primitive-involution.md:74-82]

解析按因子推进，但一个 `'C'` 对应两个因子。查表实现相应使用双指针：`r` 跟踪扁平图位置，`pos` 跟踪因子位置。^[primitive-involution.md:65-66, primitive-involution.md:93-101]

## 逐字母分派

下表列出实现中的分派规则，包括规范化输入不会进入的防御分支。`compact` 表示块恒等，`flip_last_two` 表示交换末两个顶点；E6 的顶点下标从 0 开始。^[primitive-involution.md:93-102, primitive-involution.md:138-139]

| 字母 | 因子类型 | 对合作用 |
| --- | --- | --- |
| `'c'` | 任意 | 块恒等 |
| `'s'` | A | 反对角，反转顶点次序 |
| `'s'` | 奇秩 D | 交换末两个顶点 |
| `'s'` | 偶秩 D | 块恒等 |
| `'s'` | E6 | 固定 1、3，交换 0↔5、2↔4 |
| `'s'` | 其他 E 型及 B、C、F、G | 块恒等 |
| `'s'` | T | 负恒等，对角置 −1 |
| `'C'` | 两个相同的连续因子 | 平行交换两因子的对应顶点 |
| `'u'` | 规范化后保留的偶秩 D | 交换末两个顶点 |

`'C'` 分支将当前因子的 `rs` 个顶点与紧随其后的 `rs` 个顶点平行互换，并额外执行 `pos += 1; r += rs`，以消耗第二个因子。两因子相同的条件由字母解析器保证。^[primitive-involution.md:100-101]

遵守解析前置条件时，B、C、E7、E8、F、G 上的 `'s'` 已坍缩为 `'c'`，不会进入表中对应的默认分支；这些分支仅对绕过解析的输入起防御作用。^[primitive-involution.md:138-139]

## 前置条件与失败边界

`layout_involution` 不返回 `Result`。两道 `debug_assert_eq!` 分别检查 `perm.len() == rank` 和结束时的 `r == rank`，不能替代规范化字母与排列校验。违反前置条件可能导致下标越界 panic 或命中两个 `unreachable!` 分支之一。^[primitive-involution.md:86-91]

## 与格基换基的衔接

查表结果位于单连通群基本权基上，`on_basis` 可进一步计算 $B^{-1}MB$。它求基的有理逆，通过两次有理矩阵乘法计算结果，再逐项检查整性及 `i32` 可表示性。非方阵、奇异基、非整结果和转换失败均返回 `None`，由包装器统一标记为不兼容格，详见 [[换基失败的统一不兼容格语义]]。^[primitive-involution.md:104-113]

## 测试锚点与证据范围

源包记录的测试中，A1 的 `'c'` 与坍缩后的 `'s'` 均给出 $\begin{pmatrix}1\end{pmatrix}$；A2 的 `'s'` 与 `'u'` 均给出 $\begin{pmatrix}0&1\\1&0\end{pmatrix}$，且在 `perm [1,0]` 下不变；B2 的 `'s'` 给出单位阵。^[primitive-involution.md:122-123]

两个 A1 的 `'C'` 测试检查因子互换；D4 的 `'u'` 交换末两个顶点，而 `'s'` 给出单位阵。D5、E6 和 T1 的测试分别检查末两顶点交换、指定顶点交换及 $\begin{pmatrix}-1\end{pmatrix}$。混合因子 `[A1,A2]`、字母 `"cs"` 与 `perm [2,0,1]` 的测试检查 Bourbaki 重编号对输出的作用。^[primitive-involution.md:124-127]

测试尚未覆盖 `'C'` 在非恒等 `perm` 下的行为及退化空输入，相关限制见 [[对合查表实现的证据范围与测试缺口]]。^[primitive-involution.md:140-141]
