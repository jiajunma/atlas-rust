# 原型层的测试锚点与证据边界

`atlas-real-group` 的 `lib.rs` 同时承载 crate 对外门面与 crate 私有的 A1 迁移原型层。原型类型全部为 `pub(crate)`，实现注释标明尚待替换；相关来源是结构性阅读记录，不构成数学验收。^[lib-root.md:10-14, lib-root.md:30-33]

## 三个测试锚点

来源记录了三个测试，分别锚定反射、根类型判定与算术失败行为：^[lib-root.md:51-54]

- **A1 反射取负**：检查 A1 情形下的反射结果。
- **固定根判为非紧虚根**：检查固定根按给定标志分类为非紧虚根的行为。
- **配对溢出返回错误**：对含 `i32::MAX` 坐标的配对，要求恰好返回 `ArithmeticOverflow`，而非整数回绕。

溢出测试还间接要求 `StructureError` 实现 `PartialEq`，以便比较错误结果。它提供的是特定配对输入的错误行为锚点；来源未将其表述为全部算术路径的验证。相关错误体系可参见 [[StructureError 统一错误分类学]]。^[lib-root.md:53-56]

## 根分类测试的解释边界

原型 `CartanInvolution` 检查 \(M^2=I\) 以及单根像属于根系，但其 `compact_imaginary` 标志是未经校验的调用方断言，且已被 `Grading` 取代。因此，固定根测试体现的是按给定标志分类的行为，并未验证该标志本身的数学正确性。原型 `RealReductiveGroup::classify_simple_root` 按根像等于原根、负根或其他根进行分类；`simple_real_rank` 的含义也刻意窄于一般 real rank。^[lib-root.md:45-49, lib-root.md:53-54]

## 实现描述与测试覆盖的区别

来源还描述了原型根系枚举的反射闭包、溢出检查、容量限制与确定性排序，以及原型 Weyl 群按单根作用像进行 BFS 枚举、按词逆序作用等行为。这些实现描述并未被列为上述三个测试的覆盖内容，不能据此声称相应算法已获得完整测试验证。相关概念见 [[反射闭包的防御性不变量]]、[[原型 Weyl 群的作用像枚举]] 与 [[Weyl 词对根与权的作用顺序]]。^[lib-root.md:39-44, lib-root.md:51-58]

原型 `RootDatum` 与 `root_datum` 模块中的 `BasedRootDatum` 名称相近，但不是同一类型。解释这些测试时，应保留这一类型边界，避免将原型层证据直接归于 [[BasedRootDatum：带基根数据与构造不变量]]。^[lib-root.md:57-58]

## 来源范围与验证状态

该来源只覆盖 `lib.rs` 的门面与原型层，不覆盖各模块的实现；完整错误变体清单需查阅其他来源，`weyl_size` 与 `global_tits` 的消费者也不在本文件中。因此，本页所述测试不能代表整个 crate 的验证范围。^[lib-root.md:55-58]

精确读取身份由 `2026-10-06-lib-root.json` 记录，绑定 Git base、文件字节 SHA-256 与草案生成记录；草案经维护者对照源码逐条核对改写。本次知识维护未执行 Atlas、Cargo、测试或 benchmark，故这里记录的是源码中的测试锚点，而非本次运行得到的测试通过结果。^[lib-root.md:62-66]
