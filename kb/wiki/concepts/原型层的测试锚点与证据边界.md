# 原型层的测试锚点与证据边界

`atlas-real-group` 的 `lib.rs` 同时承载 crate 对外门面与私有的 [[A1 迁移原型层与对偶格类型设计|A1 迁移原型层]]。原型类型全部为 `pub(crate)`，实现注释标明尚待替换（pending replacement）。来源对这一文件完成了结构性阅读，不声称数学验收。^[lib-root.md:9-14, lib-root.md:30-33]

## 三个测试锚点

**A1 反射取负**：检查 A1 情形下反射取负的行为。^[lib-root.md:51-54]

**固定根按标志判为非紧虚根**：检查固定根依据给定标志得到非紧虚根分类的行为。^[lib-root.md:53-54]

**配对溢出返回精确错误**：含 `i32::MAX` 坐标的配对应恰好报告 `ArithmeticOverflow`，而非整数回绕。该测试还间接要求 `StructureError` 实现 `PartialEq`；相关错误体系见 [[StructureError 统一错误分类学]]。^[lib-root.md:53-56]

## 根分类测试的解释边界

原型 `CartanInvolution` 校验 \(M^2=I\) 及单根像属于根系，但 `compact_imaginary` 标志是未经校验的调用方断言；来源明确注明该标志已被 `Grading` 取代。因此，固定根测试的范围是按给定标志分类，不能作为标志本身经过校验的证据。相关类型纪律见 [[Grading 的位向量类型纪律]]。^[lib-root.md:45-47, lib-root.md:53-54]

原型 `RealReductiveGroup::classify_simple_root` 按根像等于原根、负根或其他情况分类；其 `simple_real_rank` 的含义刻意窄于一般 real rank。解释原型行为时，应保留这些接口的限定含义。^[lib-root.md:48-49]

## 实现描述与测试覆盖

来源描述了 `RootDatum::roots()` 的 FIFO BFS 反射闭包、`i128` 中间计算与 `i32` 收窄、4096 个互异向量的容量上限及坐标字典序输出；也描述了 `PrototypeWeylGroup` 按全部单根的作用像枚举、成功阶数至多 65,536，以及 `act_on_root` 按词逆序反射。相关说明见 [[反射闭包的防御性不变量]] 与 [[原型 Weyl 群的作用像枚举]]。^[lib-root.md:39-44]

上述算法描述并未被来源列为三个测试的完整覆盖内容；现有测试锚点不能据此扩展为根系枚举、Weyl 群枚举或全部算术路径已通过验证的结论。^[lib-root.md:39-44, lib-root.md:51-58]

原型 `RootDatum` 与 `root_datum` 模块中的 [[BasedRootDatum：带基根数据与构造不变量|BasedRootDatum]] 名称相近，但不是同一类型，原型测试的归属应保留这一边界。^[lib-root.md:57-58]

## 来源范围与验证状态

来源只覆盖 `lib.rs` 的门面与原型层，不覆盖各模块的实现。`StructureError` 的完整变体清单另见 `error-global-tits` 来源包，`weyl_size` 与 `global_tits` 的消费者也不在本文件中。^[lib-root.md:55-58]

精确读取身份由 `2026-10-06-lib-root.json` 记录，绑定 Git base、文件字节 SHA-256 与 Kimi 调用记录；草案由维护者对照源码逐条核对改写。本次知识维护未执行 Atlas、Cargo、测试或 benchmark，因此这里记录的是源码中的测试锚点，而非本次运行得到的测试通过结果。^[lib-root.md:62-66]
