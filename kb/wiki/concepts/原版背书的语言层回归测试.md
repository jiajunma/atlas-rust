# 原版背书的语言层回归测试

原版背书的语言层回归测试将 HPC 差分发现的差异固化为回归用例，以原版输出作为比较依据。`session.rs` 中的典型做法是通过 `include_str!` 载入 `tests/math/generics/` 下的 fixture，再逐字节比对 `.oracle.stdout` 与 `.oracle.stderr`。源材料将“每个差异先落成原版背书的回归”列为硬规则。^[atlas-core-session.md:58-68]

## 测试库与覆盖范围

本快照中的 `session.rs` 共 3889 行，生产代码位于第 1–178 行，第 179–3889 行包含 201 个 `#[test]`。模块负责 [[有状态的逐命令会话执行]]：Atlas 的词法分类依赖先前命令留下的状态，因此外层循环不会预先切分整个源文件。^[atlas-core-session.md:9-14, atlas-core-session.md:58-58]

按测试名称前缀统计，较大的家族包括 `named`（10 项）、`while`（8 项），以及 `polynomial`、`operator`、`generic`、`for`（各 7 项）；此外还有 `weyl`、`torus`、`returns`（各 6 项），`completion`、`byte`（各 5 项），`recursive`、`psp4`、`overload`、`matrix`（各 4 项）。这些计数描述的是该快照的测试组织，不能脱离版本解释为通用覆盖结论。^[atlas-core-session.md:60-68, atlas-core-session.md:78-80]

## 原版输出与逐字节比对

冻结的 oracle 输出为具体用例提供比较基准。例如，`weyl_context_core_cold_dual_original` 从源码第 796 行起，绑定 A1 `cold_dual` 的冻结 goldens。源材料说明，这些测试的可执行正确性由 HPC 门验证，所述 `session.rs` 字节与 632 项清单中的对应文件一致；632 项清单与本文件的 201 个测试是不同统计范围。^[atlas-core-session.md:63-68]

逐字节比较所涉及的输出边界包括 [[SessionEvent 与字节保留输出]]。`SessionEvent::output()` 先尝试 `String::from_utf8`：合法 UTF-8 进入 `Output`，非法 UTF-8 则以原始字节进入 `OutputBytes`，不会被替换字符改写。^[atlas-core-session.md:20-26]

## 会话行为中的关键约束

标识符在 token 被消费时记录，以保留被包含文件与后续命令的首次使用顺序，参见 [[补全标识符的首次使用顺序]]。多行命令解析返回 `Ok(None)` 时，会保留缓冲前缀、不求值且不发出诊断；raw 与文件会话使用同一条处理路径，参见 [[多行命令的增量解析]]。^[atlas-core-session.md:42-50]

源码位置和输出顺序也是会话层的可观察行为。`SetType` 的跨度依据真实词法终止符重建；执行失败时，先通过 `drain_failed_printed(span)` 排空已经打印的内容，再发出诊断。相关机制见 [[SetType 命令的词法终止符跨度重建]] 与 [[运行时失败后的已打印输出保留]]。^[atlas-core-session.md:51-56]

## 证据边界

源材料的结构性阅读不构成语言或数学验收。文件头及注释中的上游行号属于实现方的移植陈述，语义等值以 HPC 差分门为准。材料为 Weyl owner/dual 语义指向的证据是 A1 范围的限定验收记录 `tests/reference/hpc/math_weyl_context_core_after_v5_acceptance_2026_10_06.json`，不能据此扩展验收范围。^[atlas-core-session.md:9-14, atlas-core-session.md:75-77]

测试名称与家族计数绑定于 Git base `964f0033`、`session.rs` SHA-256 前缀 `969cdb27…` 所标识的快照，其字节与已验收的 after-v5 清单一致。这种一致性用于识别证据版本；哈希本身不证明代码正确。^[atlas-core-session.md:78-80]
