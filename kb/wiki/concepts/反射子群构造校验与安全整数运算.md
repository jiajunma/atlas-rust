# 反射子群构造校验与安全整数运算

`Subgroup::new` 是 `Weyl_orbit` 与 `Weyl_orbit_ws` 的反射子群构造与校验入口。它检查生成元根号及其 Cartan 配对矩阵，并在配对和反射计算中执行受检整数窄化；溢出与向量错秩通过错误报告，不产生回绕轨道。^[atlas-core-weyl-subgroup.md:25-35, atlas-core-weyl-subgroup.md:63-64]

## 参数与生成元校验

调用接收三个参数；dual 形式的参数顺序为 `vec, rd, gens`，通过首参不是 `RootDatum` 来识别。生成元可以是任意有符号根号，不要求是单根，但其配对必须合法。^[atlas-core-weyl-subgroup.md:27-33, atlas-core-weyl-subgroup.md:68-69]

生成元校验由 `check_W_subsystem` 先执行窄化，再逐个通过 `internal_root_nbr` 检查有符号根号。构造配对矩阵后，使用 `infer_lie_type` 检查；失败时报原版诊断 `"Matrix for root indices is not a Cartan matrix: \n  …"`。单生成元特例将配对值打印为一阶矩阵 \(\begin{pmatrix}c\end{pmatrix}\)，文本形式使用双层方括号。^[atlas-core-weyl-subgroup.md:29-33]

向量大小不匹配时返回 `"Wrong vector size for Weyl subgroup orbit"`。原版对过短向量存在越界读取行为，本实现将其处理为明确错误，不模拟未定义行为。^[atlas-core-weyl-subgroup.md:53-54]

## 安全整数运算

Cartan 配对矩阵使用 `i128` 中间精度；结果窄化失败时报告 `"Integer value too big for Cartan pairing"`。`level` 与 `reflect` 的配对、反射计算检查 `i128` 到 `i32` 的窄化，相关轨道坐标错误信息包含 `"…subgroup orbit coordinate"`。^[atlas-core-weyl-subgroup.md:29-35]

陪集树使用精确的单根或单余根配对坐标，以避免任意格核向量的选取及相关定宽溢出。原版核选向量在旧稳定器上配对为零，在新增生成元上配对为正数 \(c\)；本实现将后者取为 \(1\)。这种正比例缩放保持符号、相等判定及 BFS 边一致。有限 Cartan 矩阵的可逆性保证该限制在轨道差上单射，活动子群外的坐标不改变相等判定。详见 [[精确根配对坐标的陪集树算法]]。^[atlas-core-weyl-subgroup.md:38-42]

## 校验与轨道计算的边界

`validate` 采用 [[BuildAndDrop 领域内建验证策略]]，只执行 `Subgroup::new`，不计算轨道。因此，即使调用结果随后被丢弃，非法生成元仍须先触发构造校验与诊断。^[atlas-core-weyl-subgroup.md:52-54, atlas-core-weyl-subgroup.md:63-69]

构造后的优势化使用给定生成元：每步选取首个负 `level` 的生成元进行反射，并按应用顺序记录事件。用户生成元顺序控制优势化与扩展，内部稳定器 BFS 使用 `RootNbr` 顺序；两者应分别理解，参见 [[反射子群轨道与生成元约束下的优势化]] 和 [[反射子群轨道的稳定排序规则]]。^[atlas-core-weyl-subgroup.md:36-42, atlas-core-weyl-subgroup.md:68-69]

## 测试与证据范围

文件内测试检查非法根号、非 Cartan 矩阵诊断文本及 `i32` 窄化，要求非法生成元在结果丢弃前得到诊断，并将溢出与错秩作为安全错误处理。其他测试锚点覆盖空子群保持负权不动并返回 ambient 恒等、陪集轨道与独立穷举闭包一致、见证可重建，以及全单子群保持全群轨道顺序。^[atlas-core-weyl-subgroup.md:56-64]

这些测试锚点可结合 [[反射子群轨道与见证的独立验证]] 阅读。来源仅覆盖 `crates/atlas-core/src/domain_builtins/weyl_subgroup.rs` 的结构性阅读，其编辑状态不代表数学验收。^[atlas-core-weyl-subgroup.md:9-14, atlas-core-weyl-subgroup.md:70-72]
