# 反射子群构造校验与安全整数运算

`Subgroup::new` 是 `Weyl_orbit` 与 `Weyl_orbit_ws` 的反射子群构造与校验入口，检查生成元根号及其 Cartan 配对矩阵。实现采用宽整数中间运算和受检窄化，将溢出与向量错秩报告为安全错误，避免产生回绕轨道。^[atlas-core-weyl-subgroup.md:9-12, atlas-core-weyl-subgroup.md:25-35, atlas-core-weyl-subgroup.md:63-64]

## 参数与生成元校验

调用接收三个参数；dual 形式按 `vec, rd, gens` 排列，通过首参不是 `RootDatum` 识别。生成元允许使用任意有符号根号，不限于单根，但其配对矩阵必须合法。^[atlas-core-weyl-subgroup.md:27-33, atlas-core-weyl-subgroup.md:68-69]

`check_W_subsystem` 先执行整数窄化，再逐个通过 `internal_root_nbr` 检查有符号根号。配对矩阵交由 `infer_lie_type` 检查；失败时保留原版诊断 `"Matrix for root indices is not a Cartan matrix: \n  …"`。单生成元情况下，一阶矩阵 $\begin{pmatrix}c\end{pmatrix}$ 的诊断文本采用双层方括号形式。^[atlas-core-weyl-subgroup.md:29-33]

向量大小不匹配时返回 `"Wrong vector size for Weyl subgroup orbit"`。上游对过短向量可能越界读取，Rust 实现对此返回明确错误，不模拟未定义行为。^[atlas-core-weyl-subgroup.md:53-54]

## 配对与反射的整数边界

Cartan 配对矩阵使用 `i128` 中间精度，窄化失败时报 `"Integer value too big for Cartan pairing"`。`level`／`reflect` 的配对与反射计算检查 `i128` 到 `i32` 的窄化，坐标相关诊断包含 `"…subgroup orbit coordinate"`。^[atlas-core-weyl-subgroup.md:29-35]

陪集树采用精确的单根或单余根配对坐标，避免任意格核向量的选取及相关定宽溢出。原版核选向量在旧稳定器上配对为零，在新增生成元 $i$ 上配对为正数 $c$；本实现将该正配对取为 $1$。放大子群上的配对向量仅相差正比例缩放，因此符号、相等判定与 BFS 边保持一致。有限 Cartan 矩阵的可逆性使这一限制在轨道差上单射，活动子群外的坐标不改变相等判定。^[atlas-core-weyl-subgroup.md:38-42]

## 校验与轨道计算的边界

`validate` 采用 [[BuildAndDrop 领域内建验证策略]]，仅执行 `Subgroup::new`，不计算轨道。非法生成元必须在结果丢弃前得到诊断；原版也先完成校验，再进入无值处理。^[atlas-core-weyl-subgroup.md:52-52, atlas-core-weyl-subgroup.md:63-69]

实际轨道计算中的 `dominant` 使用调用方给定的生成元，每步选择首个负 `level` 的生成元进行反射，并按应用顺序记录事件。用户生成元顺序控制优势化与扩展，内部稳定器 BFS 则使用 `RootNbr` 顺序；参见 [[反射子群轨道与生成元约束下的优势化]] 和 [[反射子群轨道的稳定排序规则]]。^[atlas-core-weyl-subgroup.md:36-42, atlas-core-weyl-subgroup.md:68-69]

## 测试与证据范围

文件内的错误处理测试覆盖非法根号、非 Cartan 矩阵诊断文本及 `i32` 窄化，要求非法生成元在结果丢弃前触发诊断，并将溢出与错秩作为安全错误处理。其他测试锚点覆盖空子群保持负权不动且返回 ambient 恒等、陪集轨道与独立穷举闭包一致、见证可重建，以及全单子群保持完整全群轨道顺序；参见 [[反射子群轨道与见证的独立验证]]。^[atlas-core-weyl-subgroup.md:56-64]
