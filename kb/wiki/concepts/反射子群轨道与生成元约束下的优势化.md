# 反射子群轨道与生成元约束下的优势化

`crates/atlas-core/src/domain_builtins/weyl_subgroup.rs` 实现反射子群的 `Weyl_orbit` 与 `Weyl_orbit_ws`，分别返回轨道列矩阵与 ambient Weyl 见证词。初始优势化使用调用方指定的生成元；生成元可以是任意有符号根号，只要配对矩阵合法，并不限于单根。^[atlas-core-weyl-subgroup.md:9-12, atlas-core-weyl-subgroup.md:18-23, atlas-core-weyl-subgroup.md:46-51, atlas-core-weyl-subgroup.md:68-69]

## 生成元约束下的优势化

`dominant` 按给定生成元顺序选择首个负 `level` 的生成元，施行反射，并按实际应用顺序记录事件。权与余权两种作用均采用这一记录方式。用户生成元顺序控制优势化及后续扩展，内部稳定器 BFS 则使用 RootNbr 顺序，两种顺序各有职责。^[atlas-core-weyl-subgroup.md:34-37, atlas-core-weyl-subgroup.md:68-69]

这一行为修正了 original `7e1b958c` 的 R3 反例：`rootdata.h` 在转发 `make_(co)dominant` 时忽略生成元参数 `g`，见证函数却传递了正确参数。对于 A2、空生成元集和输入 `[-1,-2]`，原版矩阵轨道给出 `[2,1]`，见证却为恒等。Rust 实现以“空子群保持输入不变并返回 ambient 恒等”为独立的平凡子群不变量。^[atlas-core-weyl-subgroup.md:18-23, atlas-core-weyl-subgroup.md:58-59]

## 陪集树与轨道顺序

`cosets` 使用精确的单根或单余根配对坐标构造陪集树。原版核选向量在旧稳定器上配对为零，在新增生成元上配对为正数 \(c\)；本实现将该值取为 \(1\)。在扩大的子群上，两者的配对向量相差正比例缩放，因而保留符号、相等关系及 BFS 边。有限 Cartan 矩阵的可逆性使限制映射在轨道差上单射，活动子群之外的坐标不改变相等判定，从而避免任意格核选举及其定宽溢出问题。详见 [[精确根配对坐标的陪集树算法]]。^[atlas-core-weyl-subgroup.md:38-42]

轨道排序遵循 `rootdata.cpp` 的 BitMap `basic_orbit`／`extend_orbit`，不同于 alcove 变体的分层排序。内部 BFS 仅对新层去重，保留首次插入项，活动生成元按根号排列；这些规则须与用户顺序控制的优势化和扩展一并保留。参见 [[反射子群轨道的稳定排序规则]]。^[atlas-core-weyl-subgroup.md:18-19, atlas-core-weyl-subgroup.md:42-42, atlas-core-weyl-subgroup.md:68-69]

## 轨道矩阵与见证词

`Weyl_orbit` 将轨道元素作为矩阵列返回，列具有校验过的格秩。`Weyl_orbit_ws` 沿陪集树逐个非稳定器生成元扩展，生成 ambient Weyl 见证词。作用方向决定事件的拼接顺序：权从右到左作用，采用事件逆序；余权从左到右作用，dual 情形采用事件正序。^[atlas-core-weyl-subgroup.md:46-49]

见证词经 `build_weyl_context` 与逐次 `right_multiply_simple` 重建为 Weyl 元素，再由 `weyl_elt_value` 冻结为 canonical word。因此，反射事件的记录顺序、作用方向与最终规范词表示需要分别理解。相关约定见 [[ambient Weyl 见证词与作用方向]]。^[atlas-core-weyl-subgroup.md:36-37, atlas-core-weyl-subgroup.md:47-51]

## 校验与安全边界

`Subgroup::new` 逐个校验有符号根号，以 `i128` 中间精度计算配对矩阵，并通过 `infer_lie_type` 检查 Cartan 合法性。配对结果窄化失败时报 `"Integer value too big for Cartan pairing"`；反射坐标从 `i128` 窄化到 `i32` 时同样进行检查。详见 [[反射子群构造校验与安全整数运算]]。^[atlas-core-weyl-subgroup.md:29-35]

`validate` 采用 [[BuildAndDrop 领域内建验证策略]]，仅执行构造而不计算轨道。向量维数不匹配时报 `"Wrong vector size for Weyl subgroup orbit"`；实现不模拟上游对短向量的越界读取，溢出与错秩均作为安全错误处理。^[atlas-core-weyl-subgroup.md:52-54, atlas-core-weyl-subgroup.md:63-64]

## 测试与证据范围

文件内测试覆盖空子群保持负权不动并返回 ambient 恒等，范围为九个类型、两种编号、两种 isogeny 和两种作用的组合。其他测试检查陪集轨道与独立穷举闭包相等、通过 `word`／`root_datum` 往返及逐见证作用重建轨道列，以及全单根子群与完整 Weyl 群轨道序逐项相等。参见 [[反射子群轨道与见证的独立验证]]。^[atlas-core-weyl-subgroup.md:56-62]

非法生成元测试检查错误在值被丢弃前仍被诊断，覆盖非法根号、非 Cartan 矩阵文本及 `i32` 窄化。上述内容是单文件的结构性阅读与测试锚点记录，不构成数学验收声明；源文档将相关 HPC 门指向 `weyl_subgroup_orbits` 切片及下游目录。^[atlas-core-weyl-subgroup.md:63-64, atlas-core-weyl-subgroup.md:9-14, atlas-core-weyl-subgroup.md:70-72]
