# 反射子群轨道与见证的独立验证

反射子群轨道与见证的独立验证针对两个关联输出：`Weyl_orbit` 返回以轨道元素为列的矩阵，`Weyl_orbit_ws` 返回 ambient Weyl 见证词。实现文件 `crates/atlas-core/src/domain_builtins/weyl_subgroup.rs` 中的测试分别检查轨道与独立闭包的一致性、见证重建、顺序兼容和失败行为。^[atlas-core-weyl-subgroup.md:10-14, atlas-core-weyl-subgroup.md:44-64]

## 轨道与见证的交叉核验

核心测试将陪集算法产生的轨道与**独立穷举闭包**比较，并检查每个见证的 `word`／`root_datum` 往返，以及通过逐见证 `*` 作用重建对应轨道列。这同时核验轨道结果与见证的可用性；轨道构造背景见 [[精确根配对坐标的陪集树算法]]。^[atlas-core-weyl-subgroup.md:38-42, atlas-core-weyl-subgroup.md:60-61]

见证重建须保留作用方向：权从右到左作用，余权从左到右作用。实现按应用顺序记录反射事件，dual 情形按事件正序拼接，否则逆序拼接；随后通过 `build_weyl_context` 与逐次 `right_multiply_simple` 重建元素，再由 `weyl_elt_value` 冻结为 canonical word。相关约定见 [[ambient Weyl 见证词与作用方向]]。^[atlas-core-weyl-subgroup.md:36-37, atlas-core-weyl-subgroup.md:47-51]

## 平凡子群不变量与历史反例

空生成元集合的测试要求负权保持不动，并返回 ambient 恒等见证；覆盖九个类型、两种编号、两种 isogeny 和两种作用。这是独立于原版输出的平凡子群不变量检查。^[atlas-core-weyl-subgroup.md:18-23, atlas-core-weyl-subgroup.md:58-59]

保留的 R3 反例说明了这一检查的必要性：original `7e1b958c` 的 `rootdata.h` 在转发初始 dominance 操作时忽略生成元参数，而见证函数正确传递该参数。在 A2、空生成元、输入 `[-1,-2]` 时，原版矩阵轨道给出 `[2,1]`，见证却为恒等。Rust 实现的初始 dominance 确实使用给定生成元，相关行为见 [[反射子群轨道与生成元约束下的优势化]]。^[atlas-core-weyl-subgroup.md:18-23]

## 顺序兼容

全单子群测试要求轨道及见证与全群 `Weyl_orbit`／`_ws` 逐等，以检查完整全群轨道序。实现遵循 `rootdata.cpp` 的 BitMap `basic_orbit`／`extend_orbit` 排序，不采用 alcove 变体的分层排序。^[atlas-core-weyl-subgroup.md:18-19, atlas-core-weyl-subgroup.md:62-62]

顺序约定还区分内部稳定器遍历和用户输入：内部稳定器 BFS 使用 RootNbr 序，用户生成元顺序控制 dominance 和扩展；陪集 BFS 仅对新层去重，并保留首次插入。具体规则见 [[反射子群轨道的稳定排序规则]]。^[atlas-core-weyl-subgroup.md:38-42, atlas-core-weyl-subgroup.md:68-69]

## 构造校验与失败行为

非法生成元测试要求在结果丢弃前完成校验，并匹配原版的非法根号、非 Cartan 矩阵文本及 `i32` 收窄诊断。溢出和向量错秩应产生安全错误，而非回绕轨道；向量大小不匹配时返回 `"Wrong vector size for Weyl subgroup orbit"`，不模拟上游短向量越界读取行为。^[atlas-core-weyl-subgroup.md:53-54, atlas-core-weyl-subgroup.md:63-64]

`validate` 采用 [[BuildAndDrop 领域内建验证策略]]，仅调用 `Subgroup::new`，不会计算轨道。因此，构造阶段的校验不能替代轨道与见证的结果核验。生成元和算术检查可参见 [[反射子群构造校验与安全整数运算]]。^[atlas-core-weyl-subgroup.md:25-35, atlas-core-weyl-subgroup.md:52-52]

## 证据边界

源包记录的是结构性阅读和文件内四类测试锚点，不声称数学验收，也未给出这些测试的执行结果。覆盖范围限于该实现文件；数学验收的 HPC 门需另查 `docs/slices` 下的 `weyl_subgroup_orbits` 切片及下游目录。^[atlas-core-weyl-subgroup.md:9-14, atlas-core-weyl-subgroup.md:56-72]

源包还标注 Git base `964f0033` 和文件 SHA-256 前缀 `86d52b4f…`，并说明其与已验收 after-v5 清单中的字节相同；这些标识用于定位快照字节，不能将本包的结构性阅读扩展为独立数学验收结论。^[atlas-core-weyl-subgroup.md:13-14, atlas-core-weyl-subgroup.md:73-74]
