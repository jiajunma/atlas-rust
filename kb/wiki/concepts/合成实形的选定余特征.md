# 合成实形的选定余特征

合成实形的选定余特征由 `minimal_torus.rs` 中的 `elected_square_root` 计算，服务于 `real_form_value::build` 的自定义种子分支。它对应上游 `real_form_of` 的 `coch` 输出：从投影后的环面因子算出的强数据移位平方的 [[stable_log：选举的稳定对数|stable_log]]，由自定义 `RealReductiveGroup` 构造器保存为 `g_rho_check`。^[minimal-torus.md:17-21]

## 输入校验与 Weyl 作用方向

函数首先检查 `factor` 的长度是否等于格秩，不符则返回 `RankMismatch`；随后检查 `twisted` 的像置换长度是否等于根数，不符则返回 `DatumMismatch`。^[minimal-torus.md:35-36]

矩阵级作用由 `twisted.reduced_word` 重建：按 `word.iter().rev()` 的顺序逐生成元左复合单反射，再通过 `WeylElement::from_action` 转换，校验所得元素是否等于原来的 `twisted`。这一往返检查固定了字的合成方向，关联 [[Weyl 群的矩阵作用与词级元素双层结构]]。^[minimal-torus.md:36-39]

## 环面因子的运输与稳定对数

环面因子先经过 distinguished 对合的余权矩阵，再经过 Weyl 元素的余权作用矩阵，得到 `after_w`。代码注释将其对应到 `square_shifted = t + w.delta_tr(t)`，并说明其中的 Weyl 作用在对偶侧，参见 [[WeylAction 的对偶全格作用]]。^[minimal-torus.md:38-40]

函数逐坐标计算半平方 `half_square = (factor + after_w)/2`，构造 `plus_one = delta + I`，最后调用 `stable_log(half_square, plus_one, budget)` 得到选定余特征。`budget` 仅透传给这一调用。^[minimal-torus.md:40-42]

## 与最小环面部分的衔接

`minimal_torus_part` 使用选定余特征 `coch` 构造初始环面部分：要求 `factor − coch` 的每个坐标都是整数，否则触发 `"torus-part integrality"` 错误；将整数差的奇数坐标置位，得到 `torus_part`。^[minimal-torus.md:50-52]

强代表经逆 Cayley 与 based twisted 共轭[[强代表下降到基本纤维|下降到基本纤维]]并约化后，函数构造 `coweight = coch + lift(tp)`，即在环面部分置位的坐标上加 1。基本纤维虚单根与该余权的偶配对决定起始 grading，其中置位表示紧致。后续[[最小环面部分的 grading 轨道搜索]]筛选符合目标模式的候选，再按等维位向量的整数序选取最小环面部分。^[minimal-torus.md:53-76]

## 测试与证据边界

来源列出四个测试锚点，均为 rank 2 的紧致内类。A1.T1 中心因子案例满足 `coch == factor`，环面部分为零；A2 非典范种子案例中，配 `s0` 的因子 `[1/3,2/3]` 与配 `s1` 的因子 `[2/3,1/3]` 各自保持，环面部分分别在索引 0 与 1 处置位。另外两个锚点涉及等价因子选取同一种子，以及长度不符和空 `InvolutionTable` 的具名拒绝。^[minimal-torus.md:78-87]

三个正例均满足 `coch == factor`，因此尚未通过可区分的断言刻画非平凡运输行为；第三个测试与第二个测试的第一组输入完全相同，其独立价值仅见于注释叙述。测试还未覆盖非紧致 distinguished、多数具名错误分支，以及 `minimal_torus_part` 的 rank 大于 63 资源门，详见[[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:89-98]
