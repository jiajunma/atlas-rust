# 合成实形的选定余特征

合成实形的选定余特征由 `minimal_torus.rs` 中的 `elected_square_root` 计算。它对应上游 `real_form_of` 的 `coch` 输出，即从投影后的环面因子算出的强数据移位平方的 [[stable_log：选举的稳定对数|stable_log]]，并由自定义 `RealReductiveGroup` 构造器保存为 `g_rho_check`。该函数服务于 `real_form_value::build` 的自定义种子分支。^[minimal-torus.md:17-21]

## 计算流程

`elected_square_root` 首先检查输入的维度：`factor` 的长度必须等于格秩，否则返回 `RankMismatch`；`twisted` 的像置换长度必须等于根数，否则返回 `DatumMismatch`。^[minimal-torus.md:35-36]

随后，函数从 `twisted.reduced_word` 重建矩阵级作用：按 `word.iter().rev()` 的顺序逐生成元左复合单反射，再检查经 `WeylElement::from_action` 转换后是否等于原来的 `twisted`。这一往返校验用于固定词的合成方向，与 [[Weyl 词对根与权的作用顺序]] 相关。^[minimal-torus.md:36-39]

环面因子的运输依次应用 distinguished 对合的余权矩阵与 Weyl 元素的余权作用矩阵，得到 `after_w`。代码注释将这一顺序联系到 `square_shifted = t + w.delta_tr(t)`，其中 Weyl 作用位于对偶侧。函数逐坐标计算 `half_square = (factor + after_w)/2`，构造 `plus_one = delta + I`，最后调用 `stable_log(half_square, plus_one, budget)`；预算仅透传给该调用。^[minimal-torus.md:38-42]

## 与初始环面部分的关系

选定余特征 `coch` 随后参与 `minimal_torus_part` 的计算。该函数要求 `factor − coch` 的每个坐标均为整数，否则触发 `"torus-part integrality"` 错误；整数差的奇数坐标置位，形成初始 `torus_part`。因此，初始环面部分记录的是给定环面因子相对于 `coch` 的整数差的奇偶信息。^[minimal-torus.md:50-52]

初始强代表经逆 Cayley 与 based twisted 共轭[[强代表下降到基本纤维|下降到基本纤维]]后，函数构造 `coweight = coch + lift(tp)`，即在环面部分置位的坐标上加 1。该余权与基本纤维虚单根的偶配对决定起始紧致性模式，供后续[[最小环面部分的 grading 轨道搜索]]使用。^[minimal-torus.md:53-67]

## 测试与证据边界

测试锚点均处于 rank 2 的紧致内类。A1.T1 中心因子案例满足 `coch == factor`，且环面部分为零；A2 非典范种子案例中，配合 `s0` 的因子 `[1/3,2/3]` 与配合 `s1` 的因子 `[2/3,1/3]` 各自保持，最终环面部分分别在 `[0]` 与 `[1]` 处置位。^[minimal-torus.md:78-85]

三个正例测试都满足 `coch == factor`，尚未用可区分的断言刻画非平凡运输行为。现有覆盖也未包括非紧致 distinguished、多数具名错误分支及 rank 大于 63 的预算门；详见[[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:89-98]
