# 合成实形种子算法的门控与资源限制

`minimal_torus.rs` 的两个公开函数服务于 `real_form_value::build` 的自定义种子分支：`elected_square_root` 计算[[合成实形的选定余特征|选定余特征]]，`minimal_torus_part` 将强代表下降到基本纤维，再搜索符合目标弱实形紧致性模式的最小环面部分。其门控覆盖输入一致性、整性、对合表覆盖和轨道编码资源限制。^[minimal-torus.md:17-25, minimal-torus.md:35-76]

## 入口校验顺序

`elected_square_root` 首先检查 `factor` 长度是否等于格秩，不符时返回 `RankMismatch`；随后检查 `twisted` 的像置换长度是否等于根数，不符时返回 `DatumMismatch`。它从 `twisted.reduced_word` 重建矩阵作用，按 `word.iter().rev()` 逐生成元左复合单反射，并以 `WeylElement::from_action` 往返结果等于原 `twisted` 的校验确认字的合成方向。^[minimal-torus.md:35-38]

`minimal_torus_part` 的入口检查具有明确顺序：先检查 table 的 inner class，不符返回 `DatumMismatch`；再检查 `coch` 与 `factor` 的长度，不符返回 `RankMismatch`，其中 `actual` 取两者长度的较大值；随后检查置换长度，不符返回 `DatumMismatch`；最后检查格秩，大于 63 时返回 `SeedResourceLimit { resource: "mask bits" }`。^[minimal-torus.md:46-48]

## 算法内部的拒绝条件

初始环面部分要求 `factor − coch` 的每个坐标均为整数，否则报告 `"torus-part integrality"`；通过检查后，奇数坐标置位形成 `torus_part`。构造 `TitsCoset` 所用的 `grading_of_simples` 按单根配对的偶性计算，其配对整性检查采用具名门控，对应上游 `RatCoweight::dot` 的整性断言。^[minimal-torus.md:50-55]

[[强代表下降到基本纤维]]要求 `table.lookup(twisted)` 命中，否则报告 `"synthetic involution coverage"`。下降循环在 Weyl 部分为恒等时停止；否则按 `interface.outward()` 的迭代顺序选取首个左下降生成元。若该生成元在当前对合下为 Real，则执行逆 Cayley，返回 `Ok(None)` 也视为错误；否则执行 based twisted 共轭 `cross_pregated`。循环结束后执行幂等的 `coset.reduce`，输入本就在基本纤维时，这一步仍起决定作用。^[minimal-torus.md:55-61]

[[最小环面部分的 grading 轨道搜索]]只将受约束位置与目标一致的状态纳入候选。候选为空时返回具名错误 `"minimal torus part candidates"`，对应上游的断言；候选非空时，按 `ModTwoVector` 的等维位向量整数序选取最小值。^[minimal-torus.md:72-76]

## 编码上限与预算接口

轨道搜索使用 LIFO 栈和 `BTreeSet<u64>` 去重，状态数上限为 \(2^{\mathrm{rank}}\)。`MAX_MASK_BITS = 63` 为 seen-set 编码限定格秩上限，与弱实形 mask 游走采用相同纪律；入口门拒绝超限输入。^[minimal-torus.md:30-31, minimal-torus.md:46-48, minimal-torus.md:72-74]

两个函数的预算接口不同：`elected_square_root` 将预算仅透传给 [[stable_log：选举的稳定对数|stable_log]]；`minimal_torus_part` 没有显式预算参数，资源防护限于 `MAX_MASK_BITS` 与分配防护。内部 `encode` 函数体不会失败，其 `Result` 签名属于预留接口。^[minimal-torus.md:40-42, minimal-torus.md:99-100]

## 测试覆盖与证据边界

现有四个测试均为 rank 2、紧致内类情形，其中门控测试覆盖长度不符和空 `InvolutionTable` 的具名拒绝。尚未覆盖多数具名错误分支、rank 大于 63 的资源门、非紧致 distinguished 情形及非平凡运输。三个正例均满足 `coch == factor`，因此未用可区分的断言刻画非平凡运输行为；详见[[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:78-98]
