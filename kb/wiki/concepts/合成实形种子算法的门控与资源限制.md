# 合成实形种子算法的门控与资源限制

合成实形的自定义种子分支使用 `elected_square_root` 计算[[合成实形的选定余特征|选定余特征]]，并使用 `minimal_torus_part` 将强代表下降到基本纤维，再搜索符合目标弱实形紧致性模式的最小环面部分。两者的门控涉及输入维数、根数据一致性、整性、对合表覆盖与资源限制。^[minimal-torus.md:17-25, minimal-torus.md:35-76]

## 输入校验与错误顺序

`elected_square_root` 首先检查 `factor` 长度是否等于格秩，不符时返回 `RankMismatch`；随后检查 `twisted` 的像置换长度是否等于根数，不符时返回 `DatumMismatch`。函数还从 `twisted.reduced_word` 重建矩阵作用：按 `word.iter().rev()` 逐生成元左复合单反射，并通过 `WeylElement::from_action` 往返结果等于原 `twisted` 的校验，确认字的合成方向。^[minimal-torus.md:35-38]

`minimal_torus_part` 的入口校验依次检查 table 的 inner class、`coch` 与 `factor` 的长度、置换长度，以及格秩上限。对应错误依次为 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 和 `SeedResourceLimit { resource: "mask bits" }`；长度错误的 `actual` 取 `coch` 与 `factor` 长度的较大值，格秩超过 63 时触发资源门。^[minimal-torus.md:46-48]

## 算法内部的具名拒绝

初始环面部分由 `factor − coch` 得到，每个坐标都必须为整数，否则触发 `"torus-part integrality"`；通过后，以奇数坐标置位构造 `torus_part`。构造 `TitsCoset` 所用的 `grading_of_simples` 按单根配对的偶性计算，其配对整性检查也采用具名门控，对应上游的整性断言。^[minimal-torus.md:50-55]

[[强代表下降到基本纤维]]要求对合表包含输入 `twisted`；`table.lookup(twisted)` 缺失时报告 `"synthetic involution coverage"`。下降按 `interface.outward()` 的迭代序选择首个左下降生成元：若该生成元在当前对合下为 Real，则执行逆 Cayley，返回 `Ok(None)` 也按错误处理；否则执行 based twisted 共轭。^[minimal-torus.md:55-61]

[[最小环面部分的 grading 轨道搜索]]仅接受受约束位置与目标模式一致的候选。若候选集合为空，Rust 实现返回具名错误 `"minimal torus part candidates"`，对应上游的断言；非空时按 `ModTwoVector` 的等维位向量整数序选择最小候选。^[minimal-torus.md:72-76]

## 资源限制与预算边界

轨道搜索使用 LIFO 栈和 `BTreeSet<u64>` 去重，状态数上限为 \(2^{\mathrm{rank}}\)。`MAX_MASK_BITS = 63` 限定去重集合编码可接受的格秩，并由入口检查拒绝超过上限的输入。^[minimal-torus.md:30-31, minimal-torus.md:46-48, minimal-torus.md:72-74]

两个函数的预算接口不同：`elected_square_root` 将预算仅透传给 [[stable_log：选举的稳定对数|stable_log]]；`minimal_torus_part` 没有显式预算参数，其资源防护限于 `MAX_MASK_BITS` 与分配防护。内部 `encode` 的函数体不会失败，`Result` 签名只是预留。^[minimal-torus.md:40-42, minimal-torus.md:99-100]

## 测试与证据边界

现有四个测试均处于 rank 2 的紧致内类，门控测试覆盖长度不符及空 `InvolutionTable` 的具名拒绝。多数具名错误分支、rank 大于 63 的资源门、非紧致 distinguished 情形和非平凡运输尚未覆盖；三个正例均满足 `coch == factor`，因此没有用可区分的断言刻画非平凡运输行为。参见[[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:78-98]
