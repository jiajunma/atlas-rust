# 向量逐项除法与非负余数约定

向量 `\` 与 `%` 执行逐项算术，其中 `%` 的余数始终落在区间 `[0, |m|)` 内，`\` 的商与这一余数约定相配。因此，负除数不会使余数变成负数。来源将该行为对应到上游 `global.w:3917–3937`。^[atlas-core-builtin-registry.md:50-51]

## 负除数示例

来源给出的 oracle 示例为 `[7] % -3 == [1]` 与 `[7] \ -3 == [-2]`：除数为 `-3` 时，余数取 `1`，对应的商为 `-2`。理解或实现这两个运算时，应同时保留商与非负余数的配对约定。^[atlas-core-builtin-registry.md:50-51]
