# 向量逐项除法与非负余数约定

向量 `\` 与 `%` 执行逐项算术：余数始终取在区间 `[0, |m|)` 内，商与该余数约定配套。因此，除数为负时，余数仍然非负。来源将这一求值期契约对应到上游 `global.w:3917–3937`。^[atlas-core-builtin-registry.md:53-54]

## 负除数示例

来源给出的 oracle 示例为 `[7] % -3 == [1]` 与 `[7] \ -3 == [-2]`。对于除数 `-3`，余数为 `1`，商为 `-2`；两者共同体现了商与非负余数的配对约定。^[atlas-core-builtin-registry.md:53-54]

## 实现背景

该约定记录在内建注册表源码包的“求值期辅助的上游契约”部分。该包还覆盖 `Builtin` 元数据、`BuiltinImpl` 实现分发和启动清单，相关背景可参见 [[内建函数元数据与实现分发]] 与 [[内建注册表的启动清单与覆盖边界]]。^[atlas-core-builtin-registry.md:9-15, atlas-core-builtin-registry.md:49-54]

本材料未说明零除数的处理方式或诊断，不能由非负余数约定推定其行为；逐条内建语义也不在该源码包的覆盖范围内。^[atlas-core-builtin-registry.md:53-54, atlas-core-builtin-registry.md:78-81]
