# 向量逐项除法与非负余数约定

向量 `\` 与 `%` 执行逐项算术：`%` 的余数取在区间 `[0, |m|)` 内，`\` 的商与该余数约定配套。因此，除数为负时，余数仍然非负。来源将这一求值期契约对应到上游 `global.w:3917–3937`。^[atlas-core-builtin-registry.md:53-54]

## 负除数示例

来源给出的 oracle 示例是 `[7] % -3 == [1]` 与 `[7] \ -3 == [-2]`。除数为 `-3` 时，余数为 `1`，商为 `-2`；这两个结果共同体现了商与非负余数的配对约定。^[atlas-core-builtin-registry.md:53-54]
