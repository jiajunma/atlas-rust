# 块修正子的相对化与标准参数恢复

`RepContext::make_relative_to` 将相对定位器与表示参数的整正交差记录到块修正子中；`sr_with_modifier` 依次施加平移、反向 Weyl 姿态变换和标准参数转换。两条路径依赖同一典范 Weyl 词在两个方向上的逐字母互逆性。^[block-access-modifier.md:58-81]

## 修正子的表示

[[BlockModifier 块修正子]]包含 `locator: BlockLocator` 与 `shift: RationalWeight`。`trivial(system, simp_int)` 构造恒等 Weyl 元、恒等 `simple_pi` 和零平移；`int_sys` 取 `u32::MAX`，对应上游的 `-1` 哨兵，仅供局部使用且永不读取。`from_locator` 无校验地包装定位器；`clear` 保留 `int_sys` 与 `simp_int`，重置 Weyl 元、`simple_pi` 和平移。^[block-access-modifier.md:52-56]

## 相对化流程

`make_relative_to(loc, srm0, bm, srm1)` 首先对定位器部分执行逆合成，随后使用**更新后的** `bm.w`，通过 `transform<true>` 将 `srm1` 移回基姿态，最后把 `bm.shift` 设置为两个 `gamma_lambda` 的整正交差。定位器部分的相关主题见[[定位器的相对姿态变换]]。^[block-access-modifier.md:76-78]

`make_diff_integral_orthogonal` 从两个代表的差中减去其在 $(1-\theta)X^*$ 中的固定原像，使结果与 `srm.gamma_lambda()` 的整根系正交。计算经过 `IntegralSubsystem::integral`、`RepTable::integral_codec` 与 `theta_1_preimage`；差为零时短路，debug 构建包含正交性 `debug_assert`。^[block-access-modifier.md:72-75]

## Weyl 姿态变换

`transform_srm<LEFT_TO_RIGHT>` 沿 Weyl 词逐字母按 `kgb_status(x, s)` 分派：Complex 分支对 `x` 执行 cross，并对有理权分子施加 offset 为零的简单反射；Real 分支保持 `x` 不变，对分子施加以 $-\rho_R$ 为中心的仿射反射，offset 取分母；Imaginary 类分支返回 `RepInvariantViolation`。`LEFT_TO_RIGHT` 选择作用方向，收尾时在最终 `x` 处执行 `real_unique` 归一化。^[block-access-modifier.md:66-70]

私有函数 `simple_reflect_numerator` 按 $v \leftarrow v-\alpha_s(\langle v,\operatorname{coroot}_s\rangle+\mathrm{offset})$ 更新有理权分子，保持分母不变，全程使用 checked 算术。^[block-access-modifier.md:83-85]

Rust 使用 `WeylElement::reduced_word` 给出的典范最左下降约化词，上游则使用 transducer 随元素存储的词。实现文档将此声明为对目标域无语义差异的有意偏差：双向使用同一典范词，使 `transform<false>` 成为 `transform<true>` 的逐字母逆；相对化与标准参数恢复只依赖这一性质。参见[[Weyl 姿态变换与典范约化词]]。^[block-access-modifier.md:58-62]

## 标准参数恢复

`sr_with_modifier(srm, bm, gamma)` 的读取顺序固定为：先加 `bm.shift`，再执行 `transform<false>(bm.w)`，最后调用 `to_standard`，恢复[[StandardRepr 标准表示参数]]。其中，`shift_srm` 执行 `gamma_lambda += amount` 后，在不变的 involution 处归一化。^[block-access-modifier.md:71-81]

## 测试锚点与证据边界

源码包含两个集成测试。恒等修正子测试使用 A2 的 SL(3,R) fixture，KGB 尺寸为 4，检查 `sr_with_modifier` 与无修正子的 `sr` 一致。相对化往返测试使用定位器在同一典范数据上碰撞的 SL(3,R) 锚点对：`bm.w` 的词为 `[1]`，对应 oracle 的 `<1>`，平移为 `[0,1]/4`；平移与变换逐字母回到查询参数，完整 `sr_with_modifier` 精确恢复 `q` 本身，而非仅相差根平移。两个测试的注释包含 KGB 布局、墙交集与 word 过滤的手算推导。^[block-access-modifier.md:89-95]

上述内容描述源码中的测试锚点，不代表本次执行结果。来源属于结构性阅读，不构成数学或正确性验收；来源记录时，整个 `block_modifier` 切片尚未接线且无现存消费方。`transform_srm` 的分支覆盖通过集成测试间接进行，`shift_srm` 与 `make_diff_integral_orthogonal` 没有独立单元测试。^[block-access-modifier.md:9-13, block-access-modifier.md:99-105, block-access-modifier.md:114-115]
