# 块图的迭代式强连通分量算法

`strong_components` 在块图处理中采用迭代式 Tarjan 形强连通分量（SCC）算法，供 BlockGraph 的 SCC 消费者使用。相关实现位于 `crates/atlas-core/src/domain_builtins.rs` 的 3022 行起区域。^[atlas-core-domain-scc-root-table.md:9-14, atlas-core-domain-scc-root-table.md:16-20]

## 状态与迭代结构

算法使用 `rank`、`class_of`、`partition` 与 `induced` 等状态，并以 `active` 条目记录迭代过程。每个条目包含四项信息：顶点、父位置、下一边索引和最小秩；实现还设定 `nil = size` 与 `infinity = size + 1` 两个哨兵值。^[atlas-core-domain-scc-root-table.md:18-20]

## 证据范围

源材料仅对 SCC 区域头部进行了精读，提供了算法形态与核心状态摘要，未展开完整的遍历、状态更新和分量生成步骤。本页据此描述实现结构，不将其视为数学验收结论；上游行号属于实现方的移植陈述，兼容性仍须以 [[HPC 验收证据链|HPC 差分门]] 为准。^[atlas-core-domain-scc-root-table.md:9-14, atlas-core-domain-scc-root-table.md:40-45]
