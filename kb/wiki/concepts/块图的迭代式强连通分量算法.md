# 块图的迭代式强连通分量算法

`strong_components` 在块图处理中采用迭代式 Tarjan 形强连通分量（SCC）算法，供 `BlockGraph` 的 SCC 消费者使用。实现位于 `crates/atlas-core/src/domain_builtins.rs` 的 3022 行起区域。^[atlas-core-domain-scc-root-table.md:9-11, atlas-core-domain-scc-root-table.md:16-20]

## 状态与迭代结构

算法使用 `rank`、`class_of`、`partition` 与 `induced` 等状态。显式的 `active` 条目包含四项信息，依次为顶点、父位置、下一边索引和最小秩，用于记录迭代过程。^[atlas-core-domain-scc-root-table.md:18-20]

实现设定两个哨兵值：`nil = size` 与 `infinity = size + 1`。源材料记录了这些状态名、条目结构及哨兵取值，但没有展开完整的遍历、状态更新和分量生成步骤。^[atlas-core-domain-scc-root-table.md:18-20, atlas-core-domain-scc-root-table.md:40-42]

## 证据范围

本页依据结构性阅读摘要；来源仅对 SCC 区域头部进行了精读，不声称数学验收。因此，现有材料支持对算法形态和核心状态的描述，不能据此认定完整实现已获正确性或兼容性验收。^[atlas-core-domain-scc-root-table.md:9-14, atlas-core-domain-scc-root-table.md:40-44]

来源中的上游行号引用属于实现方的移植陈述，兼容性以 [[HPC 验收证据链|HPC 差分门]] 为准。来源标注的 Git base 为 `964f0033`；字节数与哈希仅标识快照字节。^[atlas-core-domain-scc-root-table.md:44-45]
