# 基于原版金标的差分回归

基于原版金标的差分回归，是 atlas-core 语言层将 HPC 差分发现的差异固化为回归测试的方式。测试使用原版完整捕获的输出作为金标，逐字节比较标准输出与标准错误，禁止使用 Rust 输出制作金标。^[atlas-core-regression-library.md:20-22, atlas-core-regression-library.md:36-38]

## Fixture 与金标绑定

每个 HPC 差分发现的差异都必须先在测试库中形成回归。Fixture 与 `.oracle.*` 金标存放在 `tests/math/generics/`，来源列举的实例包括 Weyl A1 的 v8 冻结 goldens。原版完整捕获是金标的来源约束，相关主题见[[原版背书的语言层回归测试]]。^[atlas-core-regression-library.md:36-38]

`session.rs` 中的典型回归通过 `include_str!` 载入 fixture，并逐字节比对 `.oracle.stdout` 与 `.oracle.stderr`，例如 `weyl_context_core_cold_dual_original`。来源记录语言层共有 244 处 `include_str!`，将 fixture 直接绑定到测试；这一数量描述的是所记录的源码快照。^[atlas-core-regression-library.md:20-22, atlas-core-regression-library.md:39-45]

## 会话全流程回归

`session_fixture_tests.rs` 包含 17 个经 `session::run_source` 全程执行的回归，将命令恢复、类型转换与求值一起覆盖。该模块刻意不保留已移除的动态求值器作为第二实现；相关说明见[[会话全流程回归测试]]，测试模块的整体组织见[[atlas-core 回归测试库的家族组织]]。^[atlas-core-regression-library.md:30-32]

## 验收证据与适用边界

[[HPC 验收证据链]]包括 `tests/reference/hpc/` 下的分阶段证据 JSON、只追加的验收账本 `tests/reference/hpc/math_acceptance_index_2026_10_01.json`，以及 `docs/HANDOFF.md` 中的衔接记录。知识库不改写该验收账本。^[atlas-core-regression-library.md:40-42]

来源仅完成 `session.rs`、`typed.rs`、`domain_builtins.rs` 与 `session_fixture_tests.rs` 四个测试模块的结构性阅读，不包含逐测试内容。单元与清单计数只标识 Git base `964f0033` 对应的快照字节；测试的可执行正确性以 HPC 门为准，例如 632 项清单与 `atlas-core-test-inventory`。来源明确不声称任何测试通过。^[atlas-core-regression-library.md:9-13, atlas-core-regression-library.md:43-45]
