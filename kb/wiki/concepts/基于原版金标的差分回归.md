# 基于原版金标的差分回归

基于原版金标的差分回归，是 atlas-core 语言层将 HPC 差分发现的差异固化为回归测试的方式。测试使用原版完整捕获的输出作为金标，并逐字节比较输出；金标不得由 Rust 输出生成。^[atlas-core-regression-library.md:20-22, atlas-core-regression-library.md:36-38]

## Fixture 与金标绑定

Fixture 与 `.oracle.*` 金标存放在 `tests/math/generics/`。`session.rs` 中的典型测试通过 `include_str!` 载入 fixture，逐字节比对 `.oracle.stdout` 和 `.oracle.stderr`，例如 `weyl_context_core_cold_dual_original`。源包记录语言层共有 244 处 `include_str!`，将 fixture 直接绑定到测试中。^[atlas-core-regression-library.md:20-22, atlas-core-regression-library.md:36-39]

每个 HPC 差分发现的差异都必须先在测试库中形成回归。金标必须来自原版的完整捕获，来源示例包括 Weyl A1 的 v8 冻结 goldens；这一来源约束是[[原版背书的语言层回归测试]]的组成部分。^[atlas-core-regression-library.md:36-38]

## 会话全流程覆盖

[[会话全流程回归测试]]通过 `session::run_source` 联合覆盖命令恢复、类型转换与求值。`session_fixture_tests.rs` 包含 17 个此类回归测试，并刻意不保留已移除的动态求值器作为第二实现。它们属于[[atlas-core 回归测试库的家族组织]]所描述的测试模块。^[atlas-core-regression-library.md:30-32]

## 验收证据与适用边界

[[HPC 验收证据链]]由 `tests/reference/hpc/` 下的分阶段证据 JSON、只追加的验收账本 `tests/reference/hpc/math_acceptance_index_2026_10_01.json`，以及 `docs/HANDOFF.md` 的衔接记录组成；知识库不改写该验收账本。^[atlas-core-regression-library.md:40-42]

源包仅完成测试模块的结构性阅读，不包含逐测试内容。单元与清单计数只标识 Git base `964f0033` 对应的快照字节；测试的可执行正确性以 HPC 门为准，例如 632 项清单与 `atlas-core-test-inventory`。这些结构与数量信息不能作为测试已通过的证据，源包也不声称任何测试通过。^[atlas-core-regression-library.md:9-13, atlas-core-regression-library.md:43-45]
