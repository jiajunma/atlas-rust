# 复型因子对与环面的名称表示

`form_name.rs` 在实形式的李代数命名中处理复型因子对与环面：内类字母 `'C'` 对应两个同构因子，以一个复李代数名称表示；单个环面因子按紧性输出 `u(1)` 或 `gl(1,R)`，复型环面对则输出 `gl(1,C)`。整体规则见 [[实形式的李代数命名规则]]。^[topology-form-name.md:59-73]

## 复型因子对

`form_type_name(layout, grading)` 按内类字母逐项处理。遇到 `'C'` 时，消费两个因子与对应的两段切片，并将第一个因子传给 `complex_name`。内类字母 `'C'` 表示复型配对，与根系类型 C 的用途不同。^[topology-form-name.md:59-61, topology-form-name.md:71-73]

`complex_name` 按下表生成名称，其中 \(n\) 或 `rank` 表示因子的秩，T 表示环面类型。^[topology-form-name.md:59-61]

| 因子类型 | 名称 |
|---|---|
| A | `sl(n+1,C)` |
| B | `so(2n+1,C)` |
| C | `sp(2n,C)` |
| D | `so(2n,C)` |
| E | `e{rank}(C)` |
| F | `f4(C)` |
| G | `g2(C)` |
| T | `gl(1,C)` |

## 环面名称与 grading 消费

单个 T 因子在紧情形下命名为 `u(1)`，否则命名为 `gl(1,R)`；复型配对分支中的 T 则命名为 `gl(1,C)`。环面因子不消费 grading 位。^[topology-form-name.md:59-73]

命名输入 grading 来自 `specialGrading` 的划分重载，是 datum 单根上的位集，其中 1 表示非紧虚根。对需要 grading 的普通根系因子，实现通过 `pulled[k] = grading[perm[k]]` 拉回到 Bourbaki 序，再逐因子消费切片。相关坐标约定见 [[specialGrading 的 Bourbaki 序拉回与因子切片]]。^[topology-form-name.md:50-55, topology-form-name.md:71-73]

## 实现边界

`form_type_name` 是公开接口，拒绝大于或等于 128 的 `perm` 位置，以符合 `u128` 位集宽度。内部 `factor_name` 的切片类型为 `u32`，假定单因子切片不超过 32 位；来源指出这一假定没有防护。某些对偶实形的对偶侧命名使用折叠小写字母 `'f'`、`'g'`，本移植不覆盖这两个分支。^[topology-form-name.md:70-73, topology-form-name.md:82-87]

## 测试与证据范围

来源列出的测试锚点包括复型因子对的 `sl(2,C)`，以及环面字母的 `u(1)`、`gl(1,R)`；未列出 `gl(1,C)` 的专门测试锚点。测试清单描述的是已有覆盖，不是本次执行结果。^[topology-form-name.md:75-78, topology-form-name.md:91-95]
