# 复型因子对与环面的名称表示

`form_name.rs` 在实形式的李代数命名中，分别处理复型因子对与环面因子：内类字母 `'C'` 覆盖两个同构因子，并用一个复李代数名称表示；单个环面因子则依紧性输出 `u(1)` 或 `gl(1,R)`。复型环面对的名称为 `gl(1,C)`。^[topology-form-name.md:59-73]

## 复型因子对

`form_type_name(layout, grading)` 按内类字母逐项处理因子。遇到 `'C'` 时，消费两个因子及对应的两段切片，并将第一个因子传给 `complex_name` 生成名称。这里的内类字母 `'C'` 表示复型配对，与下表中的根系类型 C 是不同用途的标记。^[topology-form-name.md:59-61, topology-form-name.md:71-73]

`complex_name` 的名称映射如下，其中 \(n\) 表示因子的秩；T 对应环面类型。^[topology-form-name.md:59-61]

| 因子类型 | 名称 |
|---|---|
| A | `sl(n+1,C)` |
| B | `so(2n+1,C)` |
| C | `sp(2n,C)` |
| D | `so(2n,C)` |
| E | `e{rank}(C)` |
| F | `f4(C)` |
| G | `g2(C)` |
| T | `gl(1,C)` |

## 环面名称与 grading 消费

单个 T 因子的命名规则是：紧环面输出 `u(1)`，否则输出 `gl(1,R)`。这与通过复型配对生成的 `gl(1,C)` 属于不同的命名分支。^[topology-form-name.md:59-69]

命名输入的 grading 来自 `specialGrading`，是 datum 单根上的位集，其中 1 表示非紧虚根。普通根系因子通过 `pulled[k] = grading[perm[k]]` 拉回到 Bourbaki 序，再逐因子切片；环面因子不消费 grading 位。相关坐标约定见 [[specialGrading 的 Bourbaki 序拉回与因子切片]]，整体命名规则见 [[实形式的李代数命名规则]]。^[topology-form-name.md:50-55, topology-form-name.md:71-73]

## 实现边界与证据

`form_type_name` 是公开接口；它拒绝大于或等于 128 的 perm 位置，以符合 `u128` 位集宽度。内部 `factor_name` 使用 `u32` 保存切片，假定单因子切片不超过 32 位，但源材料指出该假定没有防护。某些对偶实形命名使用的折叠小写字母 `'f'`、`'g'` 不在此移植范围内。^[topology-form-name.md:70-73, topology-form-name.md:82-87]

源材料列出的测试锚点包括复型因子对的 `sl(2,C)`，以及环面字母的 `u(1)`、`gl(1,R)`；未列出 `gl(1,C)` 的专门测试锚点。本页依据结构性源码阅读，不代表数学验收；本次知识维护未运行 Atlas、Cargo、测试或 benchmark。^[topology-form-name.md:75-78, topology-form-name.md:9-14, topology-form-name.md:91-95]
