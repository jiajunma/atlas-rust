# 完整块图的对偶数据变换

`BlockGraph::dual` 通过纯数据变换，得到同一对实形式角色互换后的完整块，对应上游 `Bare_block::dual`。完整块本身是实形式与对偶实形式的 KGB 图按 twisted involution 配对形成的纤维积；对偶化转换其元素编号、坐标、长度、下降状态及 cross/Cayley 链接。背景见 [[完整块的 KGB 纤维积]]。^[block-graph.md:17-24, block-graph.md:95-104]

## 元素编号、坐标与长度

设块大小为 \(N\)，原元素编号为 \(z\)。对偶化反转元素序，令 \(z'=N-1-z\)，并交换两侧 KGB 坐标：\(x'(z')=y(z)\)、\(y'(z')=x(z)\)。^[block-graph.md:95-97]

长度转换为 \(\ell'(z')=L-\ell(z)\)。非空块取 \(L=\ell(N-1)\)，依赖末元素长度最大的排序性质；空块取 \(L=0\)。原块中的长度是 primal KGB 长度，供 KL 表进行长度排序。^[block-graph.md:60-61, block-graph.md:97-99]

坐标交换后，`first_z_of_x` 按原块的 `max_y + 1` 范围重新计算。该表记录满足 \(x(z)\ge x\) 的首个块元素，长度为 `xrange + 1`，带有 size 哨兵；它与坐标定位都依赖 `xs` 弱增的不变量。参见 [[BlockGraph 存储布局与坐标定位不变量]]。^[block-graph.md:62-64, block-graph.md:102-102]

## 下降状态与链接

每个下降状态通过 `BlockDescent::dual` 转换：`ComplexAscent` 与 `ComplexDescent` 互换，`RealNonparity` 与 `ImaginaryCompact` 互换，`ImaginaryTypeI` 与 `RealTypeII` 互换，`ImaginaryTypeII` 与 `RealTypeI` 互换。完整状态约定见 [[BlockDescent 八值状态体系]]。^[block-graph.md:43-44, block-graph.md:99-100]

每条 cross/Cayley 链的目标编号 \(c\) 映射为 \(N-1-c\)。**Cayley 第二像仅在第一像有定义时映射**；双值 Cayley 对不重新排序。因此，与原生构造的对偶块比较时，两个 Cayley 像按无序集比较。^[block-graph.md:100-101]

直接 Cayley 与逆 Cayley 共用 `cayley_first`、`cayley_second` 存储槽，通过 weak descent 状态区分访问语义：`cayley` 在 weak descent 处返回 `Some((None, None))`；`inverse_cayley` 恰在 weak descent 处返回槽原值，在非 descent 处返回 `Some((None, None))`。内层 `None` 对应上游 `UndefBlock`。参见 [[块图的直接与逆 Cayley 变换]]。^[block-graph.md:58-60, block-graph.md:84-87]

完整块的 cross 链总有定义，这是它与部分公共块 `dual()` 的区别之一。上游标注为 “probably not right” 的 `orbits`、`dd` 字段没有 Rust 对应物。^[block-graph.md:102-104]

## 测试与证据边界

源材料列出的 7 个测试全部属于秩 1 的 A1 情形。对偶相关检查包括下降状态映射表及其对合性、元素反转、坐标互换和链接映射，以及经 `element` 换编号后与原生对偶块的一致性。在覆盖全 KGB 范围时，测试还检查 `dual().dual()` 为恒等，包括 `first_z_of_x` 表。^[block-graph.md:117-124]

测试未覆盖多生成元情形及两种平铺布局的区分、C±/rn/ic 块级状态、全部 20 个 `BlockInvariantViolation` 字面量分支、空对偶包与空块、`element` 失败分支以及 `n_bruhat_comparable`。详见 [[完整块图的测试覆盖与证据边界]]。^[block-graph.md:124-126]
