# 实形式的李代数命名规则

`form_name.rs` 为实形式生成李代数名称，公开接口为 `form_type_name(layout, grading)`，服务于 presentation 层。源材料将其描述为上游 `output::printType`、`print_real_form_name`、`printComplexType` 与 `split` 的移植；这一说明来自结构性源码阅读，不构成数学验收，所引用的上游代码字节也未独立核对。^[topology-form-name.md:10-14, topology-form-name.md:48-55, topology-form-name.md:82-87]

## 输入与因子处理

输入 grading 来自 `specialGrading` 的划分重载，是 datum 单根上的位集，其中 `1` 表示非紧虚根。命名前通过 `pulled[k] = grading[perm[k]]` 拉回到 Bourbaki 序，再逐因子消费对应切片。相关约定见 [[specialGrading 的分区代表与位集编码]] 与 [[specialGrading 的 Bourbaki 序拉回与因子切片]]。^[topology-form-name.md:50-55]

`form_type_name` 按内类字母处理因子：`'C'` 消费两个同构因子及两段 grading 切片；环面因子不消费 grading 位；其他因子在置换拉回切片后调用 `factor_name(bits, letter, rank, ic)`。其中 `m` 为最低置位的位置加一，平凡位集取 `m = 0`。^[topology-form-name.md:62-73]

## 名称生成规则

辅助函数 `split(name, n, m)` 在 `m == 0` 时生成单参数形式 `(n)`，否则将参数整理为弱递减的 `(n-minority, minority)`。例如，`su(1,2)` 会打印为 `su(2,1)`。^[topology-form-name.md:57-58]

### 经典型

A1 的平凡 grading 给出 `su(2)`，非平凡 grading 给出 `sl(2,R)`。更高秩 A 型包含 `su` 的参数分配规则；不等秩 A 型进入四元数分支须同时满足秩为奇数且 grading 平凡。测试锚点包括不等秩 A2 只有 `sl(3,R)`，以及不等秩 A3 的 `sl(2,H)`、`sl(4,R)`。^[topology-form-name.md:62-65, topology-form-name.md:75-76]

B 型按源材料记作 `so(2n+1, 2m)` 的规则处理。C 型在 `m == rank` 时生成 `sp(2n,R)`，否则采用 `sp(n,m)`。这些分派记法须结合辅助函数的参数整理规则理解。^[topology-form-name.md:57-58, topology-form-name.md:65-65]

D 型的等秩分支包含 `so*` 系列；源材料将 `[1,0]`／`[0,1]` 的选择概括为由 `rank % 4` 与 `m == rank` 的相等性条件决定。不等秩 D4 区分 `so(7,1)` 与 `so(5,3)`，任何非零 grading 都给出后者。^[topology-form-name.md:66-67]

### 例外型

E 型在 grading 平凡且满足“紧或 `rank > 6`”时生成裸名称 `e{rank}`。E6、E7 使用基于 `m` 的分派表；E8 使用 `0xCC` 掩码，对应 `e7.su(2)` 的非紧位 `{2,3,6,7}`。实现还包含 F、G 型分支，但源材料未展开其具体分派规则。^[topology-form-name.md:68-69]

## 复型与环面

复型条目 `'C'` 覆盖两个同构因子，`complex_name` 接收第一个因子，按下表生成名称。^[topology-form-name.md:59-61]

| 因子类型 | 复李代数名称 |
| --- | --- |
| A | `sl(n+1,C)` |
| B | `so(2n+1,C)` |
| C | `sp(2n,C)` |
| D | `so(2n,C)` |
| E | `e{rank}(C)` |
| F | `f4(C)` |
| G | `g2(C)` |
| T | `gl(1,C)` |

实环面因子 T 在紧情形下命名为 `u(1)`，否则为 `gl(1,R)`。折叠小写字母 `'f'`、`'g'` 仅用于某些对偶实形的对偶侧命名，本移植不覆盖。^[topology-form-name.md:69-70]

## 边界与测试证据

接口拒绝 `perm` 中大于等于 128 的位置，以符合 `u128` 位集宽度。内部 `factor_name` 使用 `bits: u32`，假定单因子切片不超过 32 位；源材料指出这一假定没有防护。^[topology-form-name.md:71-73, topology-form-name.md:85-86]

源材料列出七组测试锚点，覆盖 A1、A2、A3、复型 A1 对、B2、不等秩 D4 与环面。其中 B2 测试明确 datum 序中 bit 0 对应前长根，并得到 `so(3,2)`。E/F/G 与 `so*` 分支没有测试锚点。^[topology-form-name.md:75-78, topology-form-name.md:85-87]
