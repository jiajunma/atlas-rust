# 对偶实形式的分层计数管线

`dual_real_form_count` 是 `dual.rs` 中的公开自由函数，通过构造对偶内类、逐层建立纤维与 grading 数据，最终返回弱实形式分区的类数。代码注释将其对应到上游 `InnerClass::numDualRealForms`；来源仅作结构性阅读，未核对上游实现字节，也不构成计数数学正确性的验收。^[root-datum-dual.md:103-106, root-datum-dual.md:166-172, root-datum-dual.md:10-14]

## 固定构造顺序

计数函数按固定顺序执行：`dual_inner_class` → `CartanFiber::build` → `AdjointCartanFiber::build` → `CartanGradingData::build` → `WeakRealFormPartition::build` → `class_count()`。所有可失败阶段均通过 `?` 传播错误，前序构造失败时不会继续计算最终类数。相关数据层次见 [[CartanGradingData 与纤维来源一致性]]与 [[弱实形式的伴随 Cartan 纤维轨道划分]]。^[root-datum-dual.md:166-172]

## 对偶内类的构造

对偶根数据由 `dual_datum` 转置 Cartan 矩阵并互换简单根与简单余根，再调用 `BasedRootDatum::from_simple_data` 复用全部构造校验。接口保留可失败签名；来源不将“已校验根数据的对偶必然通过重校验”视为已验收结论。^[root-datum-dual.md:108-112]

设原 distinguished involution 的权作用矩阵为 \(q\)，最长 Weyl 元的作用矩阵为 \(W_0\)。辅助函数 `dual_involution` 先返回 \(M=qW_0\)，本身不取负或转置；`dual_inner_class` 再逐元素执行 `checked_neg`，构造对偶权作用 \(-M^t\) 与对偶余权作用 \(-M\)，最后通过 `LatticeInvolution::new` 和 `InnerClass::new` 完成构造。参见 [[对偶根数据与对偶内类构造]]。^[root-datum-dual.md:129-139]

## 预算与失败传播

预算分别约束最长元定位、对偶根系闭包、Cartan fiber、伴随 fiber 和弱实形式分区。其中，`weyl_budget` 只管理最长元定位，`root_budget` 约束对偶根系闭包；各阶段的错误均向计数函数调用者传播。^[root-datum-dual.md:138-139, root-datum-dual.md:166-172]

最长元定位使用将 \(2\rho\) 送到 \(-2\rho\) 的下坡行走：按生成元升序选取第一个与当前权具有正余根配对的反射，左合成并更新当前权。预算允许恰好 `weyl_budget` 步；超过预算或某轮无法推进时，返回 `StructureError::LayoutInvariantViolation { invariant: "longest Weyl element" }`。这一前置阶段的失败会阻止后续纤维构造，详见 [[最长 Weyl 元的下坡行走]]。^[root-datum-dual.md:114-125, root-datum-dual.md:166-172]

## 测试锚点与证据边界

来源照录的计数断言包括：单连通（sc）A1 为 2，伴随（adjoint）A1 为 2，等秩紧 A2 为 1，扭 A2 为 2，紧 B2 为 3。等秩紧 A2 的对偶被描述为拟分裂伴随 A2，唯一形式为 `PSL(3,R)`；紧 B2 的说明使用 \(w_0=-1\)，指出紧与分裂内类两侧重合。^[root-datum-dual.md:174-178]

这些数值是既有测试断言的记录，并非本次知识维护重新运行测试所得的结果。来源没有定义各 fiber 类型的内部算法，也未验收对偶实形式计数的数学正确性；此次维护未执行 Atlas、Cargo、测试或 benchmark。^[root-datum-dual.md:209-216]
