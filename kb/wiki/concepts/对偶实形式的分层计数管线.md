# 对偶实形式的分层计数管线

`dual_real_form_count` 是 `dual.rs` 中的公开自由函数，通过对偶内类、纤维和 grading 数据的分层构造，最终返回弱实形式分区的类数。代码注释将其对应到上游 `InnerClass::numDualRealForms`；来源未核对上游实现字节，该对应关系属于注释记录。^[root-datum-dual.md:103-106, root-datum-dual.md:166-172, root-datum-dual.md:10-14]

## 固定构造顺序

计数管线依次执行 `dual_inner_class` → `CartanFiber::build` → `AdjointCartanFiber::build` → `CartanGradingData::build` → `WeakRealFormPartition::build` → `class_count()`。所有可失败阶段均通过 `?` 传播错误，前序构造失败便停止当前计数。相关概念见 [[CartanGradingData 与纤维来源一致性]]与 [[弱实形式的伴随 Cartan 纤维轨道划分]]。^[root-datum-dual.md:166-172]

## 对偶内类的前置构造

`dual_datum` 转置 Cartan 矩阵、互换简单根与简单余根，再调用 `BasedRootDatum::from_simple_data` 复用全部构造校验。即使输入根数据已经校验，对偶构造仍保留可失败接口；来源不将重校验必然成功视为已验收结论。^[root-datum-dual.md:108-112]

设原 distinguished involution 的权作用矩阵为 \(q\)，最长 Weyl 元的作用矩阵为 \(W_0\)。辅助函数 `dual_involution` 返回 \(M=qW_0\)，本身不取负或转置；`dual_inner_class` 随后逐元素执行 `checked_neg`，构造对偶权作用 \(-M^t\) 与对偶余权作用 \(-M\)，最后经 `LatticeInvolution::new` 和 `InnerClass::new` 完成构造。详见 [[对偶根数据与对偶内类构造]]。^[root-datum-dual.md:129-139]

## 预算与失败行为

预算依次分配给最长元定位、对偶根系闭包、Cartan fiber、伴随 fiber 和弱实形式分区。其中，`weyl_budget` 只约束最长元定位，`root_budget` 约束对偶根系闭包；计数管线通过 `?` 将各阶段错误传给调用者。^[root-datum-dual.md:138-139, root-datum-dual.md:166-172]

最长元定位采用把 \(2\rho\) 送到 \(-2\rho\) 的下坡行走：按生成元升序选择第一个与当前权具有正余根配对的反射，左合成并更新当前权。允许恰好执行 `weyl_budget` 步；若步数超过预算或某轮无法推进，则返回 `StructureError::LayoutInvariantViolation { invariant: "longest Weyl element" }`。参见 [[最长 Weyl 元的下坡行走]]。^[root-datum-dual.md:114-125]

## 测试锚点

来源照录的对偶实形式计数断言为：单连通（sc）A1 为 2，伴随（adjoint）A1 为 2，等秩紧 A2 为 1，扭 A2 为 2，紧 B2 为 3。来源将等秩紧 A2 的对偶描述为拟分裂伴随 A2，其唯一形式为 `PSL(3,R)`；紧 B2 的说明使用 \(w_0=-1\)，指出紧与分裂内类两侧重合。^[root-datum-dual.md:174-178]

`dual_cartan_correspondence` 提供另一层输出：按原分类的 Cartan 顺序，为每个类返回对偶 `CartanId` 及对偶类的弱实形式计数。单连通 A1 的对应表断言为 `[(CartanId(1), 1), (CartanId(0), 2)]`，并以 oracle capture `3501500` 锚定；这一逐 Cartan 类的对应表应与 `dual_real_form_count` 最终返回的分区类数区分。^[root-datum-dual.md:141-154, root-datum-dual.md:166-180]

## 证据边界

本页依据 `root_datum.rs` 与 `dual.rs` 的结构性阅读。各 fiber 类型的内部定义不在来源包范围内；来源未验收对偶实形式计数的数学正确性，也未验收最长元行走的复杂度声明。上述数值是既有测试断言的记录，本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[root-datum-dual.md:9-14, root-datum-dual.md:174-182, root-datum-dual.md:209-216]
