# 对偶根数据与对偶内类构造

对偶构造由 `dual.rs` 中的自由函数实现：`dual_datum` 构造对偶根数据，`dual_inner_class` 构造对偶内类，配套函数负责最长 Weyl 元定位、Cartan 类对应及对偶实形式计数。根数据由 [[BasedRootDatum：带基根数据与构造不变量]] 承载，区分整个格的秩 `lattice_rank` 与简单根个数 `semisimple_rank`。^[root-datum-dual.md:18-25]

## 对偶根数据与构造校验

`dual_datum` 转置 Cartan 矩阵，并交换简单根与简单余根，最后调用 `BasedRootDatum::from_simple_data`。对偶构造因此复用全部构造校验，接口保持可失败语义；来源未将“已校验 datum 的对偶必然通过重校验”作为已验收结论。^[root-datum-dual.md:108-112]

构造校验顺序固定：先验证 Cartan 矩阵，再检查格秩不小于半单秩、简单根与余根的数量、各向量的维数，最后逐项验证根与余根的配对等于对应 Cartan 元素。秩或数量不符返回 `RankMismatch`，配对不符返回带行列位置及预期、实际值的 `RootPairingMismatch`。^[root-datum-dual.md:39-46]

构造允许 `lattice_rank > semisimple_rank` 的中心环面情形，也允许空 Cartan 矩阵配合正格秩表示纯环面。`standard(cartan)` 则以单位坐标向量作为简单根、Cartan 矩阵的列作为简单余根，因此其格秩与半单秩相等。^[root-datum-dual.md:48-51]

## 最长 Weyl 元定位

对偶内类构造使用 `longest_action` 定位最长 Weyl 元的作用 \(W_0\)。函数旨在返回把 \(2\rho\) 送到 \(-2\rho\) 的 `WeylAction`：按生成元升序选择第一个与当前权具有正余根配对的简单反射，左合成并更新当前权。这一过程采用 [[最长 Weyl 元的下坡行走]]，不枚举全部群元素。^[root-datum-dual.md:114-125]

行走允许恰好 `weyl_budget` 步；超过预算或无法推进时，返回 `StructureError::LayoutInvariantViolation`，不变量名称为 `"longest Weyl element"`。`two_rho` 只累加 `is_positive(id) == Some(true)` 的根，使用带检查的 `i64` 加法并逐坐标转换为 `i32`；行走内层配对却采用未检查的 `i64` 累加，来源将这一差异列为待核对事项。^[root-datum-dual.md:116-127]

## 对偶内类的格作用

记 distinguished involution 的权作用矩阵为 \(q\)，最长元的矩阵为 \(W_0\)。辅助函数 `dual_involution` 只计算乘积 \(M=qW_0\)，本身不取负、不转置；`dual_inner_class` 才将对偶权作用设为 \(-M^t\)，对偶余权作用设为 \(-M\)。代码注释以 \(M\) 是对合解释余权作用的推导。^[root-datum-dual.md:129-137]

实现逐元素执行 `checked_neg`，按 `dual_weight[column][row] = -product[row][column]` 填入权作用，按 `dual_coweight[row][column] = -product[row][column]` 填入余权作用，再依次通过 `LatticeInvolution::new` 与 `InnerClass::new(dual, involution, root_budget)` 完成构造。相关类型见 [[格对合（LatticeInvolution）]]。^[root-datum-dual.md:134-139]

预算职责分开：`weyl_budget` 只约束最长元定位，`root_budget` 约束对偶根系闭包，不能将其中一个预算理解为整个对偶构造的统一规模上限。^[root-datum-dual.md:138-139]

## Cartan 类对应与代表元重放

`dual_cartan_correspondence` 按原分类的 crate Cartan 顺序，为每个类输出“对偶 `CartanId`、对偶类的弱实形式计数”。它先检查两侧 fundamental 的存在性与 datum 一致性，再通过具有来源校验的 `TwistedConjugacyPartition::class_of` 建立反查表；找不到对应类是不变量错误，而不是可容许的缺失。^[root-datum-dual.md:141-155]

查找键采用格映射在对偶根上诱导的根像置换。代码注释解释，对偶 twisted involution 会经过规范化，其存储代表元一般是 `tw * w0` 的共轭，因此直接比较代表元矩阵不可靠。公开参数 `_weyl_budget` 是未使用的遗留参数，此处最长元行走实际使用对偶根系已枚举的根数作为预算。该数学解释属于代码注释，来源未独立验证；详见 [[跨对偶的 Cartan 类对应与扭曲代表元]]。^[root-datum-dual.md:147-154]

内部函数 `dual_twisted_representative` 经 `WeylElement::from_action` 与 `canonical_word` 提取原代表元的规范 Weyl 字，使用原 datum 的 Cartan 构造 `WeylInterface`，再在对偶 datum 上逐生成元重放。最后左合成最长元，并结合对偶 distinguished involution 构造 `TwistedInvolution`；这一路径保留两种格作用及 distinguished involution 的来源信息。^[root-datum-dual.md:157-164]

## 对偶实形式计数

`dual_real_form_count` 采用固定管线：`dual_inner_class` → `CartanFiber::build` → `AdjointCartanFiber::build` → `CartanGradingData::build` → `WeakRealFormPartition::build` → `class_count()`。各阶段以 `?` 传播错误，预算分别覆盖最长元、对偶根系、Cartan fiber、伴随 fiber 与弱实形式分区；详见 [[对偶实形式的分层计数管线]]。^[root-datum-dual.md:166-172]

## 测试锚点与证据边界

来源记录的测试断言包括：单连通 A1 与伴随 A1 的对偶实形式计数均为 2，等秩紧 A2 为 1，扭 A2 为 2，紧 B2 为 3。A2 单位 involution 的 `dual_involution` 结果为 \(\begin{pmatrix}0&-1\\-1&0\end{pmatrix}\)；该值是辅助函数返回的乘积矩阵，尚未执行对偶内类构造中的取负与转置。^[root-datum-dual.md:131-137, root-datum-dual.md:174-179]

单连通 A1 的 Cartan 对应表为 `[(CartanId(1), 1), (CartanId(0), 2)]`，来源记录 oracle capture `3501500` 为锚点。紧 B2 的对应表长度为 4，首条计数为 1，全格 \(-1\) involution 类计数为 3，对偶 `CartanId` 集合恰为 \(\{0,1,2,3\}\)。^[root-datum-dual.md:179-182]

本说明依据结构性源码阅读及测试断言记录，不构成根数据层或对偶构造的数学验收。来源中的上游 C++ 引用转录自代码注释，未核对上游字节；本次维护也未执行 Atlas、Cargo、测试或 benchmark。最长元复杂度、`two_rho` 与 \(2\rho\) 的恒等以及对偶实形式计数的数学正确性，均未由该材料独立验收。^[root-datum-dual.md:9-14, root-datum-dual.md:204-216]
