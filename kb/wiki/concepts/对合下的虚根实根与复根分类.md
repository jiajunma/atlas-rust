# 对合下的虚根、实根与复根分类

`RootInvolutionData` 在枚举根系上验证根置换与余根运输，并将根分为虚根（`Imaginary`）、实根（`Real`）和复根（`Complex`）。底层 `LatticeInvolution` 只保证格作用是保持配对的对合；保持有限根系及正确运输余根的条件由 `RootInvolutionData` 建立。^[involution-types.md:63-65, involution-types.md:82-92]

## 分类规则

设对合为 $\theta$，根为 $\alpha$。实现先判断 $\theta(\alpha)=\alpha$，成立则归为虚根；否则判断 $\theta(\alpha)=-\alpha$，成立则归为实根；其余情况归为复根。此判断顺序固定，负根坐标通过逐坐标 `checked_neg` 计算。^[involution-types.md:86-92]

## 构造前提与错误顺序

`RootInvolutionData::new(&RootSystem, LatticeInvolution)` 首先检查 datum 一致性与秩，然后验证单根像，最后遍历全部根。除了要求每个根的像仍是根，还要求每个存储余根被运输到像根对应的余根。后一个条件排除了“固定所有根却移动余根中心环面坐标”的作用；仅有配对保持不足以排除这种情况。^[involution-types.md:39-39, involution-types.md:82-91]

错误优先级为 `DatumMismatch` → `RankMismatch` → 单根级错误 → 主循环错误。单根级错误包括 `SimpleRootImageNotRoot { simple_root }` 和 `SimpleCorootImageMismatch { simple_root, image_root }`；主循环中，像非根报 `InvalidRootAutomorphism`，余根运输不符报 `InvalidRootDatumAutomorphism`。参见 [[对合类型的分层构造验证与错误优先级]]。^[involution-types.md:86-91]

构造器不独立检查根置换的平方是否为单位，而是依赖 `LatticeInvolution` 的代数对合校验。底层分别验证权格作用与余权格作用平方为单位，再检查配对保持条件 $W^{T}C=I$。^[involution-types.md:67-71, involution-types.md:144-145]

## 虚根与实根子系统的单根

`subsystem_simple_roots` 分别处理虚根与实根，取该类中简单坐标全非负的根，从而继承原根系的正系。候选按 `RootId` 升序处理；来源将筛选条件描述为：候选若可分解为集合内另一成员与某正坐标向量的差，则跳过，否则入选。最终单根列表也按 `RootId` 升序输出，测试锚定了具体顺序。^[involution-types.md:94-97]

## 查询接口

`image(root)` 返回对合下的根像，`kind(root)` 返回类别；两者遇到越界 `RootId` 均返回 `None`，不会 panic。`image_permutation()` 提供完整根像列表，`roots_of_kind(kind)` 按 `RootId` 升序惰性遍历指定类别的根。`imaginary_simple_roots()` 与 `real_simple_roots()` 分别返回虚根和实根子系统的单根列表。^[involution-types.md:40-46, involution-types.md:99-100]

## 测试锚点

A2 上的负反对角对合给出 2 个实根、4 个复根、0 个虚根，实根子系统单根为 `[id_of([1,1])]`。恒等对合下所有根均为虚根，虚根子系统单根按枚举序为 `[id_of([0,1]), id_of([1,0])]`。^[involution-types.md:123-125]

另有测试中的作用通过 `LatticeInvolution::new` 的配对保持与对合校验，却因不置换根而在 `RootInvolutionData::new` 中触发 `SimpleRootImageNotRoot { simple_root: 0 }`。正、负单根对应的余根运输错误分别触发 `SimpleCorootImageMismatch`，体现了根数据自同构校验比格上的配对保持更强。^[involution-types.md:126-129]
