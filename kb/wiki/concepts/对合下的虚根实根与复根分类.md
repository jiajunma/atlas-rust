# 对合下的虚根、实根与复根分类

`RootInvolutionData` 在枚举根系上验证对合的根置换及余根运输，并将根分为虚根（`Imaginary`）、实根（`Real`）与复根（`Complex`）。底层 `LatticeInvolution` 只保证格上的配对保持与对合性质，保持有限根系的更强条件由 `RootInvolutionData` 建立。^[involution-types.md:13-15, involution-types.md:63-65, involution-types.md:82-84]

## 分类规则

设对合为 \(\theta\)，根为 \(\alpha\)。实现依次判断：若 \(\theta(\alpha)=\alpha\)，则为虚根；否则，若 \(\theta(\alpha)=-\alpha\)，则为实根；其余情况为复根。判定优先级固定，负根坐标通过逐项 `checked_neg` 计算。^[involution-types.md:86-92]

## 构造前提与错误顺序

构造器首先检查 datum 一致性与秩，再验证单根像，最后遍历全部根。它要求每个根的像仍是根，并要求每个存储余根被运输到像根对应的余根。余根运输检查排除了“固定所有根却移动余根中心环面坐标”的作用；仅有配对保持无法排除这种情况。^[involution-types.md:82-91]

错误顺序是 `DatumMismatch` → `RankMismatch` → 单根级错误 → 主循环错误。单根级错误包括 `SimpleRootImageNotRoot { simple_root }` 与 `SimpleCorootImageMismatch { simple_root, image_root }`；主循环中，像非根报 `InvalidRootAutomorphism`，余根运输不符报 `InvalidRootDatumAutomorphism`。相关设计见 [[对合类型的分层构造验证与错误优先级]]。^[involution-types.md:86-91]

根置换是否平方为单位没有独立检查，而是依赖 `LatticeInvolution` 的代数门控：权格与余权格作用分别平方为单位，并满足配对保持条件 \(W^{T}C=I\)。^[involution-types.md:67-71, involution-types.md:144-145]

## 虚根与实根子系统的单根

`subsystem_simple_roots` 分别处理虚根与实根。它选取该类中简单坐标全非负的根，继承原根系的正系，并按 `RootId` 升序处理候选。来源将筛选条件描述为：候选若可分解为集合内另一成员与某正坐标向量的差，则跳过，否则入选。最终子系统单根也按 `RootId` 升序输出，测试锚定了具体顺序。^[involution-types.md:94-97]

## 查询接口

`image(root)` 返回根在对合下的像，`kind(root)` 返回根的类别；两者对越界 `RootId` 均返回 `None`，不会 panic。`image_permutation()` 提供完整根像列表，`roots_of_kind(kind)` 按 `RootId` 升序惰性遍历指定类别的根。`imaginary_simple_roots()` 与 `real_simple_roots()` 分别提供虚根和实根子系统的单根列表。^[involution-types.md:39-46, involution-types.md:99-100]

## 测试锚点与证据边界

A2 的负反对角对合测试给出 2 个实根、4 个复根、0 个虚根，实根子系统单根为 `[id_of([1,1])]`。恒等对合下所有根均为虚根，虚根子系统单根按枚举序为 `[id_of([0,1]), id_of([1,0])]`。^[involution-types.md:123-125]

另有测试验证配对保持与根数据自同构之间的区别：某作用通过 `LatticeInvolution::new`，却因不置换根而在 `RootInvolutionData::new` 中触发 `SimpleRootImageNotRoot { simple_root: 0 }`；正、负单根相关的余根运输错误则触发 `SimpleCorootImageMismatch`。^[involution-types.md:126-129]
