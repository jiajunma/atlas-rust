# 对合下的虚根、实根与复根分类

`RootInvolutionData` 在枚举根系上建立对合的根置换，并将根分为虚根（`Imaginary`）、实根（`Real`）与复根（`Complex`）。它以 [[格对合（LatticeInvolution）]] 为基础，进一步验证根的像与余根运输；格上的配对保持本身不足以保证根数据自同构。^[involution-types.md:13-15, involution-types.md:63-65, involution-types.md:82-84]

## 分类规则

设对合为 \(\theta\)，根为 \(\alpha\)。实现首先判断 \(\theta(\alpha)=\alpha\)，成立则归为虚根；否则判断 \(\theta(\alpha)=-\alpha\)，成立则归为实根；其余情况归为复根。负根坐标通过逐项 `checked_neg` 计算，判定优先级固定。^[involution-types.md:86-92]

## 构造前提与错误顺序

[[根对合数据（RootInvolutionData）|RootInvolutionData]] 的构造首先检查 datum 一致性与秩，再验证单根的像，最后遍历全部根。每个根的像必须仍是根，每个存储余根也必须被运输到像根对应的余根。余根运输条件排除了“固定所有根却移动余根中心环面坐标”的作用，这类作用可能通过配对保持检查。^[involution-types.md:82-91]

错误按阶段报告：`DatumMismatch` 先于 `RankMismatch`；单根阶段的 `SimpleRootImageNotRoot` 与 `SimpleCorootImageMismatch` 先于主循环中的 `InvalidRootAutomorphism` 与 `InvalidRootDatumAutomorphism`。这一顺序属于 [[对合类型的分层构造验证与错误优先级]]。^[involution-types.md:86-91]

构造器不独立检查根置换本身是否平方为单位，而是依赖底层 `LatticeInvolution` 的代数门控：权格与余权格作用各自平方为单位，且两者满足配对保持条件 \(W^{T}C=I\)。^[involution-types.md:67-71, involution-types.md:144-145]

## 虚根与实根子系统的单根

实现分别为虚根和实根计算子系统单根。它选取该类中简单坐标全非负的根，继承原根系的正系，并按 `RootId` 升序处理候选；按来源所述，候选若可分解为集合内另一成员与某正坐标向量的差，则跳过，否则入选。输出也按 `RootId` 升序排列，相关主题见 [[继承正系中的子系统单根提取]]。^[involution-types.md:94-97]

## 查询接口

`image(root)` 查询对合下的根像，`kind(root)` 查询根的分类；两者遇到越界 `RootId` 均返回 `None`，不会 panic。`image_permutation()` 提供完整根像列表，`roots_of_kind(kind)` 按 `RootId` 升序惰性枚举指定类别的根。`imaginary_simple_roots()` 与 `real_simple_roots()` 分别返回虚根和实根子系统的单根列表。^[involution-types.md:39-46, involution-types.md:99-100]

## 测试锚点与证据边界

在 A2 测试中，负反对角对合产生 2 个实根、4 个复根和 0 个虚根，实根子系统单根为 `[id_of([1,1])]`。恒等对合下所有根均为虚根，虚根子系统单根按枚举顺序为 `[id_of([0,1]), id_of([1,0])]`。^[involution-types.md:123-125]

另有测试展示配对保持但不置换根的作用：它通过 `LatticeInvolution::new`，却在 `RootInvolutionData::new` 中触发 `SimpleRootImageNotRoot { simple_root: 0 }`。余根运输错误则在正、负单根相关测试中触发 `SimpleCorootImageMismatch`。^[involution-types.md:126-129]

这些记录来自结构性源码阅读与测试断言转录，不构成数学验收；来源中的上游引用仅转录自代码文档注释，未核对上游字节。本次知识维护未执行 Atlas、Cargo、测试或 benchmark，且所列测试未覆盖 `image()` 与 `kind()` 的越界 `None` 路径。^[involution-types.md:9-15, involution-types.md:138-141, involution-types.md:149-156]
