# 对合查表实现的证据范围与测试缺口

对合查表实现的现有证据来自对 `crates/atlas-real-group/src/primitive_involution.rs`（529 行）的结构性阅读。源包草案经维护者对照源码逐条核对改写，但不构成数学或正确性验收；上游行号仅转录自代码文档注释，未独立核对上游文件字节。本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[primitive-involution.md:9-13, primitive-involution.md:134-134, primitive-involution.md:145-149]

## 实现范围

该模块服务于 primitive `involution(LieType,[int],string)` 与 `involution(LieType,mat,string)` 包装器，涵盖内类字母解析与坍缩、单连通群基本权基上的逐字母对合表，以及精确换基。模块定位为纯表实现，不涉及 root datum、Weyl group 或 inner-class 管线；用户提供的 Bourbaki 重编号 `perm` 由包装器侧验证。相关概念见 [[内类字母的字节解析与规范化]]、[[单连通群基本权基上的逐字母对合表]] 与 [[Bourbaki 重编号与对合矩阵下标映射]]。^[primitive-involution.md:17-25]

## 已有测试锚点

源包记录六个测试，断言涉及字母规范化、对合矩阵与换基结果。这些记录说明源码中的覆盖范围，不是本次运行通过的验证结果。^[primitive-involution.md:46-48, primitive-involution.md:115-130, primitive-involution.md:145-149]

### 字母解析与诊断顺序

`'s'` 的断言覆盖坍缩为 `'c'` 的 A1、B2、C3、D4、D6、E7、E8、F4、G2，以及保留 `'s'` 的 A2、A5、D5、E6、T1。`'u'` 的断言覆盖 D4/D6 中保留、A2/D5/E6/T1 中转为 `'s'`，以及 A1、B2、C2、E7、F4、G2 中报 `MeaninglessUnequalRank`；还检查了精确文案 `Unequal rank class is meaningless for type A1`。^[primitive-involution.md:117-121]

解析时先检查符号是否属于 `"Ccesu"`，再检查是否还有可用因子。测试注释明确固定“未知符号先于因子计数报告”的规则，属于 [[内类字母解析的错误模型与诊断顺序]] 的兼容约定。^[primitive-involution.md:71-72]

### 对合矩阵与重编号

矩阵断言覆盖 A1 的恒等阵、A2 的交换阵、B2 的恒等阵、两个 A1 因子的 `'C'` 互换、D4 的 `'u'` 与 `'s'` 差异、D5 的末两顶点交换、E6 的指定顶点交换，以及 T1 的负恒等阵。重编号锚点包括 A2 在 `perm [1,0]` 下结果不变，以及 `[A1,A2]` 配合 `"cs"`、`perm [2,0,1]` 的表输出。^[primitive-involution.md:122-127]

### 精确换基

对于 A2 翻转阵，`on_basis` 在基 \(\begin{pmatrix}1&0\\1&1\end{pmatrix}\) 上返回矩阵 \(\begin{pmatrix}1&1\\0&-1\end{pmatrix}\) 的 `Some` 值，在基 \(\begin{pmatrix}1&0\\0&2\end{pmatrix}\) 上因结果非整而返回 `None`。其他锚点包括 A1 单位阵在偶子格基 \(\begin{pmatrix}2\end{pmatrix}\) 上保持不变、奇异基返回 `None`，以及单位阵在任意可逆基上不变。^[primitive-involution.md:128-130]

## 前置条件与失败语义

`layout_involution` 要求 `letters` 来自 `checked_inner_class_letters`，且 `perm` 是 `0..rank` 的排列。函数不返回 `Result`，依靠文档前提和两道 `debug_assert_eq!` 检查排列长度及最终累计秩；违反前提可能导致下标越界 panic 或进入 `unreachable!`。这些检查并不提供完整的运行时输入校验。^[primitive-involution.md:86-91]

遵守解析前提时，B、C、E7、E8、F、G 上的 `'s'` 已坍缩为 `'c'`，查表中的对应默认分支不可达，仅对绕过解析的输入起防御作用。源包还将 `rs >= 2` 列入前置条件限制，并指出绕过检查的输入可能进入防御分支或 panic。^[primitive-involution.md:135-139]

`on_basis` 计算 \(B^{-1}MB\)，将非方阵、奇异基、非整结果和 `i32` 转换失败统一折叠为 `None`，包装器再将失败重标为不兼容格。调用方无法从返回值区分四类原因；记录中的非整结果与奇异基断言仅覆盖部分失败路径，相关接口约定见 [[换基失败的统一不兼容格语义]]。^[primitive-involution.md:104-113, primitive-involution.md:128-130]

## 明确的测试缺口

源包明确列出四项未覆盖面：`TooManySymbols` 与 `TooFewSymbols` 的 `Display` 文案、`on_basis` 的非方阵早退分支、`'C'` 在非恒等 `perm` 下的行为，以及退化空输入。这里对两个计数错误指出的缺口是诊断文案，不能扩大表述为其所有行为均未测试。^[primitive-involution.md:140-141]
