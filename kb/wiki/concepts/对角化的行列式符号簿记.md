# 对角化的行列式符号簿记

`matreduc::diagonalise` 的行列式符号簿记记录整数矩阵对角化过程中的符号变化，是[[整数矩阵算法的逐操作保真移植]]的一部分。对输入矩阵 `m`，函数返回幺模矩阵 `row`、`col` 及对角元素 `diagonal`，使 `row * m * col` 为对角矩阵，且除首项外的对角元素均为正。空形状 \(0\times n\) 或 \(n\times0\) 提前返回。^[matreduc.md:20-33]

## 精确复现的动机

欠定整数系统 \(Ax=b\) 的被选解在下游可观测：\(\tau\) 与 \(t\) 坐标的奇偶性会进入 `ext_block::same_sign`。因此，移植需要复现上游 C++ 的确切幺模操作序列及行列式符号簿记。算术采用 wrapping `i32`，来源也将溢出行为域列为被选解兼容性的一部分。^[matreduc.md:20-26]

## gcd 中的局部符号变化

`gcd(row, &mut flip, dest)` 以 `wrapping_abs` 选择最小绝对值主元。负主元取正时翻转 `flip`，并在记录矩阵中设置 `col.set(mindex, mindex, -1)`；末尾将主元列交换到 `dest` 时也翻转 `flip`。消元使用正除数下的下取整除法 `divide`，其负数分支避免直接对 `i32::MIN` 取负，详见[[整数消元中的下取整除法与 gcd 主元选择]]。^[matreduc.md:37-41]

## 对角化中的累计顺序

每列首次 gcd 的 `flip` 对 `row_minus` 使用**覆盖赋值**。随后，内层循环交替执行行、列 gcd，将 `flip` 分别通过 `^=` 累计到 `col_minus`、`row_minus`。覆盖与异或的区别属于需要保留的操作细节。^[matreduc.md:42-44]

内层循环退出后，再执行一次 `row_minus ^= flip`。若从行 gcd 的 `break` 退出，该次 `flip` 会计入两侧；若从列 gcd 的 `break` 退出，其对 `row_minus` 的净效果抵消。^[matreduc.md:44-45]

主元列未左对齐时，算法通过稳定排列 `pull_back_columns` 调整列位置，并异或计入排列符号，即逆序对数量的奇偶性。最后，若 `row_minus != col_minus`，则将 `diagonal[0]` 取负；`row_minus`、`col_minus` 分别通过第 0 行、第 0 列乘以 \(-1\) 进行归一处理。^[matreduc.md:45-49]

## 行列式约定与测试锚点

源码注释对最终行列式保证存在不一致：一处写作 “ensure det(row)=1”，测试注释则说明上游只强制 `det(col) == 1`，而 `det(row)` 可以为 \(-1\)。来源明确以测试为准；11 个重构用例检查 \(|\det(\text{row})|=1\)、\(\det(\text{col})=1\)、逐项对角结果一致，以及首项之外为正。^[matreduc.md:48-49, matreduc.md:69-70]

`oracle_reference_cases` 保留了来自 C++ oracle 的精确结果：`[[0,5],[0,0]]` 对应 `diagonal [-5]` 及确切的 `row`、`col`，`[[-4]]` 对应 `[-4]`。另一个 \(6\times6\) 秩亏且主元列未左对齐的案例固定了完整变换矩阵，以及被选解 `[6,14,5,-37,-421,345]`。这些锚点同时约束首项负号和具体变换结果，相关背景见[[整数矩阵移植的 oracle 回归锚点与证据边界]]。^[matreduc.md:71-74]
