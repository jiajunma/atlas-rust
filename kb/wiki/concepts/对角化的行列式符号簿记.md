# 对角化的行列式符号簿记

`matreduc::diagonalise` 的行列式符号簿记用于复现上游整数矩阵约化的确切操作序列。对输入矩阵 \(m\)，它返回幺模矩阵 `row`、`col` 与对角元素 `diagonal`，使 `row * m * col` 为对角矩阵，且除首项外的对角元素均为正。空形状 \(0\times n\) 或 \(n\times0\) 提前返回。^[matreduc.md:30-33]

## 为什么需要精确复现

欠定整数系统 \(Ax=b\) 的被选解在下游可观测：\(\tau\) 与 \(t\) 坐标的奇偶性会进入 `ext_block::same_sign`。因此，移植目标不仅是得到一个正确解，还包括复现 C++ 的幺模操作序列及其行列式符号簿记。算术采用 wrapping `i32`；来源将溢出行为域也列为被选解兼容性的一部分。^[matreduc.md:20-26]

## gcd 操作中的符号记录

`gcd(row, &mut flip, dest)` 使用 `wrapping_abs` 选择最小绝对值主元。负主元取正时翻转 `flip`，并在记录矩阵中设置 `col.set(mindex, mindex, -1)`；末尾将主元列交换到 `dest` 时也翻转 `flip`。消元使用正除数下的向下取整除法 `divide`，其负数分支避免对 `i32::MIN` 直接取负。^[matreduc.md:37-41]

## 对角化中的累计顺序

每列首次 gcd 返回的 `flip` 对 `row_minus` 采用**覆盖赋值**。随后内层循环交替执行行、列 gcd，分别将 `flip` 通过异或赋值 `^=` 累计到 `col_minus`、`row_minus`。这些赋值方式与先后顺序都是逐操作移植的一部分。^[matreduc.md:42-44]

内层循环退出后，还会执行一次 `row_minus ^= flip`。若从行 gcd 的 `break` 退出，该次 `flip` 会计入两侧；若从列 gcd 的 `break` 退出，其对 `row_minus` 的净效果抵消。^[matreduc.md:44-45]

当主元列未左对齐时，算法通过稳定排列 `pull_back_columns` 调整列位置，并异或计入该排列的符号，即逆序对数量的奇偶性。最后，若 `row_minus != col_minus`，则将 `diagonal[0]` 取负；`row_minus`、`col_minus` 分别通过第 0 行、第 0 列乘以 \(-1\) 进行归一处理。^[matreduc.md:45-49]

## 行列式约定与测试锚点

源码注释对最终行列式约定存在不一致：一处写作 “ensure det(row)=1”，测试注释则说明上游只强制 `det(col) == 1`，而 `det(row)` 可以为 \(-1\)。来源明确以测试为准；重构测试检查的是 \(|\det(\text{row})|=1\)、\(\det(\text{col})=1\)、对角结果一致以及首项之外为正。^[matreduc.md:48-49, matreduc.md:69-70]

`oracle_reference_cases` 包含来自 C++ oracle 的精确锚点：矩阵 `[[0,5],[0,0]]` 对应 `diagonal [-5]` 及确切的 `row`、`col`；矩阵 `[[-4]]` 对应 `[-4]`。另有一个 \(6\times6\) 秩亏、主元列未左对齐的案例，固定完整变换矩阵及被选解 `[6,14,5,-37,-421,345]`。这些案例保留了首项负号与具体变换结果。^[matreduc.md:71-74]
