# 局部标签到外部编号的类型组合

`RealFormLabels` 与 `ExternalFormOrder` 分别负责 Cartan 局部弱实类的全局标签和解释器面的外部编号。两者的衔接类型是 fundamental 分区的 `WeakRealFormId`：`label` 输出该内部编号，`external` 接受该内部编号。来源据此提出“局部类 → fundamental 内部编号 → 外部编号”的类型组合，但明确将其标为未验证的推断；所检查的两个文件互不导入，也没有代码或测试执行这一组合。^[real-form-labels-order.md:88-94]

## 两层映射的契约

`RealFormLabels::label(k)` 将一个 Cartan 中按 `classes()` 顺序排列的局部弱实类映射到 fundamental 分区的全局标签。构造依次检查 datum 一致性、两侧 grading 所属的对合、分解是否经指定 distinguished 对合因子化，以及分区与 fiber 的来源一致性。具体机制见 [[弱实形式的局部到全局标签映射]]。^[real-form-labels-order.md:17-24]

`ExternalFormOrder` 提供内部弱实形编号与上游外部输出编号之间的双射。排序先比较 depth，再比较 `specialGrading` 的 PARTITION 重载产生的无符号位集，其中生成元 0 对应最低位。实现要求 `(depth, grading)` 严格有序；出现并列时报告 `"strict (depth, grading) order"` 不变量违例。具体规则见 [[弱实形式的外部编号与严格排序]]。^[real-form-labels-order.md:49-59]

因此，来源所述组合依赖双方相容的 fundamental 内部编号域，其证据止于接口类型上的可衔接性，尚无完整串联流程的执行结果。^[real-form-labels-order.md:90-94]

## Quasisplit 锚点与访问边界

两层映射都以 fundamental 分区的 `quasisplit_class()` 为锚点，但约束的位置不同：标签层要求首标签指向 fundamental quasisplit 类，外部编号层要求 quasisplit 居末。标签层违反要求时报告 `"quasisplit anchor"`，空分区也会触发该违规；编号层通过 `"quasisplit last"` 维护末项约束。^[real-form-labels-order.md:41-42, real-form-labels-order.md:56-58, real-form-labels-order.md:90-94]

外部编号层的 `internal` 与 `external` 访问器对越界输入返回 `None`；`quasisplit_external()` 返回 `form_count().saturating_sub(1)`。“compact（深度 0）为 external 0”是文档声明，代码没有显式断言首项深度为 0。^[real-form-labels-order.md:57-59, real-form-labels-order.md:77-80]

## 证据范围

来源是对 `real_form_labels.rs` 与 `real_form_order.rs` 的结构性阅读，不构成标签或编号层的数学验收。标签层测试涉及 A1、A2、B2；编号层涉及 A1、A2、B2、D4、E6，其中 E6 仅覆盖生成元映射。两文件没有组合测试。^[real-form-labels-order.md:9-13, real-form-labels-order.md:103-104]

失败路径的覆盖也有限：标签层的 `ImpossibleGrading` 与 `"quasisplit anchor"` 失败没有测试锚点，编号层几乎全部失败路径缺乏锚点。本次来源维护未执行 Atlas、Cargo、测试或 benchmark，因此测试锚点的记录不代表本次重新运行验证。^[real-form-labels-order.md:98-104, real-form-labels-order.md:108-112]
