# 平方类编号与换基不变量

平方类编号 `SquareClassId` 是商空间 `(adjoint fiber group) / im(toAdjoint)` 中陪集在 crate 所选 echelon 基下的坐标整数。编号依赖基的约定；换基只会置换标签，partition 结构与所有 size 保持不变。^[strong-real.md:24-30]

## 平方类的构造与编号

强实层建立在已完成的 Cartan 分类之上。构建时，`StrongRealClassification::build` 逐 Cartan 取 grading 的 adjoint fiber 与 ambient fiber，构造 fiber map 的像坐标，并通过 `ModTwoSubquotient` 求平方商；相关坐标结构可参见 [[F₂ 子商的低主元坐标（ModTwoSubquotient）]]。^[strong-real.md:19-22, strong-real.md:49-54]

来源记录的 stage-(d) 排序审计表明，本 crate 的基选举与上游一致，因此该版本的 `SquareClassId` 等于上游 `printStrongReal` 输出的 `class #N`。这一对应依赖双方共享的 low-pivot RREF 约定，不能脱离换基约定视为永久的编号一致性；相关概念见 [[最低主元索引的典范 RREF 子空间]]。^[strong-real.md:26-30]

## 换基保持什么

任一侧改变平方商的基，只会置换平方类标签，不改变分类的 partition 结构或各项大小。因此，平方类编号的数值一致与分类结构的一致是需要区分的性质。^[strong-real.md:26-30]

强代表元 `StrongRealFormRep { fiber_orbit, square_class }` 表示某一平方类的 fiber group 中的一个 $W_{im}$ 轨道，并归属于一个弱实形式。这里的 `fiber_orbit` 编号还有另一项选择依赖：它取决于本 crate 消元时选取的具体解，而上游采用不同约定。不过，$\ker(\mathrm{toAdjoint})$ 的平移与作用交换，因此轨道的 class size 不依赖该解的选择。参见 [[强实形式与 fiber 轨道]]。^[strong-real.md:19-22, strong-real.md:32-37]

## 接口中的编号约定

每个 Cartan 类的 `StrongRealData` 保存平方类集合、逐平方类的 fiber 轨道大小与强代表元。`square_classes` 按编号升序访问；`square_class_representative(square)` 选取该平方类中编号最小的局部 weak class，而上游 `makeRealFormPartition` 选取它遇到的第一个 form。这些代表元选举约定应与平方类及轨道大小的不变量区分。^[strong-real.md:39-47]
