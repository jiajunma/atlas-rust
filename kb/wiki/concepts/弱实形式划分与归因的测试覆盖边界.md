# 弱实形式划分与归因的测试覆盖边界

`weak_real_form.rs` 的测试涉及两项职责：`WeakRealFormPartition` 将伴随 Cartan 纤维划分为 $W_{im}$ 轨道；`weak_real_form_at_representative` 将指定 Cartan 代表元上的环面因子归因到全局弱实形式编号。来源通过结构性阅读记录了 **11 个测试锚点**，未执行测试，也不扩展该模块既有的 HPC 正确性证据链。^[weak-real-form.md:9-16, weak-real-form.md:20-23, weak-real-form.md:58-63, weak-real-form.md:84-91, weak-real-form.md:106-106]

## 轨道划分与编号

划分测试覆盖 A2 恒等对合的 2 类、B2 恒等对合的 3 类、单连通 A1 平凡作用下的 2 个单元类，以及 A2 图扭转的 1 类。其中 B2 用例精确固定了代表元，为 [[弱实形式的伴随 Cartan 纤维轨道划分]] 提供具体测试锚点。^[weak-real-form.md:84-89]

实现按各轨道在 canonical-coordinate 整数序下的最小元升序编号，首次出现的元素即代表元；class 0 是 identity 所在的 quasisplit 类。来源将编号与上游内部 `RealFormNbr` 的一致性归于 stage-(d) 排序审计，而解释器外部 `FormNumberMap` 顺序仍需 adapter 置换。该审计结论与上述具体测试用例应分别理解，相关契约见 [[WeakRealFormId 的确定性编号与上游对齐]]。^[weak-real-form.md:25-32, weak-real-form.md:37-45]

## 代表元归因与错误门控

合成 A1 测试固定了以下归因结果：紧 Cartan 或分裂 Cartan 配环面因子 0 时得到类 0，紧 Cartan 配 $1/2$ 时得到类 1。其他锚点覆盖秩与半整投影门控、外来同秩分类优先报 `DatumMismatch`，以及 A2 反射半整投影错误的固定 `Display` 文案。^[weak-real-form.md:84-87]

这些测试所涉及的实现先检查原始因子长度、分类来源、`twisted` 的 datum、$w\delta=\theta$ 分解和代表元查找，随后进行投影。投影后的整性门对**每个单根**要求整数配对，先于虚根 grading 提取，使虚基为空的实 Cartan 也无法绕过检查；偶数配对标记非紧虚根，再经 `element_from_grading`、局部 `class_of` 和 `labels().label(local)` 得到全局编号。详见 [[弱实形式归因的来源与整性门控]]。^[weak-real-form.md:74-82]

归因 helper 的适用范围限于分类中已经存储的代表元。一般 twisted involution 移到代表元时，仍需通过 table-backed Tits cross actions 同步搬运 torus factor；该 helper 不隐式构建或扩展所需表，`minimal_torus_part` 下降还依赖分离的 inverse-Cayley 操作。参见 [[代表元归因与 Tits 搬运的职责边界]]。^[weak-real-form.md:65-72]

## 资源预算与表示边界

测试覆盖外来元素与预算不足的拒绝，并区分 rank-33 的预算拒绝和 rank-64 的 mask-bits 拒绝。`MAX_MASK_BITS = 63` 约束 `u64` 掩码表示；调用方的 `max_elements` 则限制枚举规模 $2^{\mathrm{dimension}}$。因此，rank-33 用例体现的是资源预算门，而非固定秩上限。^[weak-real-form.md:34-35, weak-real-form.md:49-51, weak-real-form.md:88-91]

`walk_mask_orbits` 使用 `u128` 计算 $2^{\mathrm{dimension}}$，与扩宽后的 `max_elements` 比较，故意不采用饱和运算，以防 `dimension == 64` 借 `usize::MAX` 上限漏过检查。相关遍历实现见 [[基于位掩码的 W_im 轨道枚举]]。^[weak-real-form.md:37-45]

类表使用 `Vec<u32>`，并保留 `u32::MAX` 作为 `CLASS_SENTINEL`；类序号无法用 `u32` 表示或等于哨兵时，`seeded_class` 返回 `limit_error("classes", …)`。来源记录了该守卫的直接测试，并指出在无伴随 `m_alpha`、每个掩码自成一类的单连通积情形下，该守卫原则上可达。^[weak-real-form.md:41-45, weak-real-form.md:89-91]

## 覆盖缺口

来源明确列出的未覆盖项是 `class_of_mask` 越界、各 `ArithmeticOverflow` 转换分支，以及 `max_elements == 2^dimension` 的显式边界断言。已有预算不足拒绝测试，不能代替预算恰好等于枚举规模时的边界断言。^[weak-real-form.md:88-91]

生成元对合性所依赖的配对关系 $\langle\alpha,\alpha^\vee\rangle=2$ 在模二下的性质，仅通过 `debug_assert` 检查；这是实现中的检查强度限制，应与测试锚点的覆盖范围一并保留。^[weak-real-form.md:40-43]
