# 弱实形式的外部编号与严格排序

`ExternalFormOrder` 建立内部弱实形式编号与上游解释器外部输出编号之间的双射，对应 `FormNumberMap`。它先按深度 `depth` 升序排列，再以 `specialGrading` 位集打破平局；实现要求排序键严格有序，并要求 quasisplit 实形式位于末尾。^[real-form-labels-order.md:49-59]

## 排序键与不变量

第一排序键 `depth` 是 distinguished involution 处极大正交 noncompact 虚根集的大小。第二排序键来自 `specialGrading` 的 PARTITION 重载，表示为 twist-fixed 简单生成元上的无符号位集，按数值比较，其中生成元 0 对应最低位。^[real-form-labels-order.md:51-55]

上游使用不稳定的 `std::sort`；Rust 移植断言严格的 `(depth, grading)` 序，任何并列键都会触发 `"strict (depth, grading) order"` 不变量违例。quasisplit 不在末位时触发 `"quasisplit last"`。“compact（深度 0）为 external 0”是文档声明，代码没有显式断言首项深度为 0。^[real-form-labels-order.md:56-59]

## 深度计算

`DepthTables` 预计算正虚根及其基非紧奇偶，计算使用 \(M=C^T\) 的有理逆列和，并通过 `"integral imaginary-simple coordinates"` 检查整性。`depth` 的贪心过程保持 `positive_imaginary` 的顺序，每步选择首个 noncompact 根，将与它不正交的候选移出 noncompact 集合；对与它正交但两根之和仍为根的候选，则翻转 compactness。后一情形涉及非单键型（non-simply-laced）根系中的短根对。^[real-form-labels-order.md:61-66]

来源还记录该函数存在一段无效果的空转循环，作为待清理评估的死代码观察；没有声明清理已经完成。^[real-form-labels-order.md:65-66]

## Grading 位集与坐标约束

`special_grading_key` 以分区类代表为种子，升序扫描 `0..2^dimension`，通过 `>=` 替换候选，因此在最大 popcount 的候选中选择最高 fiber 下标。随后在 fiber 秩内取补，再将补集 unslice 到 twist-fixed 简单生成元上，生成元 0 对应最低位。详见 [[specialGrading 的分区代表与位集编码]]。^[real-form-labels-order.md:72-75]

位集的数值比较依赖实际坐标顺序。`verified_generator_map` 要求升序排列的 twist-fixed 简单生成元数量等于伴随 fiber 维数，并逐位校验实际有序基，不能仅检查抽象双射。生成元下标大于或等于 `MAX_KEY_GENERATORS = 127` 时会被拒绝，参见 [[twist-fixed 生成元的有序基校验]]。^[real-form-labels-order.md:68-70]

fiber 宽度受 `MAX_MASK_BITS` 限制。`special_grading_key` 的 `0..(1 << dimension)` 全枚举是实现事实，其安全性依赖这一限制；该常量的具体数值在本来源包外定义。^[real-form-labels-order.md:72-75, real-form-labels-order.md:101-102]

## 查询接口与编号衔接

`internal` 与 `external` 在索引越界时返回 `None`。`quasisplit_external()` 返回 `form_count().saturating_sub(1)`；`special_grading(external)` 返回该外部实形式用于打破平局的位集。依据文档与字段注释，位 \(g\) 对应生成元 \(g\)，置位表示 noncompact imaginary。^[real-form-labels-order.md:77-80]

[[弱实形式的局部到全局标签映射]] 将每个 Cartan 的局部弱实类映射到 fundamental 分区的全局标签。标签层与外部编号层都以该分区的 `quasisplit_class()` 为锚点：前者要求首标签对应该类，后者要求它在外部顺序中居末。两个实现文件互不导入。^[real-form-labels-order.md:17-24, real-form-labels-order.md:88-94]

来源将“局部类 → fundamental 内部编号 → 外部编号”的串联明确标注为未验证推断：`label` 的输出与 `external` 的输入同为 fundamental 分区的 `WeakRealFormId`，因此类型上相容，但所读字节中没有执行这种组合的代码或测试。^[real-form-labels-order.md:90-94]

## 测试与证据边界

外部编号层记录了六个测试锚点：SL(2) 的 compact 编号 0、split 居末及 KGB 大小 1、3；Spin(5) 的 `[1,4,11]`；等秩 A2 中 SU(3) 先于 SU(2,1)；twisted A2 的单一 quasisplit 实形式；Spin(8) 的同深度实形式通过 grading 严格排序，且 compact 居首、split 居末；E6 twisted 的生成元坐标回归要求 `verified_generator_map == [1, 3]`，其期望来自给定置换，而非 Rust 输出。^[real-form-labels-order.md:82-86]

这些材料属于结构性源码阅读，不构成数学或正确性验收；上游位置引用仅转录自代码注释。外部编号层几乎全部失败路径缺少测试锚点，测试涉及 A1、A2、B2、D4、E6，其中 E6 仅覆盖生成元映射；标签层与编号层没有组合测试。本次来源知识维护未执行 Atlas、Cargo、测试或 benchmark。^[real-form-labels-order.md:9-13, real-form-labels-order.md:98-104, real-form-labels-order.md:108-112]
