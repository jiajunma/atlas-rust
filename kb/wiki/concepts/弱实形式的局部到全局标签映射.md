# 弱实形式的局部到全局标签映射

`RealFormLabels` 将一个 Cartan 的局部弱实类映射到 fundamental 分区的类，即 inner class 的全局内部实形式编号。`label(k)` 是按 `classes()` 顺序排列的第 `k` 个局部类的全局标签；解释器使用的外部编号则由 `ExternalFormOrder` 另行转换。^[real-form-labels-order.md:17-24, real-form-labels-order.md:49-59]

## 构造前提与错误顺序

构造按固定顺序校验输入。首先检查 datum 一致性，失败返回 `DatumMismatch`。随后要求 fundamental grading 位于本 inner class 的 distinguished involution，Cartan grading 位于分解的合成对合；任一不符均返回 `CartanFiberInvolutionMismatch`。再检查分解是否经由该 distinguished involution 因子化，失败返回 `DistinguishedInvolutionMismatch`。最后执行分区与 fiber 探针，外来 fiber 经元素来源检查以 `CartanFiberMismatch` 失败。相关背景见 [[CartanGradingData 与纤维来源一致性]]。^[real-form-labels-order.md:19-24]

## 映射算法

映射采用基于 grading 的既有机制，依次完成 Cayley 回拉、根列表运送、基本 grading 扩展和增广模二求解，最终确定局部类在 fundamental 分区中的归属。^[real-form-labels-order.md:26-40]

### Cayley 回拉与根运送

对 Cartan 侧的每个虚单根 `root`，统计使 `root + alpha` 仍为根的 Cayley 根 `alpha` 的数量；数量为奇数时，记录相应翻转位。随后将根列表 `cartan_imaginary ++ cayley` 经 cross 作用运送。每个像相对于 distinguished involution 都必须是虚根，否则触发 `"fundamental imaginary"` 不变量违例。参见 [[Cayley 回拉与模二 grading 求解]]。^[real-form-labels-order.md:28-31]

### 基 grading 扩展

内部函数 `base_grading_extension`（`pub(crate)`）计算基本 grading 在任意虚根处的值：将该根写成虚单根基的线性组合，取坐标系数和的奇偶。坐标通过精确求解**转置的 bracket 索引子 Cartan 系统**得到，其中第 `j` 行记录各基根与余根 `j` 的配对。^[real-form-labels-order.md:32-35]

虚根性必须显式检查。非虚根的投影也可能具有整数坐标，因此坐标整性不能替代虚根判据。^[real-form-labels-order.md:33-35]

### 增广模二求解

算法构造增广 `ModTwoSubspace`，包含 `list_len` 个根位置和与维数相同数量的哨兵位，用来表达 fundamental fiber 基代表与运送根之间的关系。对每个局部类，右端由“回拉后的 grading XOR 翻转位”接上 Cayley 块的全 noncompact 值组成，再与扩展基 grading 求差。^[real-form-labels-order.md:36-38]

若 `quotient_representative` 的余量在根位置仍有置位，则返回 `ImpossibleGrading`。否则，根据哨兵位异或组合出 ambient 代表，再调用 fundamental 分区的 `class_of` 得到全局标签。相关概念见 [[F₂ 商空间的确定性代表元与陪集判定]]。^[real-form-labels-order.md:39-40]

### Quasisplit 锚点

首标签必须等于 fundamental 分区的 quasisplit 类，否则触发 `"quasisplit anchor"` 不变量违例；空分区也必然触发该违例。^[real-form-labels-order.md:41-42]

## 与外部编号的衔接

`real_form_labels.rs` 与 `real_form_order.rs` 互不导入。`label` 的输出和 `external` 的输入同为 fundamental 分区的 `WeakRealFormId`。来源据此将“局部类 → fundamental 内部编号 → 外部编号”的串联标为类型上可行的推断，但所检查的代码和测试没有执行这一组合。外部排序机制见 [[弱实形式的外部编号与严格排序]]。^[real-form-labels-order.md:88-94]

两层都以 fundamental 分区的 `quasisplit_class()` 为锚点，但位置约束不同：标签映射要求首标签为该类，外部编号要求该类居末。^[real-form-labels-order.md:93-94]

## 测试与证据边界

标签层的六个测试锚点覆盖：A2 反射 Cartan 只标 quasisplit、fundamental Cartan 给出恒等映射、单连通 A1 分裂 Cartan 标 quasisplit，以及 B2 与 twisted A2 各 Cartan 的标签计数、quasisplit 锚点和值域。另有交叉或外来输入的三条拒绝路径，以及 A2/B2 基 grading 扩展的手算奇偶锚点和实根拒绝检查。^[real-form-labels-order.md:44-47]

标签层测试仅触及 A1/A2/B2；`ImpossibleGrading` 和 `"quasisplit anchor"` 的失败分支缺少测试锚点，两文件也没有组合测试。现有覆盖不能视为局部到外部编号完整链条已经验证。^[real-form-labels-order.md:98-104]

来源属于维护者对照源码核对后的结构性阅读，不声称标签或编号层的数学验收。上游行号仅转录自代码注释；精确读取身份由来源所列快照绑定 Git base、文件字节 SHA-256 与调用记录。本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[real-form-labels-order.md:9-13, real-form-labels-order.md:108-112]
