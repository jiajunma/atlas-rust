# 强代表下降到基本纤维

强代表下降到基本纤维是 `minimal_torus_part` 的中间步骤：通过逆 Cayley 与 based twisted 共轭，使给定强代表的 Weyl 部分成为恒等，并约化环面部分。后续算法沿基本虚 grading 轨道搜索，选出数值最小、且 datum-单根紧致性模式复现目标弱实形的环面部分。^[minimal-torus.md:22-25, minimal-torus.md:53-76]

## 输入门控与初始环面部分

入口检查依次为：对合表的 inner class 是否匹配、`coch` 与 `factor` 的长度是否等于格秩、`twisted` 的像置换长度是否等于根数，以及格秩是否超过 63。失败分别返回 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 和 `SeedResourceLimit { resource: "mask bits" }`；长度错误中的 `actual` 取两个输入长度的较大值。^[minimal-torus.md:35-36, minimal-torus.md:46-48]

初始 `torus_part` 由 `factor − coch` 得到：逐坐标要求差为整数，否则报 `"torus-part integrality"`；整数坐标为奇数时，将对应位置置位。这里的 `coch` 来自 `elected_square_root`，是强数据移位平方的 `stable_log`，相关背景见 [[合成实形的选定余特征]]。^[minimal-torus.md:19-21, minimal-torus.md:50-52]

## 下降算法

算法首先通过 `grading_of_simples` 按单根配对的偶性计算 grading，并构造 `TitsCoset`。上游配对运算中的整性断言在这里由具名门控检查；若 `table.lookup(twisted)` 找不到当前对合，则报 `"synthetic involution coverage"`。^[minimal-torus.md:53-56]

下降循环以 **Weyl 部分为恒等**作为停止条件。否则，按 `interface.outward()` 的迭代顺序选择**首个左下降生成元**。代码注释将此顺序对应到上游 `WeylGroup::leftDescent` 按外部编号寻找首个非零抛物片段的约定。^[minimal-torus.md:56-59]

若所选生成元在当前对合下为 `Real`，则执行逆 Cayley，且 `Ok(None)` 也作为错误处理；否则调用 `cross_pregated` 执行 based twisted 共轭。可结合 [[Cayley/Cross 的下降剥离算法]] 理解这一分支选择。^[minimal-torus.md:59-60]

循环结束后执行 `coset.reduce`。该约化具有幂等性；当输入的 `twisted` 已在基本纤维中、无需进入下降循环时，末尾约化仍起决定作用。^[minimal-torus.md:60-61]

## 逐步约化的依据与限制

Rust 实现复用 stage-(c) 的 `TitsCoset` 操作，在每个中间环面部分的目标对合处约化；来源所述的上游实现仅在末尾约化。代码注释称，这些操作是模二商上的类映射，因此逐步约化不改变最终约化类，并将该性质关联到 stage-(e) 的 KGB 枚举验证。来源包未独立验证这一论证，详见 [[TitsCoset 逐步约化的类映射依据]]。^[minimal-torus.md:27-29]

## 与 grading 轨道搜索的衔接

下降得到的环面部分 `tp` 用于余权提升：`coweight = coch + lift(tp)`，即在 `tp` 的置位坐标上给 `coch` 加 1。算法随后在基本纤维 `CartanId(0)` 的虚单根基上构造 `start`：与 `coweight` 偶配对的位置置位，表示紧致。`constrained` 标记其中属于 datum-单根的位置，`target` 则记录受约束位置的目标非紧致性，并通过翻转适配 crate 的 `Grading` 位约定。^[minimal-torus.md:62-67]

目标模式按虚单根基的实际位置配对。上游依赖 datum-单根位于基本单虚根基的前导段，而 crate 使用自己的确定性根序，因此改为逐位置配对。代码注释声明，两者在前导段不变量成立时一致，特别包括平凡 distinguished 的情形；这一一致性未在来源包中独立验证。参见 [[基本虚根 grading 的位置约束]]。^[minimal-torus.md:68-71, minimal-torus.md:95-96]

后续 [[最小环面部分的 grading 轨道搜索]] 使用 LIFO 栈与 `BTreeSet<u64>` 去重，在每个置位 grading 位上以 `m_alpha[i]` 平移，并按 `grading_shift[i]` 翻转 grading。满足目标约束的候选按 `ModTwoVector` 的等维位向量整数序取最小值；候选为空时报 `"minimal torus part candidates"`。^[minimal-torus.md:72-76]

## 测试与证据边界

来源列出四个测试锚点，均为 rank 2、紧致内类，涉及 A1.T1 中心因子、A2 非典范种子、等价因子及门控拒绝。三个正例都满足 `coch == factor`，未用可区分的断言刻画非平凡运输；其中第三个测试与第二个测试的第一组输入完全相同，其独立价值仅体现在注释叙述中。^[minimal-torus.md:78-91]

未覆盖的情形包括非紧致 distinguished、多数具名错误分支、rank > 63 的资源门及非平凡运输。`minimal_torus_part` 没有显式预算参数，仅有 `MAX_MASK_BITS` 与分配防护。详见 [[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:93-100]
