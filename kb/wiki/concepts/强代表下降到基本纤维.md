# 强代表下降到基本纤维

强代表下降到基本纤维是 `minimal_torus_part` 的中间步骤：通过逆 Cayley 与 based twisted 共轭，使给定强代表的 Weyl 部分成为恒等，并约化环面部分。随后算法沿基本虚 grading 轨道搜索，选出复现目标弱实形的数值最小环面部分。^[minimal-torus.md:22-25, minimal-torus.md:53-76]

## 输入门控与初始环面部分

入口按顺序检查：对合表的 inner class 是否匹配、`coch` 与 `factor` 的长度是否等于格秩、`twisted` 的像置换长度是否匹配，以及格秩是否超过 63。失败依次对应 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 和 `SeedResourceLimit { resource: "mask bits" }`；长度错误的 `actual` 取两者长度的较大值。^[minimal-torus.md:46-48]

初始 `torus_part` 来自 `factor − coch`：每个坐标必须为整数，否则触发具名错误 `"torus-part integrality"`；整数坐标为奇数时，将对应位置置位。这里的 `coch` 是 `elected_square_root` 给出的选定余特征，相关背景见 [[合成实形的选定余特征]]。^[minimal-torus.md:19-21, minimal-torus.md:50-52]

## 下降过程

算法先通过 `grading_of_simples` 按单根配对的偶性构造 grading，再构造 `TitsCoset`。配对整性在 Rust 中由具名门控检查；若 `table.lookup(twisted)` 找不到当前对合，则报 `"synthetic involution coverage"`，不会静默忽略缺失项。^[minimal-torus.md:53-56]

下降循环在 Weyl 部分为恒等时停止。否则，按 `interface.outward()` 的迭代顺序选择**首个左下降生成元**。代码注释将这一选择对应到上游 `WeylGroup::leftDescent` 按外部编号寻找首个非零抛物片段的约定。^[minimal-torus.md:56-59]

若所选生成元在当前对合下为 `Real`，则执行逆 Cayley，且 `Ok(None)` 也视为错误；否则调用 `cross_pregated` 执行 based twisted 共轭。相关分解可结合 [[Cayley/Cross 的下降剥离算法]] 阅读。^[minimal-torus.md:59-60]

循环结束后执行 `coset.reduce`。该约化具有幂等性；当输入的 `twisted` 已在基本纤维中、无需进入下降循环时，末尾约化仍起决定作用。^[minimal-torus.md:60-61]

## 逐步约化与实现差异

Rust 实现复用 stage-(c) 的 `TitsCoset` 操作，在每个中间环面部分的目标对合处约化；来源所述的上游实现仅在末尾约化。代码注释解释，这些操作是模二商上的类映射，因此逐步约化不改变最终约化类，并将该性质关联到 stage-(e) 的 KGB 枚举验证。此处属于注释声明，来源包未独立验证这一论证。^[minimal-torus.md:27-29]

## 与 grading 轨道搜索的衔接

下降所得环面部分 `tp` 用于余权提升：`coweight = coch + lift(tp)`，即在 `tp` 的置位坐标上给 `coch` 加 1。随后在基本纤维 `CartanId(0)` 的虚单根基上计算起始 grading：与 `coweight` 偶配对的位置置位，表示紧致；属于 datum-单根的位置构成目标约束，目标非紧致性按 crate 的 `Grading` 位约定处理。^[minimal-torus.md:62-67]

目标模式按虚单根基的实际位置配对。来源指出，上游依赖 datum-单根位于基本单虚根基的前导段，而 crate 使用自己的确定性根序，因此改为逐位置配对。两者在前导段不变量成立时一致，特别包括平凡 distinguished 的情形；这一一致性仍属于注释声明。详见 [[基本虚根 grading 的位置约束]]。^[minimal-torus.md:68-71, minimal-torus.md:95-96]

后续 [[最小环面部分的 grading 轨道搜索]] 使用 LIFO 栈与 `BTreeSet<u64>` 去重，在置位 grading 位上通过 `m_alpha` 平移并按 `grading_shift` 翻转 grading。满足目标约束的候选按 `ModTwoVector` 的等维位向量整数序取最小值；候选为空时报 `"minimal torus part candidates"`。^[minimal-torus.md:72-76]

## 测试与证据边界

来源是对 `minimal_torus.rs` 的结构性阅读，不构成数学或正确性验收；上游位置仅转录自代码注释，未核对上游字节。本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[minimal-torus.md:9-13, minimal-torus.md:104-108]

现有四个测试锚点均为 rank 2、紧致内类，涉及 A1.T1 中心因子、A2 非典范种子、等价因子及门控拒绝。三个正例都满足 `coch == factor`，未用可区分的断言刻画非平凡运输；非紧致 distinguished、多数具名错误分支及 rank > 63 的资源门也未覆盖。详见 [[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:78-98]
