# 强代表下降到基本纤维

强代表下降到基本纤维是 `minimal_torus_part` 的中间步骤：通过逆 Cayley 变换与 based twisted 共轭消去强代表的 Weyl 部分，再约化环面部分。随后算法在基本虚 grading 轨道中搜索，选出复现目标弱实形的数值最小环面部分。下降本身并不完成这一最小值选举。^[minimal-torus.md:22-25, minimal-torus.md:53-76]

## 输入与初始环面部分

入口依次检查对合表的 inner class、`coch` 与 `factor` 的长度、`twisted` 的像置换长度，以及格秩是否超过 63。相应失败分别返回 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 或 `SeedResourceLimit { resource: "mask bits" }`；长度错误的 `actual` 取 `coch` 与 `factor` 长度的较大者。^[minimal-torus.md:46-48]

初始 `torus_part` 由 `factor − coch` 构造：每个坐标必须为整数，否则触发具名错误 `"torus-part integrality"`；整数坐标为奇数时，将对应位置设为 1。这给出后续 [[TitsCoset 逐步约化的类映射依据|TitsCoset]] 操作使用的模二环面部分。^[minimal-torus.md:50-52, minimal-torus.md:27-29]

## 下降过程

算法先用 `grading_of_simples` 按单根配对的偶性构造 grading，再据此构造 `TitsCoset`。配对所需的整性以具名门控检查；`table.lookup(twisted)` 若找不到当前对合，则报 `"synthetic involution coverage"`，不会把缺失视为可忽略的查询结果。^[minimal-torus.md:53-56]

下降循环以 Weyl 部分为恒等作为停止条件。每一步按 `interface.outward()` 的迭代顺序选取**首个左下降生成元**：若它在当前对合下为 Real，则执行逆 Cayley 变换，且 `Ok(None)` 也视为错误；否则调用 `cross_pregated` 执行 based twisted 共轭。选择首个下降生成元的顺序是算法约定的一部分，可与 [[Cayley/Cross 的下降剥离算法]] 对照理解。^[minimal-torus.md:56-60]

循环结束后仍执行一次 `coset.reduce`。该操作具有幂等性；当输入的 `twisted` 已在基本纤维中、下降循环无需运行时，这次末尾约化起决定作用。^[minimal-torus.md:60-61]

## 逐步约化与类映射依据

实现复用 stage-(c) 的 `TitsCoset` 操作，在每个中间环面部分的目标对合处约化；来源转录的上游行为则只在末尾约化。代码注释将这种差异的依据表述为：这些操作是模二商上的类映射，因此逐步约化不改变最终约化类，并将该性质关联到 stage-(e) 的 KGB 枚举验证。当前来源包没有独立验证这一声明，详见 [[TitsCoset 逐步约化的类映射依据]]。^[minimal-torus.md:27-29]

## 与后续 grading 搜索的衔接

下降所得环面部分 `tp` 用于余权提升：`coweight = coch + lift(tp)`，即在 `tp` 的置位坐标上给 `coch` 加 1。算法随后在基本纤维 `CartanId(0)` 的虚单根基上计算起始紧致性模式，并以其中属于 datum-单根的位置约束目标模式。后续 [[最小环面部分的 grading 轨道搜索]] 遍历轨道并从合格候选中取最小值。^[minimal-torus.md:62-76]

## 证据边界

来源是对 `minimal_torus.rs` 的结构性阅读，不构成数学或正确性验收；上游位置仅由代码注释转录，未核对上游字节。现有测试锚点均为 rank 2、紧致内类，三个正例都满足 `coch == factor`，未以可区分的断言刻画非平凡运输。非紧致 distinguished、多数具名错误分支及 rank > 63 的资源门也未覆盖，参见 [[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:10-13, minimal-torus.md:78-98]
