# 强代表下降到基本纤维

强代表下降到基本纤维是 `minimal_torus_part` 的中间步骤：通过逆 Cayley 变换与 based twisted 共轭，使强代表的 Weyl 部分成为恒等，并约化环面部分。随后算法才在基本虚 grading 轨道中搜索，选出复现目标弱实形的数值最小环面部分。^[minimal-torus.md:22-25, minimal-torus.md:53-76]

## 输入门控与初始环面部分

入口依次检查对合表的 inner class、`coch` 与 `factor` 的长度、`twisted` 的像置换长度，以及格秩是否超过 63。相应失败分别返回 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 或 `SeedResourceLimit { resource: "mask bits" }`；长度错误的 `actual` 取 `coch` 与 `factor` 长度的较大者。^[minimal-torus.md:46-48]

初始 `torus_part` 由 `factor − coch` 构造：每个坐标必须为整数，否则触发具名错误 `"torus-part integrality"`；整数坐标为奇数时，将对应位置设为 1。这给出下降所用的模二环面部分，相关表示见 [[环面部分的模二表示与余权提升]]。^[minimal-torus.md:50-52]

## 下降算法

算法先用 `grading_of_simples` 按单根配对的偶性构造 grading，再据此构造 `TitsCoset`。配对所需的整性通过具名门控检查；`table.lookup(twisted)` 若找不到当前对合，则报 `"synthetic involution coverage"`。^[minimal-torus.md:53-56]

下降循环以 Weyl 部分为恒等作为停止条件。每一步按 `interface.outward()` 的迭代顺序选择**首个左下降生成元**。代码注释将这一顺序对应到上游 `WeylGroup::leftDescent` 按外部编号选择首个非零抛物片段的约定。^[minimal-torus.md:56-59]

若所选生成元在当前对合下为 `Real`，则执行逆 Cayley 变换，且返回 `Ok(None)` 也视为错误；否则调用 `cross_pregated` 执行 based twisted 共轭。这一分支结构可结合 [[Cayley/Cross 的下降剥离算法]] 阅读。^[minimal-torus.md:59-60]

循环结束后仍执行一次 `coset.reduce`。该操作具有幂等性；当输入的 `twisted` 已在基本纤维中、下降循环无需运行时，这次末尾约化起决定作用。^[minimal-torus.md:60-61]

## 逐步约化的依据与限制

实现复用 stage-(c) 的 `TitsCoset` 操作，在每个中间环面部分的目标对合处约化；来源记载的上游实现则只在末尾约化。代码注释给出的依据是：这些操作是模二商上的类映射，因此逐步约化不改变最终约化类，并将该性质关联到 stage-(e) 的 KGB 枚举验证。这属于注释声明，当前来源包未独立验证。^[minimal-torus.md:27-29]

## 与后续 grading 搜索的衔接

下降所得环面部分 `tp` 用于余权提升：`coweight = coch + lift(tp)`，即在 `tp` 的置位坐标上给 `coch` 加 1。算法随后在基本纤维 `CartanId(0)` 的虚单根基上计算起始模式：与 `coweight` 偶配对的位置置位，表示紧致；其中属于 datum-单根的位置用于约束目标模式。^[minimal-torus.md:62-67]

目标的非紧致性位按 crate 的 `Grading` 约定处理，并按虚单根基的实际位置配对。来源指出，这与上游依赖 datum-单根位于基前导段的处理存在有意差异；两者在该前导段不变量成立时一致，但这一一致性仍属于注释声明。相关位置约束见 [[基本虚根 grading 的位置约束]]。^[minimal-torus.md:65-71, minimal-torus.md:95-96]

后续 [[最小环面部分的 grading 轨道搜索]] 使用 LIFO 栈与 `BTreeSet<u64>` 去重，收集满足目标约束的候选，再按 `ModTwoVector` 的等维位向量整数序取最小值。空候选触发具名错误 `"minimal torus part candidates"`，因此完成下降并不等于完成最小环面部分的选举。^[minimal-torus.md:72-76]

## 证据边界

来源是对 `minimal_torus.rs` 的结构性阅读，不构成数学或正确性验收；上游位置仅从代码注释转录，未核对上游字节。本次知识维护未执行 Atlas、Cargo、测试或 benchmark。^[minimal-torus.md:9-13, minimal-torus.md:104-108]

现有四个测试锚点均为 rank 2、紧致内类；三个正例都满足 `coch == factor`，未以可区分的断言刻画非平凡运输。非紧致 distinguished、多数具名错误分支及 rank > 63 的资源门也未覆盖，详见 [[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:78-98]
