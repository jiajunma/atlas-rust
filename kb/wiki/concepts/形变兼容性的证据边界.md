# 形变兼容性的证据边界

形变兼容性需要区分结构性阅读、实现方的移植陈述与 HPC 差分验证。形变缓存机器来源明确标注“结构性阅读，不声称数学验收”；其中的上游行号引用属于实现方移植陈述，兼容性以 HPC 差分门为准。^[atlas-core-deformation-cache.md:9-15, atlas-core-deformation-cache.md:62-64]

## 结构性阅读的覆盖范围

来源覆盖 `domain_builtins.rs` 中普通与扭曲全形变的入口、递归和缓存机器，以及矩阵辅助函数。相关的 `common_deformation_terms` 与块机器位于派生臂区域，`RepContext`、`ExtRepContext` 和领域值系数契约则由其他包覆盖，不能将本包视为完整覆盖这些依赖的材料。^[atlas-core-deformation-cache.md:9-14, atlas-core-deformation-cache.md:52-61]

[[全形变缓存与递归环检测]]的实现纪律包括：以 canonical 单元 `(x, y_bits, gamma)` 为键，仅在缓存读写瞬间持锁，不跨递归持有缓存或块属主锁；只缓存完整且按 canonical 顺序排列的结果，并用 `active` 集检测递归环。[[形变计算的协作式截止]]在阶段间检查期限，超限返回 `None`，不缓存部分结果。^[atlas-core-deformation-cache.md:19-27]

## 普通全形变的算法对应

来源给出的普通全形变递推为 $F(z)=L(z)+\sum_t c_t(1-s)F(t)$，遍历每个可约点；利用 $(1-s)^2=2(1-s)$，它对应原版整数递推 $D(z)\mathrel{+}=c_tL(t)+2c_tD(t)$。这是来源陈述的算法对应关系，其兼容性判定仍以 HPC 差分门为准。^[atlas-core-deformation-cache.md:29-33, atlas-core-deformation-cache.md:62-64]

递归项的完整性是实现解释中的关键约束：scale-zero 基底保留全部 final 项，子项依次经过 `scale`、`deform_readjust`、表示查找和 `common_deformation_terms`，再以 $c(1-s)$ 因子递归。停在前一个可约点并将其化为单个 K 型，会丢弃 Split 因子及后代，参见[[全形变中的 Split 因子与后代保留]]。顶层对每个 final 组分形变、按系数缩放并合并，最终按 canonical `KTypePol` 项序排序。^[atlas-core-deformation-cache.md:36-42]

## 扭曲全形变的计时边界

[[扭曲全形变计算流程]]依次经过 `distinguished_twist`、`ExtRepContext` 和 `extended_finalise`，计时在 `extended_finalise` 之后才开始，因此 setup 成本不在协作截止范围内。随后调用 `twisted_reducibility_lookup` 与 `twisted_deformation_with_cancel`；finalise 翻转不同时系数为 $s$，否则为 $1$，结果逐项合并排序。来源引用 `axis.w:8303–8308` 说明计时位置，该引用仍属于实现方移植陈述。^[atlas-core-deformation-cache.md:46-50, atlas-core-deformation-cache.md:62-64]

## 验收入口与快照限制

来源将普通全形变弧的兼容验证指向 HPC 差分门 `3845838/3845872`，并要求参照根 `AGENTS.md` 的 “Ordinary full deformation” 条目。这是追查[[HPC 验收证据链]]的入口；本包自身仍定位为结构性阅读，不能据此宣称数学验收。^[atlas-core-deformation-cache.md:9-15, atlas-core-deformation-cache.md:62-64]

快照标注的 Git base 为 `964f0033`。字节数与哈希只标识本快照字节，不是形变兼容性的验证结论；兼容性仍须依据上述 HPC 差分门判断。^[atlas-core-deformation-cache.md:62-65]
