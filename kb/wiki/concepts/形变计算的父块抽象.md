# 形变计算的父块抽象

形变计算通过 `KlSumParent<'a>` 为 twisted KL 和与 twisted deformation 提供父公共块的借用视图；`DeformParent` 则持有递归可约点查找返回的父块，经 `as_kl_sum_parent` 转为借用。两者区分完整块与部分公共块的参数重构方式，并要求形变项计算期间所选父块保持存活。^[deformation-drivers.md:83-93]

## 借用视图：KlSumParent

完整块变体为 `Full { block: &BlockGraph, lambda_rho: &Weight }`，借用完整块与调用方提供的常量 `lambda_rho`。部分公共块变体为 `Partial { block: &PartialBlock, modifier: Option<&BlockModifier> }`，按 `common_block::sr` 的方式为每行重构自己的 `lambda_rho`。相关结构见 [[公共块的构造与元素编号（PartialBlock）]] 与 [[BlockModifier 块修正子]]。^[deformation-drivers.md:85-89]

### 完整块的参数约束

一次性传入 `lambda_rho` 属于 [[形变驱动的冻结移植契约]]，并不意味着完整块内各元素天然共享该值。例如，SL(2,R) 块在 $\gamma=2\rho$ 时，compact-Cartan 元素的值为 `[1]`，split 元素为 `[0]`。调用方须提供所有形变项共享该值的参数；语言层使用 `rc.lambda_rho(p)`，来源说明这与已验证的 `deform` 分支一致。^[deformation-drivers.md:29-33]

### 部分公共块的逐行重构

来源描述的真积分子系统路径以 `PartialBlock` 为父块。每行经 `RepContext::sr_with_modifier`，结合自身存储的 `gamma_lambda` 与查找返回的 block modifier 重构参数，与上游 `common_block::sr` 一致。相关过程见 [[块修正子的相对化与标准参数恢复]]。^[deformation-drivers.md:34-37]

## 资源持有：DeformParent

`DeformParent` 是递归 twisted deformation 中可约点查找返回的拥有资源的版本，具有 `Full { Box<BlockGraph>, Weight }` 与 `Partial { Arc<PartialBlock>, BlockModifier }` 两种形式。递归驱动通过 `as_kl_sum_parent` 提供借用视图，并必须在 `twisted_deformation_terms` 借用其块视图期间保持所选父块存活。^[deformation-drivers.md:89-93]

在 [[扭曲全形变计算流程]] 中，`lookup` 在具有积分 `gamma` 的可约点参数处，承担上游 `rt.lookup(zi, index, bm)` 与 `block.extended_block(bm, ...)` 的角色。rank-0 积分子系统对应单例，不贡献形变项，也不调用 `lookup`。^[deformation-drivers.md:126-134]

## 父块参与的计算语义

两个 twisted KL 和使用不同的长度函数确定交错符号。`twisted_kl_column_at_s` 针对父块元素 `y0`，使用 `parent.length(eblock.z(x))`；`twisted_kl_sum` 针对扩展块元素 `y`，使用扩展块自身的 `eblock.length`。这一差异见 [[twisted KL 和的长度函数选择]]。^[deformation-drivers.md:95-103]

奇异集的读取也依赖块上下文。在平凡 block modifier 下，`simple_singular_flags` 对应 `common_block::singular(gamma)`，`singular_orbits_at` 给出扩展块在 `gamma` 处的奇异轨道标志；部分父块则折叠其子系统生成元的奇异集。^[deformation-drivers.md:77-81]

`common_deformation_terms` 对 `RepTable::lookup` 返回的 partial block 计算 common-block 形变项，采用上游 `contributions(block, block.singular(bm,gamma), y)` 路径。^[deformation-drivers.md:112-114]

## 适用范围与未决歧义

来源对 `IntegralBlockScope::ProperSubsystem` 的说明要求：真积分子系统的 common-block 支撑不在该处移植面，调用方必须显式失败，不能默默改用完整块计算。同一来源又描述了部分父块的逐行重构、`KlSumParent::Partial`、`DeformParent::Partial` 及 `common_deformation_terms` 路径。来源同时保留了这一限制与这些支持路径，但未明确划清各入口的适用范围。^[deformation-drivers.md:34-37, deformation-drivers.md:73-75, deformation-drivers.md:85-93, deformation-drivers.md:112-114]

因此，部分父块抽象的存在不足以证明所有形变驱动入口均支持真积分子系统；也不能将该处显式失败要求推广为所有部分公共块路径均不可用。
