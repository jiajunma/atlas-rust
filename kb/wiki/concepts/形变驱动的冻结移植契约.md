# 形变驱动的冻结移植契约

形变驱动的冻结移植契约是 Rust `deform.rs` 移植上游 `gkmod/repr.cpp` 时遵循的 `domain/deform` 约定。它涵盖 twisted 形变项提取、在 $s$ 处求值的两个 twisted KL 和、高度受限的块形变，以及递归 twisted deformation，并明确各路径的参数前提与简化范围。^[deformation-drivers.md:18-48]

## 参数重构与父块选择

完整块路径由调用方一次性提供 `lambda_rho`，不再逐元素从上游 `StandardReprMod` 池读取。调用方必须保证所传参数的所有形变项共享该值；完整块自身并不保证这一点。例如，SL(2,R) 在 $\gamma=2\rho$ 时，compact-Cartan 元素的 `lambda_rho` 为 `[1]`，split 元素为 `[0]`。语言层使用 `rc.lambda_rho(p)`，与来源所述已验证的 `deform` 分支一致。^[deformation-drivers.md:29-33]

真积分子系统采用 [[公共块的构造与元素编号（PartialBlock）|PartialBlock]]。每行使用自身存储的 `gamma_lambda`，结合 lookup 返回的 [[BlockModifier 块修正子|block modifier]]，通过 `RepContext::sr_with_modifier` 重构参数，与上游 `common_block::sr` 对应；这一路径按行恢复各自的 `lambda_rho`。^[deformation-drivers.md:34-37, deformation-drivers.md:85-89]

[[形变计算的父块抽象]]区分借用视图与拥有型数据：`KlSumParent<'a>` 提供完整块或部分块的借用；`DeformParent` 是递归中 reducibility-point lookup 返回的拥有型版本，分别持有 `Box<BlockGraph>` 与 `Weight`，或 `Arc<PartialBlock>` 与 `BlockModifier`。递归驱动通过 `as_kl_sum_parent` 获取借用，并须在 `twisted_deformation_terms` 使用块视图期间保持父块存活。^[deformation-drivers.md:83-93]

## 积分子系统门控

`integral_block_scope(rc, gamma)` 根据余根与 `gamma` 的整配对情况分类：当 `coroot · gamma.numerator()` 能被 `gamma.denominator()` 整除时，该余根与 `gamma` 整配对。无根整配对时为 `Singleton`；每个简单余根都整配对时为 `Full`；真积分子系统为 `ProperSubsystem`。相关细节见 [[积分块范围与奇异集]]。^[deformation-drivers.md:61-75]

rank-0 子系统走单例 `{p}` 的快速路径：块长度为零，形变项为空，twisted KL 和在 $s$ 处为 `1*p`。递归形变中，这类单例不调用 `lookup`。^[deformation-drivers.md:38-39, deformation-drivers.md:68-70, deformation-drivers.md:130-132]

`ProperSubsystem` 不得默默使用完整块计算。来源的分类说明要求：不具备 common-block 支撑的移植路径必须显式失败；来源另述的部分块路径则按行重构真积分子系统中的参数。A1 在 $\nu=[1]/2$ 时，完整块大小为 3，而积分块为单例，说明直接套用完整块会改变计算范围。^[deformation-drivers.md:34-37, deformation-drivers.md:71-75]

## 奇异集与长度函数

当 `bm` 平凡时，上游按 `block_modifier` 索引计算的 singular orbits，与 `ExtBlock::singular_orbits` 使用普通简单余根奇异集的结果一致。此时 `bm.simp_int` 是按恒等索引排列的简单根列表，`bm.simple_pi` 是恒等置换。部分父块则折叠自身子系统生成元的奇异集。^[deformation-drivers.md:40-43, deformation-drivers.md:77-81]

两个 twisted KL 和使用不同的长度函数：`twisted_kl_sum` 对扩展块元素 `y` 求 $q=s$ 处的交错列和，符号取自扩展块自身的长度；`twisted_kl_column_at_s` 对父块元素 `y0` 处的参数求交错和，符号取自 `parent.length(eblock.z(x))`。这是两个接口的关键差异，详见 [[twisted KL 和的长度函数选择]]。^[deformation-drivers.md:95-103]

## 递归预处理与记忆化简化

当 `gamma.denominator() > 2^rank` 时，在递归 twisted deformation 之前应用 `weyl::alcove_center` 收缩。上游 `Rep_table` 的 `deformation_unit`／`alcove_hash` 记忆化则由朴素重算替代；没有共享池时，每个结果都针对当前报告 flip 的参数本身计算，因此不需要 memo-hit flip 调整。^[deformation-drivers.md:44-48]

[[递归 twisted deformation 与取消语义|递归 twisted deformation]] 接受 final、delta-fixed 参数 `z`，输出 `(KType, SplitInteger)` 项，并报告 shrink-wrap 到最后一个 reducibility point 所记录的 net flip；没有 shrink-wrap 时，`flip == false`。可取消变体在每次递归或块级操作之间检查取消 probe，取消时返回 `Ok(None)`，不发布部分多项式。^[deformation-drivers.md:124-134]

## 形变项、系数与输出顺序

`twisted_deformation_terms` 是上游对应驱动的平凡 block modifier 版本，使用父块编号处理 final、delta-fixed 元素 `y`，按 reverse-accumulated finals 顺序返回 `(StandardRepr, int)`。wrapper 将每个系数 `c` 转为 `Split(c, -c)`，即 $c(1-s)$，再按 `SR_poly` 顺序排序。部分块的 `common_deformation_terms` 则使用上游 `contributions(block, block.singular(bm,gamma), y)` 路径。^[deformation-drivers.md:59-59, deformation-drivers.md:105-114]

[[SplitInteger 分裂整数系数|SplitInteger]] 表示 $a+bs$，承载 $F(z)=L(z)+(1-s)D(z)$ 中的系数。字段为 `i32`，所有算术使用 `wrapping_*`，沿用上游环绕语义；溢出防护不属于该类型的职责。^[deformation-drivers.md:50-59]

`block_deformation_to_height` 是平凡 block modifier 版本，处理 `p` 的完整块中高度不超过 `height_bound` 的项，按 downward（reversed）block order 返回 `(StandardRepr, SplitInteger)`；`u32::MAX` 对应上游负界表示的 maximal level。由于 Atlas 值不可变，上游原地 `queue.erase` 的效果改为通过与 `accumulator` 平行的已消费项 flags 报告。^[deformation-drivers.md:115-120]

上游在高度界之上使用 `plug_hole` 跳过对偶块 KL 表的部分填充工作。来源说明多项式值不依赖这些 holes，因此移植版本填充整张表。输出顺序及相关边界另见 [[形变项计算的边界情形与输出顺序]]。^[deformation-drivers.md:115-122]
