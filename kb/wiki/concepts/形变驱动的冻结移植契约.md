# 形变驱动的冻结移植契约

形变驱动的冻结移植契约是 Rust `deform.rs` 移植上游 `gkmod/repr.cpp` 驱动时遵循的 `domain/deform` 约定，涵盖形变项提取、两个在 $s$ 处求值的 twisted KL 和、高度受限的块形变与递归 twisted deformation。契约明确参数重构、父块选择、奇异集计算、递归预处理和记忆化简化的适用范围。^[deformation-drivers.md:18-48]

## 参数重构与父块选择

完整块路径由调用方一次性提供 `lambda_rho`，不再逐元素从上游 `StandardReprMod` 池读取。因此，调用方必须保证所有形变项共享该值；完整块本身并不保证这一点。例如，SL(2,R) 在 $\gamma=2\rho$ 时，compact-Cartan 元素的值为 `[1]`，split 元素为 `[0]`。语言层使用 `rc.lambda_rho(p)`，与来源所述已验证的 `deform` 分支一致。^[deformation-drivers.md:29-33]

真积分子系统采用 [[公共块的构造与元素编号（PartialBlock）|PartialBlock]]。每行使用自身存储的 `gamma_lambda`，结合 lookup 返回的 [[BlockModifier 块修正子|block modifier]]，通过 `RepContext::sr_with_modifier` 重构参数，与上游 `common_block::sr` 对应；这条路径按行恢复各自的 `lambda_rho`。^[deformation-drivers.md:34-37, deformation-drivers.md:85-89]

[[形变计算的父块抽象]]区分借用与拥有两种形式：`KlSumParent<'a>` 提供完整块或部分块的借用视图；`DeformParent` 是递归中 reducibility-point lookup 返回的拥有型版本。递归驱动通过 `as_kl_sum_parent` 获取借用，并必须在 `twisted_deformation_terms` 使用该视图期间保持父块存活。^[deformation-drivers.md:83-93]

## 积分子系统门控

`integral_block_scope(rc, gamma)` 根据余根与 `gamma` 的整配对情况分类：`coroot · gamma.numerator()` 能被 `gamma.denominator()` 整除，即为整配对。无根整配对时为 `Singleton`，每个简单余根都整配对时为 `Full`，真积分子系统为 `ProperSubsystem`。相关概念见 [[积分块范围与奇异集]]。^[deformation-drivers.md:61-75]

rank-0 子系统走单例 `{p}` 的快速路径：块长度为零，形变项为空，twisted KL 和在 $s$ 处为 `1*p`。递归形变中，这类单例也不调用 `lookup`。^[deformation-drivers.md:38-39, deformation-drivers.md:68-70, deformation-drivers.md:130-132]

`ProperSubsystem` 不能被默默当作完整块计算。来源在完整块驱动的移植面中要求：缺少 common-block 支撑时，调用方必须显式失败；另行描述的部分块路径才承担真积分子系统的参数重构。来源以 A1、$\nu=[1]/2$ 为警示例子：完整块大小为 3，而积分块是单例。^[deformation-drivers.md:34-37, deformation-drivers.md:71-75]

## 奇异集与长度函数

当 `bm` 平凡时，上游按 `block_modifier` 索引计算的 singular orbits 与 `ExtBlock::singular_orbits` 使用的普通简单余根奇异集一致。此时 `bm.simp_int` 是按恒等索引排列的简单根列表，`bm.simple_pi` 是恒等置换。部分父块则折叠自身子系统生成元的奇异集。^[deformation-drivers.md:40-43, deformation-drivers.md:77-81]

两个 twisted KL 和保留不同的长度约定：`twisted_kl_sum` 对扩展块元素求交错列和，符号取自扩展块自身的长度；`twisted_kl_column_at_s` 对父块元素处的参数求交错和，符号取自 `parent.length(eblock.z(x))`。这一差异不能在移植中合并，详见 [[twisted KL 和的长度函数选择]]。^[deformation-drivers.md:95-103]

## 递归预处理与记忆化简化

当 `gamma.denominator() > 2^rank` 时，先应用 `weyl::alcove_center` 收缩，再进入递归 twisted deformation。该阈值对应 [[Alcove 分母界守卫]] 所涉及的分母检查。^[deformation-drivers.md:44-45]

上游 `Rep_table` 的 `deformation_unit`／`alcove_hash` 记忆化在此移植中由朴素重算替代。没有共享池时，每个结果都针对当前报告 flip 的参数本身计算，因此不需要 memo-hit flip 调整。^[deformation-drivers.md:46-48]

[[递归 twisted deformation 与取消语义|递归 twisted deformation]] 接受 final、delta-fixed 参数，输出 `(KType, SplitInteger)` 项，并报告 shrink-wrap 到最后一个 reducibility point 所记录的 net flip；没有 shrink-wrap 时，`flip == false`。可取消变体在递归或块级操作之间检查取消 probe，取消时返回 `Ok(None)`，不发布部分多项式。^[deformation-drivers.md:124-134]

## 输出与块形变适配

`twisted_deformation_terms` 的平凡 block modifier 版本使用父块编号，针对 final、delta-fixed 元素，按 reverse-accumulated finals 顺序返回 `(StandardRepr, int)`。wrapper 将每个系数 `c` 转为 `Split(c, -c)`，即 $c(1-s)$，再按 `SR_poly` 顺序排序。部分块的 `common_deformation_terms` 则采用上游 `contributions(block, block.singular(bm,gamma), y)` 路径。^[deformation-drivers.md:59-59, deformation-drivers.md:105-114]

系数类型 [[SplitInteger 分裂整数系数|SplitInteger]] 表示 $a+bs$，承载公式 $F(z)=L(z)+(1-s)D(z)$ 中的系数。其字段为 `i32`，所有算术使用 `wrapping_*`，沿用上游环绕语义；溢出防护不属于该类型的职责。^[deformation-drivers.md:50-59]

[[高度受限的块形变|block_deformation_to_height]] 处理完整块中高度不超过 `height_bound` 的项，按 downward（reversed）block order 返回；`u32::MAX` 对应上游负界表示的 maximal level。由于 Atlas 值不可变，上游原地 `queue.erase` 的效果改为通过与 `accumulator` 平行的已消费项 flags 报告。上游在高度界之上使用 `plug_hole` 跳过部分 KL 表工作；来源说明多项式值不依赖这些 holes，因此移植版本填充整张表。^[deformation-drivers.md:115-122]
