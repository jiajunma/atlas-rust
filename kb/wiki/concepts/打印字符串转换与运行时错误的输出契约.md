# 打印、字符串转换与运行时错误的输出契约

内建注册表通过 `BuiltinImpl` 区分 `Prints`、`Print`、`ToString`、`Error` 与领域打印包装器 `DomainPrinter`。这些分支规定文本的打印表示、换行行为、返回值及运行时错误的形成方式，分发结构见 [[内建函数元数据与实现分发]]。^[atlas-core-builtin-registry.md:26-40]

## 通用打印与字符串转换

`Print` 对应 `print@@T`，按打印表示逐字输出，字符串带引号；在要值的求值级别，它还原样返回参数。`ToString` 对应 `to_string@@T`，产生剥离字符串引号后的拼接串值；`Error` 对应 `error@@T`，将这种拼接文本作为运行时错误抛出。^[atlas-core-builtin-registry.md:37-40]

`prints`、`to_string` 与 `error` 的文本形成规则由 `to_string_aux` 的变参元组处理约定说明：字符串分量不带引号打印，其余分量按 `print` 规则打印。因此，剥离引号针对字符串分量，其他分量仍使用其打印表示；相关主题见 [[上游兼容的值打印约定]]。^[atlas-core-builtin-registry.md:64-67]

## 换行与返回值

`Prints` 在当前注册方式中采用普通类型方案 `T->void`。`prints` 自行追加 `std::endl`，`prints_wrapper` 的输出为“剥离文本 + 一个换行”；`to_string` 与 `error` 不追加换行。^[atlas-core-builtin-registry.md:37-40, atlas-core-builtin-registry.md:64-67]

## 领域打印与无值求值

`DomainPrinter { name }` 在无值与 `single_value` 两个求值级别都会写报告，并在 `single_value` 级别产出空元组。其无值门之前没有诊断；这一约定可结合 [[TypedExpr 六族求值与值需求层级]] 阅读。^[atlas-core-builtin-registry.md:31-33]

领域调用的 `DomainNoValue` 另行规定 `NoValue` 级别的处理策略：`Skip` 表示跳过，`Validate` 表示校验，`BuildAndDrop` 表示完整构造后丢弃。补全名清单不能用于推断无值策略，例如 `orientation_nr` 注册为 `BuildAndDrop`，而非 `Skip`；参见 [[BuildAndDrop 领域内建验证策略]]。^[atlas-core-builtin-registry.md:42-47]
