# 打印、字符串转换与运行时错误的输出契约

内建注册表区分 `Prints`、`Print`、`ToString`、`Error` 与领域打印包装器 `DomainPrinter`。它们分别规定文本如何形成、是否追加换行、是否返回值，以及是否将文本作为运行时错误抛出；相关分发机制见 [[内建函数元数据与实现分发]]。^[atlas-core-builtin-registry.md:23-37]

## 通用打印与文本转换

`print@@T` 按打印表示逐字输出，字符串带引号；在要求值的求值级别，它还原样返回参数。`to_string@@T` 则产生剥离字符串引号后的拼接串值，`error@@T` 将同样的剥离拼接文本作为运行时错误抛出。^[atlas-core-builtin-registry.md:34-37]

共享辅助逻辑 `to_string_aux` 处理变参元组时，字符串分量不带引号打印，其余分量按 `print` 的规则打印。因而，文本拼接保留非字符串分量的打印表示，同时省去字符串分量的引号；这一规则可结合 [[上游兼容的值打印约定]] 理解。^[atlas-core-builtin-registry.md:61-64]

## 换行与返回值

`prints` 在当前注册方式中采用普通 scheme `T->void`。它自行追加 `std::endl`，其包装器输出契约是“剥离文本 + 一个换行”；`to_string` 与 `error` 不追加换行。^[atlas-core-builtin-registry.md:34-37, atlas-core-builtin-registry.md:61-64]

## 领域打印包装器

`DomainPrinter { name }` 在无值与 `single_value` 两个求值级别都会写报告；在 `single_value` 级别还产出空元组。其无值门之前没有诊断。理解这一行为时，可参照 [[TypedExpr 六族求值与值需求层级]]。^[atlas-core-builtin-registry.md:28-30]

领域调用的 `DomainNoValue` 策略另行区分 `Skip`、`Validate` 与 `BuildAndDrop`，分别表示跳过、校验、完整构造后丢弃。补全名清单不能用来推断这些无值策略；相关验证行为见 [[BuildAndDrop 领域内建验证策略]]。^[atlas-core-builtin-registry.md:39-44]
