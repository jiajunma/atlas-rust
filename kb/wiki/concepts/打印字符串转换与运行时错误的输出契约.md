# 打印、字符串转换与运行时错误的输出契约

内建注册表通过 `BuiltinImpl` 区分 `Prints`、`Print`、`ToString`、`Error` 与领域打印包装器 `DomainPrinter`。这些实现规定文本如何形成、是否追加换行、返回什么值，以及是否将文本作为运行时错误抛出；分发结构见 [[内建函数元数据与实现分发]]。^[atlas-core-builtin-registry.md:26-40]

## 通用打印与字符串转换

`print@@T` 按打印表示逐字输出，字符串带引号；在要值的求值级别，它还原样返回参数。`to_string@@T` 产生剥离字符串引号后的拼接串值，`error@@T` 则将这种拼接文本作为运行时错误抛出。^[atlas-core-builtin-registry.md:37-40]

共享辅助逻辑 `to_string_aux` 处理变参元组时，字符串分量不带引号打印，其余分量按 `print` 的规则打印。因此，“剥离”针对字符串分量的引号，非字符串分量仍保留其打印表示；相关规则见 [[上游兼容的值打印约定]]。^[atlas-core-builtin-registry.md:64-67]

## 换行与返回值

`prints` 在当前注册方式中采用普通 scheme `T->void`。它自行追加 `std::endl`，其包装器 `prints_wrapper` 的输出契约是“剥离文本 + 一个换行”；`to_string` 与 `error` 不追加换行。^[atlas-core-builtin-registry.md:37-40, atlas-core-builtin-registry.md:64-67]

## 领域打印与无值求值

`DomainPrinter { name }` 在无值与 `single_value` 两个求值级别都会写报告，并在 `single_value` 级别产出空元组。其无值门之前没有诊断。这一行为与 [[TypedExpr 六族求值与值需求层级]] 相关。^[atlas-core-builtin-registry.md:31-33]

领域调用另有 `DomainNoValue` 策略，以 `Skip`、`Validate`、`BuildAndDrop` 分别规定在 `NoValue` 级别跳过、校验或完整构造后丢弃。补全名清单不能用来推断无值策略，例如 `orientation_nr` 注册为 `BuildAndDrop`；相关说明见 [[BuildAndDrop 领域内建验证策略]]。^[atlas-core-builtin-registry.md:42-47]
