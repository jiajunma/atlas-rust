# 扩展参数的默认扩展

默认扩展是 [[扩展参数值类型 ExtParam]] 的一组构造与判定接口，包括在 KGB 元素 `x` 处构造默认扩展的 `at`，以及 `default_extend`、`default_extend_srm`、`shifted_default_extension` 和 `is_default`。^[ext-param.md:42-52]

## 参数与接口

`ExtParam` 包含 Weyl 元素 `tw`、余权 `l`、有理权 `gamma_lambda`、权 `tau`、余权 `t` 与翻转位。其 `x(ctx)` 方法由 `(tw, l mod 2)` 重建 KGB 元素；默认扩展构造 `at` 则以 KGB 元素 `x` 为构造位置。^[ext-param.md:42-47]

默认扩展一族中，`default_extend_srm` 明确要求 `gamma_lambda` 已在 `x` 处满足 `real_unique`。来源同时列出 `default_extend`、`shifted_default_extension` 与 `is_default`，但未展开它们的具体构造公式或判定条件。^[ext-param.md:49-52]

## 在 finalisation 与符号调校中的作用

默认扩展为 [[扩展参数的 finalisation 驱动]] 提供翻转比较的基准。三个驱动通过队列循环重放 folded-orbit 反射与 [[扩展参数的 star 运算|star]] 下降，并跟踪相对默认扩展的净翻转。`extended_finalise(ctx, sr)` 返回 `Vec<(StandardRepr, bool)>`，其 standard 与 delta-fixed 前置条件通过 `debug_assert` 检查；`scaled_extended_finalise(ctx, sr, factor_num, factor_den)` 返回 `(StandardRepr, bool)`，缩放 $\nu$ 而保持 $\lambda$ 固定。^[ext-param.md:56-62]

在 [[扩展块符号调校的 StarOracle 实现|扩展块符号调校]] 中，`ExtParamOracle` 服务于 `ExtBlock::tune_signs`，每个父块元素的默认扩展通过 `ext_param::def_ext` 重建。另一个实现 `PartialBlockOracle` 以 `PartialBlock` 为父块后端，用于 `ExtBlock::build_partial` 之后的 `tune_signs`。^[ext-param.md:64-68]

## 移植约定与证据边界

默认扩展接口所在模块遵循统一算术约定：`Weight`、`Coweight` 与 `int` 运算采用二进制补码 wrapping i32，有理权分子保持 i64。上游 `assert` 转为 `debug_assert` 或仅在 debug 下执行的 `validate`，真正的数据相关失败通过 [[StructureError 统一错误分类学|StructureError]] 暴露。^[ext-param.md:28-31]
