# 扩展块与 δ-不动部分

扩展块是普通块的 $\delta$-不动部分，其生成元折叠到 $\delta$-轨道中。`ext_block.rs` 覆盖这一结构切片，沿用完整块图的元素编号、cross/Cayley 语义，并以 `None` 表示上游的 `UndefBlock`。扩展参数与 `star` 运算属于后续切片，通过 `StarOracle` trait 注入。^[extended-block.md:19-22]

## 折叠生成元与下降分类

[[折叠生成元与 fold_orbits|fold_orbits(cartan, twist)]] 特化到父块的简单生成元：`twist` 是 $\delta$ 诱导的简单根置换，矩阵约定为 $\mathrm{cartan}[i][j]=\langle\alpha_i,\alpha_j^\vee\rangle$。轨道按 `s0` 递增输出；非对合的 `twist` 对应上游的 “Not a distinguished involution” 错误。^[extended-block.md:39-42]

折叠生成元采用 `ExtGen { kind: ExtGenKind, s0, s1 }` 表示。`kind` 取 `One/Two/Three`，`length()` 分别返回 1、2、3；`One` 情形的 `s1` 使用 `usize::MAX` 哨兵值，对应上游的 `~0`。^[extended-block.md:37-38]

[[DescValue 扩展下降分类]] 包含 32 个变体，按 `One*`、`Two*`、`Three*` 三族排列，`is_descent` 对应奇数枚举值。它提供 `is_complex`、`is_unique_image`、`has_double_image`、`is_like_noncompact` 等十二个谓词，以及 `generator_length` 和 `link_count` 查询。零链接类型如 `OneRealNonparity`、`OneImaginaryCompact` 不记录 cross action。^[extended-block.md:26-31]

`has_october_surprise` 定义为 `generator_length == if has_defect { 3 } else { 2 }`；上游注释将其描述为自 2016 年 10 月起单独标识的、长度差为偶数的链接。^[extended-block.md:31-33]

## 两种构造路径

`extended_type` 在父块上进行纯组合的局部类型识别。全父块构造 `ExtBlock::build` 使用平凡的 [[BlockModifier 块修正子]]，此时 `transformed_twisted` 退化为对两个 KGB 坐标分别调用 `kgb.twisted`，并经 `complete_construction` 与诱导置换 `induced` 完成构造。^[extended-block.md:46-50]

`ExtBlock::build_partial` 以真积分子系统上的 [[公共块的构造与元素编号（PartialBlock）]] 为父块。不动点测试采用 `transformed_twisted` 的 `x + gamma_lambda` 形式：部分块的 `y` 是合成的子系统 y-计数，并非对偶 KGB 元素，因此全块路径的对偶 `kgb.twisted` 测试不适用。此路径中的 `fold_orbits` 使用子系统 Cartan 矩阵与子系统生成元 twist。^[extended-block.md:52-57]

部分块路径在 `complete_construction` 之后通过 cofold 处理生成元姿态：用 `induced(orbits, bm.simple_pi)` 置换 diagram、轨道和链接表，并通过 `bm.simple_pi` 重写轨道成员编号。当前仅移植恒等生成元姿态，此时上述处理为无操作；非恒等的 `bm.simple_pi` 会显式失败。^[extended-block.md:58-61]

## 元素索引与访问

扩展块提供 `rank`（轨道数）、`size`、`orbit(s)`、`folded_generators`、`folded_cartan` 和 `descent_type(s, n)` 等访问器。其中 `folded_cartan` 是上游 `folded_diagram` 的整数矩阵形式。^[extended-block.md:73-75]

[[扩展块与父块的索引映射]] 由 `z(n)` 给出扩展元素 `n` 的父块索引。`element(zz)` 返回满足 `z(n) >= zz` 的最小 `n`，不存在时返回 `size()`；另有 `is_present(zz)` 查询。元素长度继承父块，满足 `length(n) = parent.length(z(n))`。^[extended-block.md:75-77]

## 符号调校与调试验证

`ExtBlock::tune_signs` 通过 `StarOracle` trait 注入逐生成元的 `star` 计算及用于比较的扩展参数值。[[StarOracle 注入与符号调整调试门]] 中的 `check_quadratic` 与 `check_braid` 在 `tune_signs` 内部受 `debug_assertions` 控制运行，对应上游的 `#ifndef NDEBUG` 块。^[extended-block.md:65-69]
