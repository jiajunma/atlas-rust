# 换行抑制状态机

换行抑制状态机是 Atlas 有状态词法器决定是否输出 `Newline` token 的机制：只有能够终止当前命令的换行才可观察，分组构造与续行 token 会抑制换行。扫描器支持解析器或 REPL 逐 token 消费，`tokenize` 则提供完整 token 流的便利接口。^[atlas-core-lex.md:9-13, atlas-core-lex.md:38-43]

## 状态与透出条件

`Lexer` 保存 `offset`、`ended`、`pending`、`nesting`、`prevent_termination`、`previous_termination` 和 `at_command_start`。其中，`nesting` 是由 `Group`、`Let`、`Block` 构成的栈。`skip_space` 在内部消费空白和注释；只有当 `nesting` 与 `prevent_termination` 都为空时，换行才会透出，否则被消费。^[atlas-core-lex.md:40-46]

## 关键字与标点的状态转换

关键字通过栈操作与续行标记控制命令边界。`let` 压入 `Let`；`begin`、`if`、`while`、`for`、`case` 压入 `Block`。`in` 在栈顶为 `Let` 时弹栈并设置 `I`；`end`、`fi`、`od`、`esac` 执行弹栈。`and`、`or`、`not` 设置 `~`，`whattype`、`set`、`set_type` 分别设置 `W`、`S`、`T`。^[atlas-core-lex.md:47-50]

标点也参与状态转换：`(` 与 `[` 压入 `Group`，`)` 与 `]` 执行弹栈；`,`、`;`、`.`、`:` 分别以自身作为抑制标记，`~` 设置 `~`。这些状态共同决定后续换行能否结束当前命令。^[atlas-core-lex.md:40-46, atlas-core-lex.md:51-52]

## 算符与续行规则

`operator_termination` 检查前一个终止符：若它是 `.`，当前算符不再抑制换行，因此“`.` 后接算符”的序列不会吞掉换行；否则，以该算符字符设置抑制状态。^[atlas-core-lex.md:53-54]

`finish_operator` 会尝试跨越空白和注释寻找 `:=`。若找到，则将算符与赋值符融合为一个 `OperatorBecomes` token，并设置 `:`；否则回退扫描偏移，输出普通算符并保留续行标记。注释消费失败时也会回退。该融合属于 [[Atlas 词法 Token 模型]] 的词法行为。^[atlas-core-lex.md:17-20, atlas-core-lex.md:55-57]

关系符有独立规则：由 `<`、`=`、`>` 构成的极大连续段作为一个算符；单个尖括号兼作类型参数定界符，不吞掉换行。这类关系符永不与 `:=` 融合，而 `:=` 自身设置 `:`。裸 `!` 是 const 模式标记，既不是公式算符，也不能作为 operate-assign 的头部；`->`、`~[`、`\%`、`##` 各有专门分支。^[atlas-core-lex.md:58-62]

## 错误恢复与命令边界

遇到不支持的字符时，词法器清空嵌套与抑制状态，使下一个换行能够终止命令。这一规则对应源材料所述的 oracle 行为：报告语法错误，并在下一换行恢复。`recover_command` 则丢弃当前物理行的剩余部分，同时重置续行、嵌套和命令首状态。^[atlas-core-lex.md:63-64, atlas-core-lex.md:78-78]

字符串与指令扫描还具有各自的换行边界。字符串遇到换行会被视为未闭合，产生词法 warning，并将恢复出的 `String` token 放入 `pending`，供解析器继续使用；命令首指令在文件名前遇到换行则得到空文件名，且不消费该行剩余内容，后续由会话帧校验。相关机制见 [[字符串转义与未闭合恢复]] 和 [[命令首指令与文件名扫描]]。^[atlas-core-lex.md:68-77]

## 实现分工与证据边界

源材料记录了覆盖上述状态机分支的 23 个测试，但仅声明完成结构性阅读，不构成语言验收。词法器不承担语义判定；文法适配由 `syntax.rs` 负责，逐命令消费由 `session.rs` 负责，包含与重定向语义由 `session_frame.rs` 负责。可结合 [[多行命令的增量解析]] 理解其调用边界；词法兼容性仍以 HPC 语言语料门为准。^[atlas-core-lex.md:9-13, atlas-core-lex.md:85-91]
