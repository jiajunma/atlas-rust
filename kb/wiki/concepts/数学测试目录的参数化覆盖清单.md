# 数学测试目录的参数化覆盖清单

数学测试目录以 `tests/math/catalog.json` 登记群与操作的参数化组合，由 `templates/` 提供 `.atlas` 模板，并通过语言探针、渐进秩 fixture 与秩 6 清单扩展覆盖。这里的“覆盖”表示用例与目录的清点，不表示正确率或数学验收状态。^[tests-math-library.md:20-30, tests-math-library.md:39-77, tests-math-library.md:91-97]

## 顶层参数化清单

`catalog.json` 使用 schema `atlas-math-catalog-v1`，登记 8 个群与 8 个操作的组合。群包括 classical 类的 A2、B2、C2、D4，以及 exceptional 类的 G2、F4、E6、E7；规模标签分别为 A2/B2/C2/D4/G2 的 `small`、F4 的 `medium`、E6/E7 的 `large`。操作包括 `root_data`、`kgb`、`klv`、`unitarity`、`hodge`、`fpp`、`annihilator_variety` 与 `cycle_foundation`。^[tests-math-library.md:22-26]

清单还包含拒绝模板 `fpp_rank_rejected`，用于秩与有理权尺寸不匹配的诊断；包含语言操作 `generic_pair`、`generic_identity`、`basic_load`，覆盖不依赖 `basic.at` 的最小泛型构造；另有 13 个 `additional_grids`，在 grid 层扩展 groups×operations 覆盖。^[tests-math-library.md:26-30]

## 模板组织

`templates/` 共登记 31 个参数化模板。除八类主要操作外，还提供 `real_form_*` 逐实形变体，涵盖 metadata、KGB、KLV、unitarity、Hodge、FPP、annihilator 与 cycle。^[tests-math-library.md:39-44]

专项模板包括 `partial_kl_*` 的历史、包含、拒绝与回归四类，`hodge_nontrivial`、`hodge_trace`、`fpp_d4_wall`、`cartan_subsystems`、`cycle_product_ranks` 与 `real_forms_inventory`；语言与拒绝场景还包括 `basic_load`、`generic_pair`、`generic_identity`、`fpp_rank_rejected` 和 `partial_kl_nonstandard_rejected`。^[tests-math-library.md:44-48]

## 专项覆盖目录

### 语言探针

`generics/catalog.json` 使用 schema `atlas-generic-language-probes-v1`，登记 273 个用例；快照时目录中有 363 个 `.atlas` 源文件和 52 个 `.oracle.*` 逐字节金标。登记用例数、源文件数与金标数是不同统计口径。fixture 通过 `include_str!` 内嵌并与金标逐字节比较；金标必须来自原版完整流，不能由 Rust 输出充当，相关方法见 [[基于原版金标的差分回归]]。^[tests-math-library.md:50-56]

### 渐进秩门

`progressive/` 共 22 项，以 rank-1 渐进验证 fixture 为主，覆盖 unitarity、Hodge、AV-ann、加载行为、full deformation 和类型等价性，也包含 `cartan_rank1/rank2`、Cartan 类及拒绝用例。期望结果采用两种载体：`.expect.json` 表示结构化断言，`.oracle.stdout` 表示原版逐字节输出流。^[tests-math-library.md:58-67]

### 秩 6 清单

`rank6/catalog.json` 使用 schema `atlas-rank6-inventory-v1`，包含 `rank_bound`、`simple_types`、`unequal_inner_types`、`intermediate_quotients` 与 `numberings` 五个键。配套目录清单为 `blocks/parameters/forms/klv_scale`，fixture 涉及 inventory、KGB、KLV block、parameters、Cartan permutations 与 F4 class trace，另有 `cartan-regressions.patch`。秩 6 的复杂群按实根数据秩 12 计。^[tests-math-library.md:69-77]

## 基准与版本钉定

`benchmarks.json` 使用 schema `atlas-math-benchmarks-v1`，包含 E7、D6、D8 三个 KGB 计时用例，每引擎超时 300 秒，共 4 轮。基准要求新鲜进程、交替执行顺序和同一节点；每轮完整输出必须一致，首次不一致即停止。分钟窗标定按引擎进行，不得将短用例人为垫成分钟级负载。^[tests-math-library.md:31-34]

`baseline.json` 记录 [[双仓库基准版本钉定]]：oracle pin 为 `7e1b958c`，Rust 侧为 `05625c5d`。后者是建立基准时存档的 main 分支历史字节，不代表当前 HEAD。^[tests-math-library.md:35-37]

## 证据边界

本清单依据结构性阅读形成。取证时，`tests/math/catalog.json`、`tests/math/generics/catalog.json` 与 `tests/math/README.md` 存在 owner 未提交修改，`tests/math/rank6/catalog.json` 尚未跟踪；语言探针目录也有未提交修改与未跟踪文件。因此，本页描述的是快照中的工作区结构，不能将其视为全部已提交的内容。README 的运行记录以最新 HANDOFF 或回执优先。^[tests-math-library.md:9-18, tests-math-library.md:52-54]

`tests/fixtures/` 是语言语料库，快照时包含 353 个 `.atlas` 和 1 个 `.at`；可执行 fixture/event/meta 三元组的精确计数与路径敏感清单，以 HANDOFF 的冻结迁移清单为准。`tests/reference/` 保存 oracle 元数据与 HPC 证据。^[tests-math-library.md:79-84]

数学验收应沿 [[HPC 验收证据链]] 查证。`tests/reference/hpc/math_acceptance_index_2026_10_01.json` 是仅追加的验收账本种子，记录以哈希链绑定确切源码、报告、独立审查、选用例 ID、断言与限制；已发布后缀必须具有永久前缀检查点，否则仍为草稿。具体验收状态以账本与 HANDOFF 为准。^[tests-math-library.md:84-87, tests-math-library.md:97-97]

原版可执行文件是语言 oracle，金标应在新鲜进程中捕获完整流，包括拒绝与恢复标记。清单规模不能换算为正确性百分比；checker 自检、标签错配等 harness 失败既不是数学失败，也不能充当数学证据，其不可变失败阶段应保留冻结。^[tests-math-library.md:91-96]
