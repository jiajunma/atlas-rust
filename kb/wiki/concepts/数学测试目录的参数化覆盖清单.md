# 数学测试目录的参数化覆盖清单

数学测试目录以 `tests/math/catalog.json` 登记群与操作的参数化组合，由 `templates/` 提供 `.atlas` 模板，并通过语言探针、渐进秩 fixture 与秩 6 清单扩展覆盖。这些目录描述用例的组织与清点，不表示正确率或数学验收状态。^[tests-math-library.md:9-18, tests-math-library.md:20-77]

## 顶层参数化清单

`catalog.json` 使用 schema `atlas-math-catalog-v1`，登记 8 个群与 8 个操作的组合。群包括 classical 类的 A2、B2、C2、D4，以及 exceptional 类的 G2、F4、E6、E7；其中 A2/B2/C2/D4/G2 标为 `small`，F4 标为 `medium`，E6/E7 标为 `large`。操作包括 `root_data`、`kgb`、`klv`、`unitarity`、`hodge`、`fpp`、`annihilator_variety` 与 `cycle_foundation`。^[tests-math-library.md:22-26]

清单还包含拒绝模板 `fpp_rank_rejected`，用于秩与有理权尺寸不匹配的诊断；三个语言操作 `generic_pair`、`generic_identity`、`basic_load`，用于不依赖 `basic.at` 的最小泛型构造；以及 13 个 `additional_grids`，在 grid 层扩展 groups×operations 覆盖。^[tests-math-library.md:26-30]

## 参数化模板

`templates/` 包含 31 个模板。除八类主要操作外，`real_form_*` 逐实形变体还覆盖 metadata、KGB、KLV、unitarity、Hodge、FPP、annihilator 与 cycle。^[tests-math-library.md:39-44]

专项模板包括 `partial_kl_*` 的历史、包含、拒绝与回归四类，以及 `hodge_nontrivial`、`hodge_trace`、`fpp_d4_wall`、`cartan_subsystems`、`cycle_product_ranks` 和 `real_forms_inventory`。语言与拒绝场景对应 `basic_load`、`generic_pair`、`generic_identity`、`fpp_rank_rejected` 与 `partial_kl_nonstandard_rejected`。^[tests-math-library.md:44-48]

## 专项覆盖目录

### 语言探针

`generics/catalog.json` 使用 schema `atlas-generic-language-probes-v1`，登记 273 个用例；快照时目录有 363 个 `.atlas` 源文件和 52 个 `.oracle.*` 逐字节金标。这三个数字分别描述登记用例、源文件与金标。fixture 经 `include_str!` 内嵌后与金标逐字节比较；金标只能来自原版完整流，不能由 Rust 输出充当，参见 [[基于原版金标的差分回归]]。^[tests-math-library.md:50-56]

### 渐进秩门

`progressive/` 共 22 项，以 rank-1 渐进验证 fixture 为主，包含 unitarity、Hodge、AV-ann、加载行为、full deformation 与类型等价性，也包含 `cartan_rank1/rank2`、Cartan 类及拒绝用例。期望结果采用两种载体：`.expect.json` 保存结构化断言，`.oracle.stdout` 保存原版逐字节输出流。^[tests-math-library.md:58-67]

### 秩 6 清单

`rank6/catalog.json` 使用 schema `atlas-rank6-inventory-v1`，包含 `rank_bound`、`simple_types`、`unequal_inner_types`、`intermediate_quotients` 与 `numberings` 五个键。配套四个目录清单为 `blocks`、`parameters`、`forms` 和 `klv_scale`；fixture 涉及 inventory、KGB、KLV block、parameters、Cartan permutations 与 F4 class trace，另有 `cartan-regressions.patch`。秩 6 的复杂群按实根数据秩 12 计。^[tests-math-library.md:69-77]

## 基准与版本钉定

`benchmarks.json` 使用 schema `atlas-math-benchmarks-v1`，包含 E7、D6、D8 三个 KGB 计时用例，每引擎超时 300 秒，共 4 轮。基准要求新鲜进程、交替执行顺序和同一节点；每轮完整输出必须一致，首次不一致即停止。分钟窗标定按引擎进行，不得将短用例人为垫成分钟级负载。^[tests-math-library.md:31-34]

`baseline.json` 记录双仓库版本钉定：oracle pin 为 `7e1b958c`，Rust 侧为 `05625c5d`。后者是建立基准时存档的 main 分支历史字节，不代表当前 HEAD。^[tests-math-library.md:35-37]

## 语料库与验收证据

`tests/fixtures/` 是语言语料库，快照时包含 353 个 `.atlas` 和 1 个 `.at`。可执行 fixture/event/meta 三元组的精确计数与路径敏感清单，以 HANDOFF 的冻结迁移清单为准；`tests/reference/` 保存 oracle 元数据与 HPC 证据。^[tests-math-library.md:79-84]

`tests/reference/hpc/math_acceptance_index_2026_10_01.json` 是仅追加的验收账本种子。每条验收追加哈希链记录，绑定确切源码、报告、独立审查、选用例 ID、断言与限制；每个已发布后缀必须具有永久前缀检查点，否则仍是草稿。相关机制见 [[数学验收账本的哈希链与永久前缀检查点]]，具体验收状态以账本与 HANDOFF 为准。^[tests-math-library.md:84-87, tests-math-library.md:97-97]

## 证据边界

本页依据结构性阅读形成。取证时，`tests/math/catalog.json`、`tests/math/generics/catalog.json` 与 `tests/math/README.md` 有 owner 未提交修改，`tests/math/rank6/catalog.json` 尚未跟踪；语言探针目录也有未提交修改与若干未跟踪文件。因此，这些统计描述快照中的工作区字节，不能视为全部已提交的内容。README 的逐弧线运行记录遵循“最新 HANDOFF／回执优先于旧记录”的规则。^[tests-math-library.md:9-18, tests-math-library.md:52-54]

原版可执行文件是语言 oracle，金标必须在新鲜进程中捕获完整流，包括拒绝与恢复标记。README 自述的 405 个 Atlas 输入、32 个目录和 798 条 pre-index HPC JSON 记录都是覆盖清单，不能换算为正确性百分比。^[tests-math-library.md:91-94]

checker 自检、标签错配等 harness 失败不是数学失败，也不能充当数学证据；其不可变失败阶段应保留冻结。目录结构与清单规模不能替代 [[HPC 验收证据链]]，本来源不声称任何数学验收。^[tests-math-library.md:16-18, tests-math-library.md:84-87, tests-math-library.md:95-97]
