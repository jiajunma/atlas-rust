# 整数矩阵的幺模对角化

整数矩阵的幺模对角化通过左右幺模变换，将矩阵化为对角形式。`matreduc` 模块的 `diagonalise(m)` 返回 `(row, col, diagonal)`，满足 `row * m * col` 为对角矩阵；对角元素除首项外均为正。内部类型 `IntMatrix` 采用行主序存储矩形整数矩阵，遇到 `0×n` 或 `n×0` 的空形状时提前返回。^[matreduc.md:28-33]

## 逐操作移植的目的

该实现移植自上游 `utilities/matreduc.cpp`，目标不仅是求出任意正确的整数解，还要复现上游选择的那个解。欠定系统 $Ax=b$ 的被选解在下游可观测：$\tau$、$t$ 坐标的奇偶性会进入 `ext_block::same_sign`。因此，移植保留确切的幺模操作序列及行列式符号簿记，并采用 wrapping `i32` 算术，以镜像源材料所述的上游 C++ `int` 行为，包括可影响被选解的溢出行为域。^[matreduc.md:18-26]

## 主元选择与约化过程

基础操作 `divide(a, b)` 对正除数执行向下取整除法：当 `a >= 0` 时直接相除，否则使用 `-1 - ((-1 - a) / b)`，避免直接对 `i32::MIN` 取负。`gcd(row, &mut flip, dest)` 使用 `wrapping_abs` 选择最小绝对值主元，以 `divide` 完成消元；负主元取正时翻转 `flip`，并在记录矩阵中设置 `col.set(mindex, mindex, -1)`；最后将主元列交换至 `dest` 时也翻转 `flip`。^[matreduc.md:35-41]

`diagonalise` 的内层循环交替执行行、列 gcd 操作，并维护 `row_minus` 与 `col_minus`。若主元列尚未左对齐，则使用 `pull_back_columns` 进行稳定排列，同时按逆序对奇偶性计入置换符号。^[matreduc.md:42-46]

## 行列式符号簿记

符号更新次序是兼容契约的一部分。每列首个 gcd 的 `flip` 对 `row_minus` 执行覆盖赋值；内层循环的 `flip` 分别异或到 `col_minus`、`row_minus`。退出循环后还要执行 `row_minus ^= flip`：从行 gcd 的 break 退出时，该 `flip` 计入两侧；从列 gcd 的 break 退出时，其净效果抵消。这些细节可参见 [[对角化的行列式符号簿记]]。^[matreduc.md:42-45]

最终，当 `row_minus != col_minus` 时，`diagonal[0]` 取负；两个符号标志分别通过第 0 行或第 0 列乘以 $-1$ 进行归一。源码注释对行列式约定存在不一致，源材料以测试为准：`|det(row)| == 1`、`det(col) == 1`，而 `det(row)` 可以为 $-1$。因此，不能据“幺模”推断两个变换矩阵的行列式都为 $1$。^[matreduc.md:47-49, matreduc.md:69-70]

## 整数方程求解与失败行为

`has_solution(a, b)` 先对角化矩阵，再将 `b` 左乘 `row`，逐坐标检查可除性，以判定 $ax=b$ 是否存在整数解。`find_solution(a, b)` 返回一个解，无整数解时返回 `None`；上游在这种情况下抛出异常，而 Rust 调用方预期已先执行 `has_solution`。^[matreduc.md:54-59]

维度及索引错误并不统一返回可恢复错误。`from_entries` 的形状、`apply_to` 与 `right_prod` 的长度、`transpose` 的方阵要求，以及 `row_apply`、`column_apply` 的边界均由断言检查。因此，向 `has_solution` 等函数传入长度不匹配的 `b` 会触发 panic，而不是返回 `Err`。^[matreduc.md:50-52]

## 测试与证据边界

测试锚点包括 11 个重构用例，检查变换矩阵行列式、逐项对角结果及首项之外的正性；求解测试覆盖满秩、秩亏和矩形三种形态。`oracle_reference_cases` 固定了 C++ oracle 的精确输出，例如 `[[0,5],[0,0]]` 的对角结果为 `[-5]`，`[[-4]]` 的结果为 `[-4]`；另有一个主元列未左对齐的 6×6 秩亏案例，固定完整 `row`、`col` 及解 `[6,14,5,-37,-421,345]`。^[matreduc.md:69-74]

未覆盖的测试范围包括 wrapping 溢出域、空形状对角化，以及 `from_entries`、`apply_to` 的 panic 路径。模块文档记载已与编译版 oracle 逐位验证，但本来源包仅作结构性阅读，没有重新执行构建、测试或原版运行，也不提供数学验收或性能结论；相关证据应与 [[HPC 验收证据链]] 区分核对。^[matreduc.md:9-16, matreduc.md:75-76, matreduc.md:89-89]
