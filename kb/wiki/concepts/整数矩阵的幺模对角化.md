# 整数矩阵的幺模对角化

`matreduc` 模块的 `diagonalise(m)` 返回 `(row, col, diagonal)`，其中 `row`、`col` 为幺模矩阵，使 `row * m * col` 成为对角矩阵；返回的对角元素除首项外均为正。内部类型 `IntMatrix` 按行主序存储矩形整数矩阵，输入为 `0×n` 或 `n×0` 时提前返回。^[matreduc.md:28-33]

## 逐操作兼容契约

该实现移植自上游 `utilities/matreduc.cpp`，复现确切的幺模操作序列及行列式符号簿记。其动机是欠定系统 $Ax=b$ 的被选解在下游可观测：$\tau$、$t$ 坐标的奇偶性会进入 `ext_block::same_sign`。因此，兼容目标包含上游选出的具体解，详见 [[整数矩阵算法的逐操作保真移植]]。^[matreduc.md:18-26]

算术采用 wrapping `i32`。源材料将这一选择描述为对上游 C++ `int` 行为的精确镜像，包括可能影响被选解的溢出行为域；它属于本模块的移植契约。^[matreduc.md:24-26]

## 主元选择与消元

`divide(a, b)` 对正除数执行下取整除法：当 `a >= 0` 时直接相除，否则使用 `-1 - ((-1 - a) / b)`，避免直接对 `i32::MIN` 取负。`gcd(row, &mut flip, dest)` 使用 `wrapping_abs` 选择最小绝对值主元，并通过 `divide` 消元，参见 [[整数消元中的下取整除法与 gcd 主元选择]]。^[matreduc.md:37-41]

负主元取正时，算法翻转 `flip`，并在记录矩阵中设置 `col.set(mindex, mindex, -1)`；末尾将主元列交换到 `dest` 时也翻转 `flip`。`diagonalise` 的内层循环交替执行行、列 gcd；主元列未左对齐时，使用 `pull_back_columns` 进行稳定排列，并按逆序对奇偶性计入置换符号。^[matreduc.md:39-46]

## 行列式符号簿记

每列首个 gcd 的 `flip` 对 `row_minus` 执行**覆盖赋值**。内层循环中，`flip` 分别异或到 `col_minus`、`row_minus`；退出循环后还执行 `row_minus ^= flip`。从行 gcd 的 break 退出时，该 `flip` 计入两侧；从列 gcd 的 break 退出时，其净效果抵消。此更新次序是 [[对角化的行列式符号簿记]] 的关键。^[matreduc.md:42-45]

最终，当 `row_minus != col_minus` 时，`diagonal[0]` 取负；`row_minus`、`col_minus` 分别通过第 0 行、第 0 列乘以 $-1$ 归一。源码注释对行列式约定存在不一致，源材料明确以测试为准：`|det(row)| == 1`、`det(col) == 1`，而 `det(row)` 可以为 $-1$。^[matreduc.md:47-49, matreduc.md:69-70]

## 求解用途与输入边界

`has_solution(a, b)` 先对角化矩阵，再将 `b` 左乘 `row`，逐坐标检查可除性，以判定 $ax=b$ 是否存在整数解。`find_solution(a, b)` 返回一个解，无整数解时返回 `None`；上游此时抛出异常，Rust 调用方则预期已先运行 `has_solution`。相关接口见 [[整数线性系统求解与像判定]]。^[matreduc.md:54-59]

矩阵基础操作通过断言检查部分输入条件：`from_entries` 检查形状，`apply_to`、`right_prod` 检查长度，`transpose` 要求方阵，`row_apply`、`column_apply` 检查边界。因此，向 `has_solution` 等函数传入长度不匹配的 `b` 会触发 panic，而非返回 `Err`。^[matreduc.md:50-52]

## 测试与证据边界

测试包含 11 个重构用例，检查 `|det(row)| == 1`、`det(col) == 1`、逐项对角结果及首项之外的正性；`find_solution` 测试覆盖满秩、秩亏和矩形三种形态。^[matreduc.md:69-71]

`oracle_reference_cases` 固定了来自 C++ oracle 的精确输出：矩阵 $\begin{pmatrix}0&5\\0&0\end{pmatrix}$ 对应 `diagonal = [-5]` 及精确的 `row`、`col`，矩阵 $\begin{pmatrix}-4\end{pmatrix}$ 对应 `diagonal = [-4]`。另一个主元列未左对齐的 6×6 秩亏案例固定了完整 `row`、`col` 字面量及解 `[6,14,5,-37,-421,345]`，参见 [[整数矩阵移植的 oracle 回归锚点与证据边界]]。^[matreduc.md:71-74]

尚未测试的相关范围包括 wrapping 溢出域、空形状 `diagonalise`，以及 `from_entries`、`apply_to` 的 panic 路径。模块文档记载已与编译版 oracle 逐位验证，但本来源包仅作结构性阅读，未重新执行构建、测试或原版运行，不提供数学验收、性能或并行结论。上游位置转述自源码注释，未独立重读上游，行号可能随版本演进漂移。^[matreduc.md:9-16, matreduc.md:75-76, matreduc.md:85-89]
