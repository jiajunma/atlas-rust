# 整数线性系统求解与像判定

`matreduc` 提供整数线性系统 $Ax=b$ 的可解性判定、选定解构造及像判定。欠定系统的被选解具有下游可观测性：其 $\tau$/$t$ 坐标的奇偶性会进入 `ext_block::same_sign`。因此，移植要求复现上游确切的幺模操作序列及行列式符号簿记，以得到与上游一致的选定解。^[matreduc.md:20-26, matreduc.md:54-61]

## 对角化与可解性判定

内部类型 `IntMatrix` 表示行主序矩形整数矩阵。`diagonalise(m)` 返回 `(row, col, diagonal)`，其中幺模矩阵 `row`、`col` 使 `row * m * col` 成为对角矩阵；对角元素除首项外均为正。空形状 $0\times n$ 或 $n\times0$ 提前返回。符号处理详见 [[对角化的行列式符号簿记]]。^[matreduc.md:30-33]

`has_solution(a, b)` 判定 $ax=b$ 是否存在整数解：先对角化系数矩阵，再将右端向量左乘 `row`，逐坐标检查可除性。^[matreduc.md:56-57]

## 选定解与像判定

`find_solution(a, b)` 返回一个整数解；无整数解时返回 `None`，上游在此情形则抛出异常。该移植的调用方预期先运行 `has_solution`。解的选择受逐操作兼容要求约束，因为被选解的坐标奇偶性会影响下游行为。^[matreduc.md:20-26, matreduc.md:58-59]

`in_left_image` 与 `in_right_image` 提供像判定。二者的源码注释分别对应 `ext_block.cpp` 中的 `in_L_image` 与 `in_R_image`；其上游归属与来自 `matreduc.cpp` 的对角化及求解接口不同。^[matreduc.md:20-21, matreduc.md:60-61]

## 算术与失败边界

模块采用 wrapping `i32` 算术。来源将这一选择描述为镜像上游 C++ `int` 的行为，包括会影响被选解的溢出行为域。底层 `divide(a, b)` 对正除数执行下取整除法；负被除数采用 `-1 - ((-1 - a) / b)`，避免直接对 `i32::MIN` 取负。相关机制见 [[整数消元中的下取整除法与 gcd 主元选择]]。^[matreduc.md:24-26, matreduc.md:37-41]

底层输入检查使用断言：`from_entries` 检查形状，`apply_to`／`right_prod` 检查长度，`transpose` 要求方阵，`row_apply`／`column_apply` 检查边界。因此，向 `has_solution` 等接口传入长度不匹配的 $b$ 会触发 panic，而不是返回 `Err`。这与合法输入下无整数解时 `find_solution` 返回 `None` 的情形不同。^[matreduc.md:50-52, matreduc.md:58-59]

## 测试与证据范围

来源列出的测试覆盖 `find_solution` 的满秩、秩亏与矩形三种形态，以及一维像判定。对角化的 11 个重构用例检查 $|\det(\mathrm{row})|=1$、$\det(\mathrm{col})=1$、逐对角一致性及首项外为正。`oracle_reference_cases` 使用 C++ oracle 数据锚定精确结果，其中包含主元列未左对齐的 $6\times6$ 秩亏案例，记录完整 `row`／`col` 字面量及选定解 $[6,14,5,-37,-421,345]$。^[matreduc.md:69-74]

已列出的覆盖缺口包括 wrapping 溢出域、`in_*_image` 的矩形与秩亏输入、空形状对角化，以及 `from_entries`／`apply_to` 的 panic 路径。^[matreduc.md:75-76]
