# 文件命令兼容性的证据边界

文件命令兼容性涉及文件包含、单命令输出重定向、框架提示行、值输出、错误级联及决定会话退出状态的 clean 标志。来源对 `crates/atlas-core/src/session_frame.rs` 的 993 行代码完成了结构性阅读，其中生产代码位于第 1–588 行，文件内有 18 个测试；这一阅读状态不构成语言或数学验收。^[atlas-core-session-frame.md:9-16]

## 证据层次

结构性阅读记录实现的组织与行为约定。材料中对上游 `buffer.w`、`main.w`、`parser.y` 的行号引用属于实现方的移植陈述，端到端可见行为仍以 HPC 差分语料为准；相关背景见 [[HPC 验收证据链]]。^[atlas-core-session-frame.md:94-97]

18 个文件内测试提供**单元级行为锚点**，覆盖字节保留、包含控制、重定向时序与失败处理、深度缩进、void 抑制、续行、尾 token 语法错误及物理行报告。来源明确将端到端文件命令兼容性留给 HPC 语料门，并指出 `eval/file_commands_b9` 是所引用语料清单中唯一允许写入 `/tmp` 的用例。^[atlas-core-session-frame.md:81-90]

## 兼容性核对的关键行为

### 文件包含与退出传播

`<file` 带有 include-once 簿记，`<<file` 强制重读。包含判定依次涉及输入名称、解析后路径、当前活动栈与深度上限：已完成的普通包含静默跳过；已在活动栈中的文件也静默跳过并视为成功；正常完成后记录 `completed` 并打印完成框架行。包含内部的 `quit` 会结束整个会话。详见 [[SessionFrame 会话帧与文件包含语义]]。^[atlas-core-session-frame.md:11-15, atlas-core-session-frame.md:29-48]

路径解析按 `search_path` 顺序进行，每个前缀下先尝试原名，名称不带 `.at` 时再尝试追加该后缀；表示当前工作目录的空前缀最后尝试。包含深度上限为 `MAX_INCLUDE_DEPTH = 64`，与检测真实递归的活动栈守卫分别承担约束。参见 [[包含文件的搜索路径解析]]。^[atlas-core-session-frame.md:29-42]

### 重定向时序与失败处理

[[单命令输出重定向的执行纪律]]要求命令体先按表达式解析，解析成功后、求值之前才打开 sink。因此，语法错误不创建文件，求值失败仍留下可能含有部分输出的文件。重定向打开失败只输出裸 stderr 行 `Failed to open {name}`，会话保持 clean；命令的 `Output`／`OutputBytes` 事件写入 sink，其余事件照常上行，`sink.close()` 无条件执行。^[atlas-core-session-frame.md:23-25, atlas-core-session-frame.md:59-65]

### clean 标志与错误级联

语法、类型和求值错误会使会话变脏，打开失败与 abandon 级联本身不会。词法 warning 只报告，不弄脏会话也不中止；真正的词法错误会置 dirty，并在包含深度大于零时触发 abandon 级联。各层 abandon 消息按最内层优先的顺序发出。参见 [[会话 clean 标志与诊断分流]] 与 [[嵌套包含的 abandon 级联]]。^[atlas-core-session-frame.md:43-46, atlas-core-session-frame.md:66-70]

### 输出字节与诊断位置

非 void 的 `SessionEvent::Value` 打印为 `Value: <display>`，void（空元组）不打印。`ReportLine`／`ReportBytes` 按当前包含深度每层缩进两空格，`ReportBytes` 经 `SessionEvent::output` 保留字节。输入读取采用有损 UTF-8；输出侧测试覆盖冻结原版字节、重定向中的嵌套值字节，以及运行时错误和 back_trace 的原始字节。详见 [[SessionEvent 与字节保留输出]]。^[atlas-core-session-frame.md:20-22, atlas-core-session-frame.md:52-55, atlas-core-session-frame.md:83-84]

预处理先剥除每行尾部空白，再将以 `\` 结尾的行与下一行直接拼接，不插入额外内容。`line_map` 将重写行映射到首个物理行，供诊断与 abandon 使用；有 span 的诊断包含来源、物理行号、列号、消息、源行和 caret，无 span 的诊断仅使用裸 `{Kind} error:` 头。^[atlas-core-session-frame.md:72-79]

## 适用范围与限制

来源提供实现约定与单元级测试覆盖说明，未报告端到端 HPC 差分通过结果。会话层外层循环与 `SessionEvent` 定义属于另一个来源包，表达式解析和执行分别位于 `syntax.rs` 与 `typed.rs`；本包的结构性阅读范围不等于完整语言执行链的验收范围。^[atlas-core-session-frame.md:9-16, atlas-core-session-frame.md:81-97]

快照的 Git base 为 `964f0033`。字节数与哈希仅标识该快照的字节，不能证明字节正确；实现方的上游引用也不能替代 HPC 差分语料提供的端到端可见行为证据。^[atlas-core-session-frame.md:96-99]
