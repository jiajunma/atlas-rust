# 最小环面算法的测试覆盖边界

最小环面算法的四个测试锚点均限于 **rank 2、紧致内类**，涉及特定种子案例与部分输入拒绝行为。来源是对 `crates/atlas-real-group/src/minimal_torus.rs` 的结构性阅读，不声称数学验收；其中的上游引用仅转录自代码注释，未核对上游文件字节。^[minimal-torus.md:9-13, minimal-torus.md:78-87]

## 测试对象与锚点

两个公开函数服务自定义种子分支：`elected_square_root` 计算选定余特征 `coch`；`minimal_torus_part` 将强代表下降到基本纤维，再搜索符合目标弱实形紧致性模式的数值最小环面部分。相关流程见 [[合成实形的选定余特征]] 与 [[最小环面部分的 grading 轨道搜索]]。^[minimal-torus.md:17-25]

来源列出以下四个测试锚点。表中的结果是源码阅读记录的检查内容，不是本次知识维护运行所得的结果。^[minimal-torus.md:78-87, minimal-torus.md:104-108]

| 测试锚点 | 场景 | 检查内容 |
| --- | --- | --- |
| A1.T1 中心因子 | 对合翻转半单坐标，中心坐标承载整个环面因子 | `coch == factor`，环面部分为零；冻结锚点为 `weak_real_form_a1_t1_central_probe` |
| A2 非典范种子 | `[1/3, 2/3]` 配 `s0`；`[2/3, 1/3]` 配 `s1` | 因子各自保持，环面部分分别在坐标 0、坐标 1 置位；冻结锚点为 `weak_real_form_a2_noncanonical_probe` |
| 等价因子 | 语言层投影的等价类 | 等价因子选出同一种子 |
| 门控拒绝 | 长度不符、空 `InvolutionTable` | 明确拒绝；空表触发具名错误，而非静默查找失败 |

## 正例的区分能力

三个正例均满足 `coch == factor`，因此现有断言没有可区分地刻画非平凡运输时的行为。第三个测试与第二个测试的第一组输入完全相同；来源指出，其独立价值仅体现在注释叙述中。^[minimal-torus.md:89-91]

`elected_square_root` 的实现包含由约化词重建 Weyl 作用、通过往返校验固定字合成方向，以及依次施加 distinguished 对合和 Weyl 元素的余权作用。这些实现步骤的存在，不改变来源将非平凡运输列为测试缺口的结论。^[minimal-torus.md:35-42, minimal-torus.md:97-98]

## 未覆盖的分支与资源边界

来源明确列出的测试缺口包括非紧致 distinguished、多数具名错误分支、`rank > 63` 的资源门，以及非平凡运输。超过秩上限时，`minimal_torus_part` 返回 `SeedResourceLimit { resource: "mask bits" }`；该函数没有显式预算参数，仅有 `MAX_MASK_BITS` 与分配防护。参见 [[合成实形种子算法的门控与资源限制]]。^[minimal-torus.md:46-48, minimal-torus.md:95-100]

实现还检查 `factor − coch` 的逐坐标整性、对合表覆盖、逆 Cayley 返回 `Ok(None)` 的情况，以及轨道搜索候选集是否为空；空候选触发 `"minimal torus part candidates"` 错误。测试摘要明确列出的拒绝案例仅为长度不符和空表，没有提供全部失败路径的覆盖记录。^[minimal-torus.md:50-61, minimal-torus.md:72-75, minimal-torus.md:86-98]

## 兼容性声明的证据边界

在 [[强代表下降到基本纤维]] 的过程中，Rust 在每个中间环面部分的目标对合处约化，上游则只在末尾约化。代码注释声明，这些操作是 mod-2 商上的类映射，因此逐步约化不改变最终约化类；虽然注释援引 stage-(e) KGB 枚举的验证，来源包本身未验证这一性质。^[minimal-torus.md:27-29]

[[基本虚根 grading 的位置约束]] 涉及另一项注释声明：Rust 按虚根基的实际位置配对目标 grading，上游则依赖 datum 单根位于前导段的编号不变量。注释声称，在该不变量成立时，特别是平凡 distinguished 情形下，两者一致。来源未将此提升为独立验证结果，并明确非紧致 distinguished 尚未获测试覆盖。^[minimal-torus.md:63-71, minimal-torus.md:95-98]
