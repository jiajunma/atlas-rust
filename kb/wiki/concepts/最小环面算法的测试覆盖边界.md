# 最小环面算法的测试覆盖边界

最小环面算法的现有四个测试锚点均为 rank 2、紧致内类，覆盖若干冻结案例与入口拒绝行为。来源属于结构性源码阅读，不构成数学或正确性验收；其中的上游引用转录自代码注释，未核对上游原始字节。^[minimal-torus.md:9-13, minimal-torus.md:78-98]

## 测试覆盖

测试涉及两个函数：`elected_square_root` 计算自定义种子的选定余特征 `coch`；`minimal_torus_part` 将强代表下降到基本纤维，再搜索符合目标弱实形紧致性模式的最小环面部分。相关概念见 [[合成实形的选定余特征]] 与 [[最小环面部分的 grading 轨道搜索]]。^[minimal-torus.md:17-25]

来源列出的四个测试锚点如下。^[minimal-torus.md:78-87]

| 测试锚点 | 场景 | 检查内容 |
| --- | --- | --- |
| A1.T1 中心因子 | 对合翻转半单坐标，中心坐标承载整个环面因子 | `coch == factor`，环面部分为零；冻结锚点为 `weak_real_form_a1_t1_central_probe` |
| A2 非典范种子 | `[1/3, 2/3]` 配 `s0`；`[2/3, 1/3]` 配 `s1` | 因子各自保持，环面部分分别在坐标 0 与坐标 1 置位；冻结锚点为 `weak_real_form_a2_noncanonical_probe` |
| 等价因子 | 语言层投影的等价类 | 等价因子选出同一种子 |
| 门控拒绝 | 长度不符、空 `InvolutionTable` | 明确拒绝；空表触发具名错误，而非静默查找失败 |

## 正例的区分能力

三个正例都满足 `coch == factor`，因此现有断言没有可区分地刻画非平凡运输时的行为。第三个测试与第二个测试的第一组输入完全相同；来源指出，其独立价值仅体现在注释叙述中。^[minimal-torus.md:89-91]

`elected_square_root` 的实现包含由约化词重建 Weyl 作用、往返校验字合成方向，以及依次施加 distinguished 对合和 Weyl 元素的余权作用。已有正例的上述限制意味着，不能仅凭这些锚点认定非平凡运输已获得充分测试。^[minimal-torus.md:35-42, minimal-torus.md:89-91]

## 未覆盖的分支与资源边界

来源明确列出的测试缺口包括非紧致 distinguished、多数具名错误分支、`rank > 63` 的资源门，以及非平凡运输。格秩超过 63 时，入口返回 `SeedResourceLimit { resource: "mask bits" }`；`minimal_torus_part` 没有显式预算参数，仅有 `MAX_MASK_BITS` 与分配防护。相关约束见 [[合成实形种子算法的门控与资源限制]]。^[minimal-torus.md:46-48, minimal-torus.md:95-100]

实现还包含 `factor − coch` 的逐坐标整性检查、对合表覆盖检查、逆 Cayley 返回 `Ok(None)` 时的拒绝，以及候选集为空时的具名错误 `"minimal torus part candidates"`。测试摘要只明确列出长度不符和空表拒绝，不能据此将所有失败路径视为已验证。^[minimal-torus.md:50-61, minimal-torus.md:72-75, minimal-torus.md:86-98]

## 实现声明与验证证据

在 [[强代表下降到基本纤维]] 的过程中，Rust 在每个中间环面部分的目标对合处约化，上游则只在末尾约化。代码注释声明，这些操作是 mod-2 商上的类映射，因此逐步约化不改变最终约化类；注释虽引用 stage-(e) KGB 枚举的验证，本来源包并未验证该性质。^[minimal-torus.md:27-29]

[[基本虚根 grading 的位置约束]] 也有独立的兼容性边界：Rust 按基本虚根基的实际位置配对目标 grading，上游则依赖 datum 单根位于前导段的编号不变量。注释声明两种方式在该不变量成立时一致，特别包括平凡 distinguished 情形；这一声明不能替代非紧致 distinguished 的测试覆盖。^[minimal-torus.md:63-71, minimal-torus.md:95-98]
