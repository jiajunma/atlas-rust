# 最小环面算法的测试覆盖边界

最小环面算法的现有测试集中于低秩、紧致内类的冻结案例与少量入口拒绝行为。来源列出四个测试锚点，均为 rank 2；该材料属于结构性源码阅读，不构成数学或正确性验收，上游引用也未核对原始字节。^[minimal-torus.md:9-13, minimal-torus.md:78-87, minimal-torus.md:95-98]

## 测试覆盖

测试涉及 [[合成实形的选定余特征]]与 [[最小环面部分的 grading 轨道搜索]]。前者由环面因子计算 `coch`，后者将强代表下降到基本纤维，再搜索符合目标弱实形紧致性模式的最小环面部分。^[minimal-torus.md:17-25]

四个测试锚点的具体范围如下。^[minimal-torus.md:78-87]

| 测试锚点 | 输入或场景 | 检查内容 |
| --- | --- | --- |
| A1.T1 中心因子 | 对合翻转半单坐标，中心坐标承载整个环面因子 | `coch == factor`，环面部分为零；冻结锚点为 `weak_real_form_a1_t1_central_probe` |
| A2 非典范种子 | `[1/3, 2/3]` 配 `s0`；`[2/3, 1/3]` 配 `s1` | 因子各自保持，环面部分分别在 `[0]` 与 `[1]` 置位；冻结锚点为 `weak_real_form_a2_noncanonical_probe` |
| 等价因子 | 语言层投影的等价类 | 等价因子选出同一种子 |
| 门控拒绝 | 长度不符、空 `InvolutionTable` | 明确拒绝；空表触发具名错误，而非静默查找失败 |

## 正例的区分能力

三个正例都满足 `coch == factor`，因此现有断言没有可区分地刻画非平凡运输时的行为。第三个测试与第二个测试的第一组输入完全相同；来源指出，其独立价值仅体现在注释叙述中，不能据此视为新增了不同输入的覆盖。^[minimal-torus.md:89-91]

## 未覆盖的分支与资源边界

来源明确列出的测试缺口包括非紧致 distinguished 对合、多数具名错误分支、`rank > 63` 的资源门，以及非平凡运输。算法入口在格秩超过 63 时返回 `SeedResourceLimit { resource: "mask bits" }`；`minimal_torus_part` 没有显式预算参数，仅有 `MAX_MASK_BITS` 与分配防护。相关约束见 [[合成实形种子算法的门控与资源限制]]。^[minimal-torus.md:46-48, minimal-torus.md:95-100]

算法还包含逐坐标整性检查、对合表覆盖检查、逆 Cayley 无结果时的拒绝，以及候选集为空时的具名错误。现有测试摘要只明确覆盖长度不符和空表拒绝，不能据此声称这些失败路径均已验证。^[minimal-torus.md:50-61, minimal-torus.md:72-75, minimal-torus.md:86-98]

## 实现声明与验收证据的区别

[[TitsCoset 逐步约化的类映射依据]]涉及一项注释声明：下降操作是 mod-2 商上的类映射，因此逐步约化不改变最终约化类。来源虽然记录了注释对 stage-(e) KGB 枚举验证的引用，但本包并未验证该性质。^[minimal-torus.md:27-29]

[[基本虚根 grading 的位置约束]]也有独立的兼容性边界：Rust 按基本虚根基的实际位置配对目标 grading，上游则依赖 datum 单根位于前导段的编号不变量。两种方式在该不变量成立时一致，特别包括平凡 distinguished 情形；来源将这一一致性归为注释声明，现有测试未覆盖非紧致 distinguished 情形。^[minimal-torus.md:63-71, minimal-torus.md:95-98]
