# 有理权的公共分母表示与归一化

`RationalWeight` 用 `numerator: Vec<i64>` 和公共分母 `denominator: i64` 表示有理权，各坐标共享同一个分母。这与 `RationalCoweight` 的逐坐标 `Rational` 表示不同。格类型层刻意采用 checked 固定宽度存储，精确解释器值在领域边界转换。^[lattice-types.md:17-25, lattice-types.md:75-79]

## 构造与归一化

`RationalWeight::new(numerator, denominator)` 在构造时执行 gcd 归一化，并要求分母严格为正。若 `denominator <= 0`，返回 `RepInvariantViolation { invariant: "rational weight denominator" }`；源材料对照的上游 `normalize` 则拒绝零分母。`from_weight` 将整权转换为分母为 1 的有理权。^[lattice-types.md:43-47]

归一化时机是方法契约的一部分：`normalized` 重新调用构造器进行 gcd 归一化，而 `halve` 仅将分母翻倍，刻意不归一化，把后续归一化交给调用方；这一行为与上游一致。因此，不能假定所有方法返回的有理权都已经约分。^[lattice-types.md:51-53]

## 算术与坐标提取

`zero(rank)`、`add` 和 `sub` 都返回 `Result`。加减法通过内部 `combine` 交叉相乘以形成公分母，再归一化结果；`scale(numerator, denominator)` 在标量乘法后归一化，其分母相关不变量标识为 `"rational weight scale denominator"`。^[lattice-types.md:46-47, lattice-types.md:56-58]

`apply_matrix` 保持分母不变，仅对分子施加矩阵作用。`integral_coordinates` 检查各分子坐标能否被公共分母整除，将上游的整除断言转化为可检查的整性条件，使用 `"rational weight integrality"` 不变量标识。^[lattice-types.md:51-55]

`dot_coroot` 对应上游 `dot_Q`，返回已约分的 `(i64, i64)`。其秩失配错误使用 `expected: coroot.rank(), actual: self.rank()`，字段顺序与 `pair`、`combine` 的惯例相反；理解错误处理时可关联 [[StructureError 统一错误分类学]]。^[lattice-types.md:59-64]

## 实现细节与证据边界

构造器中的 `i64::try_from(gcd)` 和 `checked_div` 保留防御性溢出检查，但在当前不变量下，这两个溢出分支不可达。本文件的 `gcd_u64` 返回 `left.max(1)`，因此规定 `gcd(0,0)=1`；它与 `global_kgb.rs` 的同名私有实现存在差异，不过两处调用点均因分母恒正而安全。^[lattice-types.md:67-71]

源材料来自对 `lattice.rs` 的两次结构性阅读，两次检查的文件字节与 SHA-256 相同。该材料未执行构建、测试或原版运行，不提供数学验收、性能或并行结论；实现正确性的验证仍属于独立的 [[HPC 验收证据链]]。^[lattice-types.md:9-13, lattice-types.md:83-89]
