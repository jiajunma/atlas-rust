# 有理权的矩阵作用、整性检查与余根配对

`RationalWeight` 用 `numerator: Vec<i64>` 与公共分母 `denominator: i64` 表示有理权。其矩阵作用、整性检查与余根配对围绕这一表示展开；坐标刻意采用 checked 固定宽度存储，精确解释器值在领域边界处转换。^[lattice-types.md:17-25]

## 表示与归一化

`RationalWeight::new` 在构造时进行 gcd 归一化，并要求分母严格为正；非正分母返回 `RepInvariantViolation { invariant: "rational weight denominator" }`。`from_weight` 将整权转换为分母为 1 的有理权。^[lattice-types.md:43-47]

归一化时机也是接口契约的一部分：`halve` 只将分母翻倍，刻意不归一化；调用方可用 `normalized` 重新执行构造器的 gcd 归一化。`scale(numerator, denominator)` 则在标量乘法后归一化。^[lattice-types.md:51-58]

## 矩阵作用

`apply_matrix` 保持公共分母不变，仅对分子施加矩阵作用。这一行为对应源码注释所引用的上游 `ratvec.cpp:190`。^[lattice-types.md:51-51]

矩阵形状诊断有一处需要保留的实现细节：即使失配发生在某一行的长度，错误中的 `actual` 仍填为 `matrix.len()`，不能将该字段直接理解为出错行的长度。^[lattice-types.md:65-66]

## 整性检查

`integral_coordinates` 将上游的 `assert(entry % denominator == 0)` 转化为可检查的整性条件：每个分子坐标都必须能被公共分母整除。对应的不变量标识为 `"rational weight integrality"`，来源注释指向 `repr.cpp:194-199、768-774`。^[lattice-types.md:54-55]

## 余根配对

`dot_coroot` 对应上游 `dot_Q`，返回已约分的 `(i64, i64)`，以分子、分母二元组表示配对结果。来源注释指向 `ratvec.h:167-175`。^[lattice-types.md:59-59]

秩不一致时，`dot_coroot` 的 `RankMismatch` 使用 `expected: coroot.rank()` 与 `actual: self.rank()`；这一字段顺序与 `pair`、`combine` 的惯例相反。比较或解释错误时应保留这一差异，可结合 [[StructureError 统一错误分类学]] 阅读。^[lattice-types.md:63-64]

作为对照，整权与整余权的 `pair(weight, coweight)` 先检查秩一致，再通过 `i128` checked 累加计算配对，最后用 `i32::try_from` 收窄。`Weight` 与 `Coweight` 虽有完美配对，仍是不可互换的独立 newtype，即使所选基下坐标相同也如此。^[lattice-types.md:22-31]
