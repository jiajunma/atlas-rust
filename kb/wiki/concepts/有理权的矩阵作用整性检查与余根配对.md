# 有理权的矩阵作用、整性检查与余根配对

`RationalWeight` 使用 `numerator: Vec<i64>` 与公共分母 `denominator: i64` 表示有理权。`apply_matrix`、`integral_coordinates` 和 `dot_coroot` 分别负责矩阵作用、整坐标提取与余根配对。其坐标刻意采用带检查的固定宽度存储，精确解释器值在领域边界处转换，参见 [[格坐标的固定宽度检查算术]]。^[lattice-types.md:17-25, lattice-types.md:51-59]

## 表示与归一化

`RationalWeight::new` 在构造时进行 gcd 归一化，并要求分母严格为正；非正分母返回 `RepInvariantViolation { invariant: "rational weight denominator" }`。`from_weight` 将整权表示为分母为 1 的有理权。相关约定见 [[有理权的公共分母表示与归一化]]。^[lattice-types.md:43-47]

归一化时机取决于具体操作：`halve` 仅将分母翻倍，刻意不归一化，由调用方决定归一化时机；`normalized` 重新执行构造器的 gcd 归一化；`scale(numerator, denominator)` 则在标量乘法后归一化。^[lattice-types.md:51-58]

## 矩阵作用

`apply_matrix` 保持公共分母不变，仅对分子施加矩阵作用。源材料将这一行为对应到上游 `ratvec.cpp:190`。^[lattice-types.md:51-51]

矩阵维度错误的诊断存在一处特殊约定：即使失配发生在某一行的长度，错误字段 `actual` 仍填写 `matrix.len()`，而非该行的长度。解读诊断时应保留这一实现细节。^[lattice-types.md:65-66]

## 整性检查

`integral_coordinates` 将上游断言 `assert(entry % denominator == 0)` 转化为可检查的整性条件：每个分子坐标必须能被公共分母整除。对应的不变量标识为 `"rational weight integrality"`；源材料中的上游位置为 `repr.cpp:194-199、768-774`。^[lattice-types.md:54-55]

## 余根配对

`dot_coroot` 对应上游 `dot_Q`，返回已约分的 `(i64, i64)` 有理配对结果。源材料中的上游位置为 `ratvec.h:167-175`。^[lattice-types.md:59-59]

秩不一致时，`dot_coroot` 的 `RankMismatch` 字段为 `expected: coroot.rank()`、`actual: self.rank()`。这一顺序与 `pair`、`combine` 的惯例相反，参见 [[StructureError 统一错误分类学]]。^[lattice-types.md:63-64]

作为对照，整权与整余权的 `pair(weight, coweight)` 先检查秩一致，使用 `expected: weight.rank()`、`actual: coweight.rank()`，再委托坐标级配对，以 `i128` checked 累加并通过 `i32::try_from` 收窄。相关接口见 [[权与余权的典范配对]]。^[lattice-types.md:29-31]

`Weight` 与 `Coweight` 虽具有完美配对，仍是不可互换的独立 newtype；即使所选基给出相同坐标表示，也不能混用。这一类型纪律见 [[权格与余权格的类型隔离]]。^[lattice-types.md:22-25]
