# 有理权的矩阵作用、整性检查与余根配对

`RationalWeight` 以分子向量 `numerator: Vec<i64>` 和公共分母 `denominator: i64` 表示有理权。`apply_matrix`、`integral_coordinates` 与 `dot_coroot` 分别提供矩阵作用、整坐标提取和余根配对。格坐标刻意采用带检查的固定宽度存储，精确解释器值在领域边界处转换。^[lattice-types.md:17-25, lattice-types.md:51-59]

## 表示与归一化

`RationalWeight::new` 在构造时进行 gcd 归一化，并要求分母严格为正；非正分母触发 `RepInvariantViolation { invariant: "rational weight denominator" }`。`from_weight` 将整权表示为分母为 1 的有理权；`add`、`sub` 通过交叉相乘形成公共分母，再归一化，返回 `Result`。^[lattice-types.md:43-47]

归一化时机取决于操作：`halve` 仅将分母翻倍，刻意不归一化，将归一化时机交给调用方；`normalized` 重新执行构造器的 gcd 归一化；`scale(numerator, denominator)` 则在标量乘法后归一化。^[lattice-types.md:51-58]

## 矩阵作用

`apply_matrix` 保持公共分母不变，仅对分子施加矩阵作用。源材料将这一行为对应到上游 `ratvec.cpp:190`。^[lattice-types.md:51-51]

维度错误的字段填报有一处特殊约定：即使失配发生在矩阵某一行的长度，`actual` 仍填写 `matrix.len()`，而非失配行的长度。解读诊断时需保留这一区别。^[lattice-types.md:65-66]

## 整性检查

`integral_coordinates` 将上游断言 `assert(entry % denominator == 0)` 转为可检查的整性条件：每个分子坐标必须能被公共分母整除。相关不变量标识为 `"rational weight integrality"`；源材料注明的上游位置为 `repr.cpp:194-199、768-774`。^[lattice-types.md:54-55]

## 余根配对与秩诊断

`dot_coroot` 对应上游 `dot_Q`，返回已约分的 `(i64, i64)` 有理配对结果。源材料注明的上游位置为 `ratvec.h:167-175`。^[lattice-types.md:59-59]

秩不一致时，`dot_coroot` 的 `RankMismatch` 字段为 `expected: coroot.rank()`、`actual: self.rank()`，与 `pair`、`combine` 的惯例相反。相关错误类型可参见 [[StructureError 统一错误分类学]]。^[lattice-types.md:63-64]

作为对照，整权与整余权的 `pair(weight, coweight)` 先检查秩一致，使用 `expected: weight.rank()`、`actual: coweight.rank()`，再委托 `pair_coordinates`，以 `i128` 进行带检查的累加，并通过 `i32::try_from` 收窄结果。内部辅助函数 `pair_coordinates` 使用 `zip`，由调用方保证维度一致，避免截断。^[lattice-types.md:29-34]

配对关系并不消除类型区别：`Weight` 与 `Coweight` 是刻意分离的两个 newtype，分别表示特征格 \(X^*\) 与余特征格 \(X_*\)。两格之间虽有完美配对，即使所选基给出相同坐标表示，也不可互换。^[lattice-types.md:17-25]
