# 未移植代码路径的显式失败语义

`StructureError::NotYetImplemented { feature }` 表示上游 oracle 已定义、但 `atlas-real-group` 尚未移植的代码路径。其语义是显式报错，避免在错误近似上继续计算；它标记的是实现缺口，而非上游行为未定义。^[error-global-tits.md:53-56]

## 错误类型与表达

`NotYetImplemented` 属于 [[StructureError 统一错误分类学]]，携带 `feature` 字段，也是该枚举中唯一带文档注释的变体。源码将其与 `InvalidIntegerMatrixShape`、`ArithmeticOverflow` 一同列入算术与移植状态类别，但明确赋予它“尚未移植代码路径”的含义。^[error-global-tits.md:53-56]

`StructureError` 实现了 `std::error::Error`，其 `source()` 等方法使用默认实现。`error.rs` 不提供构造函数或 `From` 转换，错误构造点分散在各子系统中；该文件也没有序列化机制或错误码，`Display` 使用包含字段插值的英文固定字符串。^[error-global-tits.md:18-21, error-global-tits.md:149-149]

## 证据边界

现有来源支持上述错误契约，但没有列出 `NotYetImplemented` 的具体触发功能或全部调用位置。`global_tits.rs` 直接构造的七种错误不包含该变体；其依赖调用通过 `?` 传播的具体错误变体不在来源覆盖范围内，因此不能据此断言全局 Tits 传输绝不会传播此错误。^[error-global-tits.md:112-116, error-global-tits.md:154-154]

该来源属于结构性阅读，不构成错误覆盖面或数学验收的证明。`error.rs` 没有测试模块，本次知识维护也未执行 Atlas、Cargo、测试或 benchmark；因而这里记录的是源码所表达的失败语义，并非该语义已被运行验证的结论。^[error-global-tits.md:9-14, error-global-tits.md:120-120, error-global-tits.md:158-162]
