# 权与余权的简单反射及算术保护

`BasedRootDatum` 通过 `reflect_weight` 与 `reflect_coweight` 实现权与余权上的简单反射。反射系数由配对确定，底层 `reflect_coordinates` 使用 `i128` 中间值，并对分配、坐标乘减和最终整数转换进行错误检查。^[root-datum-dual.md:81-92]

## 反射公式

对生成元 $g$，记简单根为 $\alpha_g$、简单余根为 $\alpha_g^\vee$。权 $x$ 上的反射为 $s_g(x)=x-\langle x,\alpha_g^\vee\rangle\alpha_g$，余权 $y$ 上的反射为 $s_g(y)=y-\langle\alpha_g,y\rangle\alpha_g^\vee$。`reflect_weight(generator, weight)` 使用 `pair(weight, &simple_coroots[generator])` 计算系数；`reflect_coweight` 使用对偶公式。^[root-datum-dual.md:83-88]

## 输入检查与构造不变量

[[BasedRootDatum：带基根数据与构造不变量|BasedRootDatum]] 区分 `lattice_rank` 与 `semisimple_rank`：前者是整个约化环面的秩，后者是简单根个数，也是 Cartan 矩阵阶数。含中心环面时，`lattice_rank` 可以大于 `semisimple_rank`；坐标维数与生成元下标分别受这两个秩约束。^[root-datum-dual.md:18-21, root-datum-dual.md:48-51, root-datum-dual.md:83-85]

`reflect_weight` 先检查 `weight.rank() == lattice_rank`，不符时返回 `StructureError::RankMismatch`；随后通过 `.get(generator)` 检查生成元下标，越界时返回 `IndexOutOfRange { index, upper_bound: semisimple_rank }`。因此，维数错误先于生成元越界报告。^[root-datum-dual.md:83-85]

实现通过 `.get()` 检查一个数组后，直接索引另一个等长数组。其安全性依赖构造门控：简单根与简单余根数组长度均为 `semisimple_rank`，每个向量的维数均为 `lattice_rank`；构造器还逐项验证根与余根的配对符合 Cartan 矩阵。^[root-datum-dual.md:41-46, root-datum-dual.md:89-92]

## 算术与分配保护

`reflect_coordinates` 全程采用 `i128` 中间值，通过 `checked_mul` 与 `checked_sub` 完成坐标乘减，再以 `i32::try_from` 收窄为存储坐标。乘法、减法或收窄失败均返回 `ArithmeticOverflow`；结果空间通过 `try_reserve_exact` 申请，分配失败返回 `AllocationFailed`。相关错误分类见 [[StructureError 统一错误分类学]]。^[root-datum-dual.md:89-91]

这里的 `i128` 保护明确针对底层坐标更新过程。来源没有覆盖 `Weight`、`Coweight` 与 `pair` 的定义，因此不能仅凭此材料将相同的中间精度与检查方式归于配对函数内部。^[root-datum-dual.md:87-91, root-datum-dual.md:209-213]

## 调用范围与证据边界

在来源覆盖的 `root_datum.rs` 与 `dual.rs` 两个文件中，`reflect_weight` 和 `reflect_coweight` 均无调用点。[[最长 Weyl 元的下坡行走]] 中的 `longest_action` 经由 `WeylGroup` 与 `WeylAction` 执行反射，不调用 `reflect_weight`；本接口的算术保护不能据此归于最长元行走实现。^[root-datum-dual.md:184-191]
