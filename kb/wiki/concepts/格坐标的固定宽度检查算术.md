# 格坐标的固定宽度检查算术

格坐标层刻意采用受检（checked）固定宽度存储：`Weight(Vec<i32>)` 表示特征格 \(X^*\) 的元素，`Coweight(Vec<i32>)` 表示余特征格 \(X_*\) 的元素。精确解释器值在领域边界处转换，而不改变每个根系矩阵条目的表示。两个类型是独立的 newtype；两格之间虽有完美配对，即使所选基下坐标相同，也不可互换。^[lattice-types.md:17-25]

## 配对与逐坐标运算

`pair(weight, coweight)` 计算典范的特征格—余特征格配对。它先检查秩是否一致，失配时返回 `RankMismatch { expected: weight.rank(), actual: coweight.rank() }`；检查通过后，委托 `pair_coordinates` 使用 `i128` 受检累加，再通过 `i32::try_from` 检查结果能否收窄为 `i32`。内部坐标辅助函数使用 `zip`，长度一致须由调用方保证，否则会发生截断。^[lattice-types.md:29-32]

`checked_add_weights` 与 `checked_sub_weights` 对等秩权向量执行受检的逐坐标加减。符号乘法使用 `checked_mul(sign)`，拦截 `i32::MIN * -1` 这类溢出情形。^[lattice-types.md:33-34]

## 有理权的表示与归一化

`RationalWeight` 使用 `Vec<i64>` 分子与 `i64` 公共分母。构造器 `new` 要求分母严格为正，并执行 gcd 归一化；非正分母产生 `RepInvariantViolation { invariant: "rational weight denominator" }`。`from_weight` 将整权转换为分母为 1 的有理权；`zero(rank)`、`add` 和 `sub` 返回 `Result`，其中加减由 `combine` 交叉相乘取得公共分母后再归一化。^[lattice-types.md:17-20, lattice-types.md:43-47]

归一化时机取决于具体操作：`apply_matrix` 只作用于分子并保持分母；`halve` 只将分母翻倍，刻意不归一化，将归一化时机交给调用方；`normalized` 重新执行构造器的 gcd 归一化；`scale` 在标量乘法后归一化。`integral_coordinates` 将上游逐项整除断言转化为可检查的整性条件，`dot_coroot` 返回已约分的 `(i64, i64)`。^[lattice-types.md:51-59]

`RationalCoweight` 则保存逐坐标的 `Rational`。其 `from_coordinates` 为 `pub(crate)`，公开 API 提供 `dimension()` 与 `to_rationals()`，后者为 workspace 消费者提供精确坐标视图；该类型不提供算术操作或 `Hash`。^[lattice-types.md:73-79]

## 分配与错误边界

按输入长度新建 `Vec` 的路径使用 `try_reserve_exact`，并将预留失败映射为 `StructureError::AllocationFailed`；`try_copy_coordinates` 也采用这一错误映射。来源明确记录的例外是 `halve`、`normalized` 和 `to_rationals` 中的裸 `clone()`。相关错误分类见 [[StructureError 统一错误分类学]]。^[lattice-types.md:35-39]

诊断字段存在需要保留的实现差异：`dot_coroot` 的秩失配使用 `expected: coroot.rank(), actual: self.rank()`，与 `pair`、`combine` 的惯例相反；`apply_matrix` 在矩阵行长失配时，也将 `actual` 填为 `matrix.len()`。^[lattice-types.md:63-66]

构造器中的 `i64::try_from(gcd)` 与 `checked_div` 属于防御性检查，在当前不变量下相应溢出出口不可达。本文件的 `gcd_u64` 返回 `left.max(1)`，因此 `gcd(0,0)=1`；`global_kgb.rs` 中同名私有副本返回 `left`，因此 `gcd(0,0)=0`。由于各自调用点的分母恒正，两种实现目前均安全，但重复实现已出现语义漂移。^[lattice-types.md:67-71]
