# 环境根反射字的共享约定

环境根反射字由 `root_reflection.rs` 中的 `reflection_word(rc, alpha)` 统一生成，是上游 `RootDatum::reflection_word`（`rootdata.cpp:1092-1095`）的唯一移植点。模块注释禁止消费方另建私有副本；extended parameters 与 common block packet 生成共用这一字约定，相关概念包括[[扩展参数值类型 ExtParam]]与[[公共块的构造与元素编号（PartialBlock）]]。^[twisted-involution-trio.md:66-75]

## 构造与顺序约定

源材料将构造关系记为 `reflection_word(rc, alpha) = to_dominant(reflection(α, 2ρ))`，并明确要求返回字按上游约定反转一次。反转是生成结果的顺序约定，不能在描述算法时省略。^[twisted-involution-trio.md:68-72]

优势化采用贪心循环：每轮从生成元 `0` 开始扫描，选择第一个配对为负的生成元施行反射，然后重新从头扫描。循环没有迭代上限，终止性依赖数学性质，实现没有额外的迭代护栏。^[twisted-involution-trio.md:71-75]

## 算术与维度边界

`wrapping_dot` 与 `add_scaled` 全程使用 wrapping `i32` 算术，溢出时静默回绕，没有错误返回路径。长度一致性仅由 `debug_assert_eq!` 检查；release 模式下，长度不一致会按 `zip` 的行为截断。^[twisted-involution-trio.md:73-75]

这一算术策略与同一来源包中的其他工具不同：`twisted_involution` 全部采用 checked 算术，`involution_classification` 混用 checked、saturating 和普通算术，而 `root_reflection` 全部采用 wrapping 算术。来源尚未确定这种差异属于有意分层还是实现漂移。^[twisted-involution-trio.md:79-84]

## 接口关系与证据边界

`root_reflection.rs` 服务于表示层，消费方涉及 [[RepContext 借用上下文与一致性约束|RepContext]]；它与同包的 `twisted_involution.rs`、`involution_classification.rs` 互不调用。^[twisted-involution-trio.md:77-84]

本页依据结构性源码阅读，不构成数学验收；上游位置仅转录自代码注释。`root_reflection.rs` 没有文件内测试，`reflection_word` 全函数被列为未测路径，本次知识维护也未执行 Atlas、Cargo、测试或 benchmark。^[twisted-involution-trio.md:9-13, twisted-involution-trio.md:73-84, twisted-involution-trio.md:88-92]
