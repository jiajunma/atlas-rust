# 环面部分的模二表示与余权提升

`minimal_torus_part` 以模二位向量表示环面部分：先编码 `factor − coch` 的整数坐标奇偶性，再将强代表下降到基本纤维并约化，随后提升为余权，计算基本虚单根的紧致性模式，最终搜索并选出符合目标的最小环面部分。^[minimal-torus.md:50-76]

## 从整数差到模二表示

`factor` 是给定的环面因子，`coch` 是由 `elected_square_root` 算出的[[合成实形的选定余特征]]，供自定义构造器保存为 `g_rho_check`。初始环面部分要求 `factor − coch` 的每个坐标均为整数，否则触发具名错误 `"torus-part integrality"`；整数差的奇数坐标置位，偶数坐标不置位。^[minimal-torus.md:19-21, minimal-torus.md:50-52]

令 \(t=\mathrm{factor}\)、\(c=\mathrm{coch}\)，格秩为 \(r\)，这一编码写为
\[
t-c\in\mathbb Z^r,\qquad
(tp)_j=(t_j-c_j)\bmod 2\in\{0,1\}.
\]
所得位向量记录整数差的坐标奇偶性，对应上游 `(torus_factor − coch).normalize()` 整化后的 `TorusPart`。^[minimal-torus.md:50-52]

## 下降与约化

提升所用的环面部分是下降并约化后的结果。算法通过 `grading_of_simples` 构造 `TitsCoset`，并查找输入 twisted involution；查表缺失时报 `"synthetic involution coverage"`。当 Weyl 部分不是恒等元时，按 `interface.outward()` 顺序选择首个左下降生成元：若它在当前对合下为 Real，则执行逆 Cayley，且 `Ok(None)` 也视为错误；否则执行 based twisted 共轭 `cross_pregated`。相关流程见[[强代表下降到基本纤维]]。^[minimal-torus.md:53-60]

下降时，每个中间环面部分都在目标对合处约化，末尾再调用幂等的 `coset.reduce`；输入已位于基本纤维时，末尾约化仍起决定作用。源码注释将这些操作描述为模二商上的类映射，并据此声明逐步约化不改变最终约化类；来源包未验证这一声明。^[minimal-torus.md:27-29, minimal-torus.md:60-61]

## 余权提升与紧致性配对

对下降并约化后的位向量 \(tp\)，`lift(tp)` 在置位坐标取 \(1\)，其余坐标取 \(0\)。算法构造
\[
\mathrm{coweight}=\mathrm{coch}+\operatorname{lift}(tp),
\]
即在 `coch` 的对应坐标上加 \(1\)。随后，在基本纤维 `CartanId(0)` 的虚单根基上与该余权配对：偶配对的位置在 `start` 中置位，此处置位表示紧致。^[minimal-torus.md:62-64]

目标匹配只约束虚单根基中同时为 datum-单根的位置。`constrained` 标记这些位置；`target` 保存对应实形的非紧致性，经过翻转以适配 crate 的 `Grading` 存储约定。因此，解释这些位时必须保留 `start` 的紧致性含义与目标 grading 的非紧致性约定。^[minimal-torus.md:63-67]

实现按虚单根基中的实际位置配对目标信息。上游则依赖 datum-单根位于基本虚单根基前导段的编号不变量；源码注释声明，当此前导段不变量成立时，特别是在平凡 distinguished 对合下，两种做法一致。相关细节见[[基本虚根 grading 的位置约束]]。^[minimal-torus.md:68-71]

## 轨道搜索与最小代表元

搜索使用各基余根的奇偶向量 `m_alpha`，以及基间配对的模二矩阵 `grading_shift`。算法以 LIFO 栈遍历、用 `BTreeSet<u64>` 去重；在每个置位 grading 位上，以 `m_alpha[i]` 平移环面部分，并按 `grading_shift[i]` 翻转 grading。受约束位置与目标一致的状态成为候选。^[minimal-torus.md:67-75]

最终按 `ModTwoVector` 的顺序选取最小候选；等维位向量的这一顺序就是整数序。无候选时返回具名错误 `"minimal torus part candidates"`。位向量表示与完整搜索分别可参见[[F₂ 上的位打包向量（ModTwoVector）]]和[[最小环面部分的 grading 轨道搜索]]。^[minimal-torus.md:72-76]

## 输入、资源与证据边界

入口依次检查 table 的 inner class、`coch`／`factor` 长度、twisted 的像置换长度及格秩。对应失败为 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 和 `SeedResourceLimit { resource: "mask bits" }`；长度错误的 `actual` 取 `coch` 与 `factor` 长度中的较大者。`MAX_MASK_BITS = 63` 将格秩限制为不超过 \(63\)，用于 `u64` 去重编码；函数没有显式预算参数，仅有该位数上限与分配防护。^[minimal-torus.md:30-31, minimal-torus.md:46-48, minimal-torus.md:99-100]

现有四个测试锚点均为 rank 2、紧致内类。三个正例都满足 `coch == factor`，没有用可区分的断言刻画非平凡运输；非紧致 distinguished、多数具名错误分支和 rank > 63 的资源门也未覆盖。来源属于结构性阅读，不构成数学正确性验收，上游引用亦未独立核对字节。参见[[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:9-13, minimal-torus.md:78-98]
