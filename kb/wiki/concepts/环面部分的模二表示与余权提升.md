# 环面部分的模二表示与余权提升

`minimal_torus_part` 用模二位向量表示环面部分：先提取 `factor − coch` 的整数坐标奇偶性，再将强代表下降到基本纤维并约化，随后提升为余权，计算基本虚单根的紧致性模式，最终选取符合目标弱实形的最小环面部分。^[minimal-torus.md:22-25, minimal-torus.md:50-76]

## 初始环面部分的编码

`factor` 是给定的环面因子，`coch` 是 `elected_square_root` 计算的[[合成实形的选定余特征]]，由自定义构造器保存为 `g_rho_check`。初始编码要求 `factor − coch` 逐坐标为整数，否则触发具名错误 `"torus-part integrality"`；整数差的奇数坐标置位，偶数坐标不置位。^[minimal-torus.md:19-21, minimal-torus.md:50-52]

令 \(t=\mathrm{factor}\)、\(c=\mathrm{coch}\)，格秩为 \(r\)，编码关系为
\[
t-c\in\mathbb Z^r,\qquad
(tp)_j=(t_j-c_j)\bmod 2\in\{0,1\}.
\]
所得位向量记录整数差的奇偶性，对应上游 `(torus_factor − coch).normalize()` 整化后的 `TorusPart`；相关表示见[[F₂ 上的位打包向量（ModTwoVector）]]。^[minimal-torus.md:50-52]

## 下降与约化

余权提升使用下降并约化后的环面部分。算法先通过 `grading_of_simples` 构造 `TitsCoset`，再查找输入 twisted involution；查表缺失时报 `"synthetic involution coverage"`。当 Weyl 部分不是恒等元时，按 `interface.outward()` 顺序选取首个左下降生成元：若其在当前对合下为 Real，则执行逆 Cayley，且 `Ok(None)` 也视为错误；否则执行 based twisted 共轭 `cross_pregated`。详见[[强代表下降到基本纤维]]。^[minimal-torus.md:53-60]

每个中间环面部分都在目标对合处约化，末尾再调用幂等的 `coset.reduce`；输入已经位于基本纤维时，末尾约化仍起决定作用。源码注释将这些操作描述为模二商上的类映射，据此声明逐步约化不改变最终约化类；来源包未验证这一声明。^[minimal-torus.md:27-29, minimal-torus.md:60-61]

## 余权提升与 grading

对下降并约化后的 \(tp\)，`lift(tp)` 在置位坐标取 \(1\)，其余坐标取 \(0\)。算法构造
\[
\mathrm{coweight}=\mathrm{coch}+\operatorname{lift}(tp),
\]
即在 `coch` 的置位对应坐标上加 \(1\)。随后，在基本纤维 `CartanId(0)` 的虚单根基上进行配对：偶配对的位置在 `start` 中置位，表示紧致。^[minimal-torus.md:62-64]

目标匹配只约束该虚单根基中同时为 datum-单根的位置。`constrained` 标记这些位置；`target` 保存目标实形在受约束位置的非紧致性，其翻转处理适配 crate 的 `Grading` 约定。因此，读取状态时需要区分 `start` 的紧致位与目标 grading 的非紧致性约定。^[minimal-torus.md:63-67]

实现按照虚单根基中的实际位置配对目标信息。上游则依赖 datum-单根位于基本虚单根基前导段的编号不变量。源码注释声明，该不变量成立时，特别是在平凡 distinguished 对合下，两种处理一致；这仍是注释声明，不能视为本包已验证的结论。详见[[基本虚根 grading 的位置约束]]。^[minimal-torus.md:68-71, minimal-torus.md:95-96]

## 轨道搜索与最小值选取

搜索使用各基余根的奇偶向量 `m_alpha` 和基间配对的模二矩阵 `grading_shift`。算法以 LIFO 栈遍历，用 `BTreeSet<u64>` 去重；在每个置位 grading 位上，以 `m_alpha[i]` 平移环面部分，并按 `grading_shift[i]` 翻转 grading。受约束位置与目标一致的状态成为候选。^[minimal-torus.md:67-75]

最终按 `ModTwoVector` 的顺序选取最小候选；等维位向量的这一顺序就是整数序。候选为空时返回具名错误 `"minimal torus part candidates"`。完整搜索过程见[[最小环面部分的 grading 轨道搜索]]。^[minimal-torus.md:72-76]

## 输入、资源与证据边界

入口依次检查 table 的 inner class、`coch`／`factor` 长度、twisted 的像置换长度及格秩。失败分别返回 `DatumMismatch`、`RankMismatch`、`DatumMismatch` 和 `SeedResourceLimit { resource: "mask bits" }`；长度错误的 `actual` 取两者长度中的较大值。`MAX_MASK_BITS = 63` 为 `u64` 去重编码限定格秩上限；函数没有显式预算参数，仅有位数限制与分配防护。^[minimal-torus.md:30-31, minimal-torus.md:46-48, minimal-torus.md:99-100]

现有四个测试锚点均为 rank 2、紧致内类。三个正例都满足 `coch == factor`，没有用可区分的断言刻画非平凡运输；非紧致 distinguished、多数具名错误分支及 rank > 63 的资源门也未覆盖。来源属于结构性阅读，不构成数学验收，上游引用未独立核对字节。详见[[最小环面算法的测试覆盖边界]]。^[minimal-torus.md:9-13, minimal-torus.md:78-98]
