# 类型化转换与求值管线

类型化转换与求值管线是 `atlas-core` 将解析结果转换为可执行类型化表示并求值的核心，主要位于 `typed.rs`。所属 crate 定位为面向兼容性的 Atlas 语言运行时，公开模块对应可观察的语言边界，实现遵循 `docs/` 中的契约；背景见 [[atlas-core 语言门面与兼容契约]]。^[atlas-core-root.md:9-13, atlas-core-root.md:37-37]

## 解析与类型化转换

前端由多个模块配合完成：`lex.rs` 提供支持嵌套注释、可逐 token 消费的有状态词法器；`syntax.rs` 使用 LALRPOP 生成的文法，并通过独立适配层将词法流转换为带源码跨度的 token 流；`formula.rs` 负责运算符优先级归约，其结构解析器将式子视为交错序列。^[atlas-core-root.md:31-32, atlas-core-root.md:46-46]

`typed.rs` 承担 parsed→typed 的可执行转换与求值。模块说明将 `convert_expr` 对应到上游 `axis.w:272-487`，并说明检查与合成在单遍中完成，参见 [[convert_expr 的 in/out 类型模式与单遍转换]]。这一对应关系属于实现方的设计陈述，不能单独证明行为等值。^[atlas-core-root.md:37-37, atlas-core-root.md:59-61]

## 类型模型与名字解析

`types.rs` 提供 axis 类型模型，`types/polymorphic.rs` 承担二阶类型机器，`types/recursive.rs` 负责图级递归 typedef 安装。递归安装优先安排命名 RHS 槽位，并保留环上匿名后代的身份；相关背景见 [[Type 类型表示与语义等值]]。^[atlas-core-root.md:33-35]

`typed/type_groups.rs` 在递归图构造之前解析组内名字，并将这一职责与对应上游 `global.w:1632-1860` 的校验顺序及诊断分离。`coercions.rs` 提供 axis 强制转换表与类型邻近谓词。^[atlas-core-root.md:38-38, atlas-core-root.md:43-43]

## 求值支撑与领域内建

`frames.rs` 提供类型化管线的求值帧，`value.rs` 表示求值器产生的值，`linear_values.rs` 承载 vec、mat、ratvec 的具体载荷及上游打印格式。解析器与求值器共享 `diagnostic.rs` 中的结构化诊断，`source.rs` 提供自持源文本和从 1 开始的行列位置。^[atlas-core-root.md:41-48]

`domain_builtins.rs` 是语言层到 `atlas-real-group` 的桥梁，命名函数应用在此派发，参见 [[函数调用分派与内建参数解包]]。其句柄以 `Arc` 持有上下文束，结合急切种子校验与可失败的惰性 KGB／表示属主构造；句柄按内类值、内部形式号和元素 id 进行结构比较，以对应上游 memoized 句柄的可观察相等。^[atlas-core-root.md:52-52]

## 会话执行与兼容要求

`session.rs` 提供有状态、逐命令执行的外层循环。Atlas 的词法分类依赖先前命令改变的状态，因此会话不会预先切分整个文件。文件包含、输出重定向与顶层输出面由 `session_frame.rs` 承担，相关职责见 [[会话循环与文件会话帧的职责边界]]。^[atlas-core-root.md:49-50]

兼容要求包括可观察的错误文本：`typed.rs` 的模块说明指出，整数收窄使用上游 `bigint.cpp:142-162` 的逐字错误文本，包括其中的笔误。crate 以 `COMPATIBILITY_VERSION: &str = "atlas-language-v0"` 标记语言兼容契约版本。^[atlas-core-root.md:24-25, atlas-core-root.md:37-37]
