# 线性映射下降到子商的条件验证

`ModTwoSubquotient::validate_induced_map_to(target, map)` 检查环境线性映射能否下降为子商之间的映射：源分子的每个基向量必须映入目标分子，源分母的每个基向量必须映入目标分母。条件不满足时返回 `CartanFiberMapDoesNotDescend`，并区分失败的关系。^[mod-two.md:75-79]

## 子商模型与下降条件

`ModTwoSubquotient` 保存 `numerator`、`denominator` 和 `complement_basis`，表示共同环境空间中两个 $\mathbb{F}_2$ 子空间的典范商。构造时检查环境维数一致、分母秩不超过分子秩、分母的每个基向量属于分子，以及补基恰好来自分母缺少主元的位置；违反这些不变量时报 `ModTwoSubquotientInvariantViolation`。坐标约定见 [[F₂ 子商的低主元坐标（ModTwoSubquotient）]]。^[mod-two.md:64-70]

记源子商为 $N/D$，目标子商为 $N'/D'$。环境线性映射 $f$ 的下降条件为：

\[
f(N)\subseteq N',
\qquad
f(D)\subseteq D'.
\]

实现逐个检查源分子与源分母的基向量的像，以验证这两个包含关系。分子条件失败时返回 `CartanFiberMapDoesNotDescend { relation: "numerator" }`；分母条件失败时返回 `CartanFiberMapDoesNotDescend { relation: "denominator" }`。^[mod-two.md:75-79]

## 为什么不能只检查商基代表

源码注释指出：只检查商基代表，可能使正规形选择“看似”定义了映射，即使某个源分母向量的像在目标商中非零。因此，选定代表元上的检查不能替代对源分母的检查。^[mod-two.md:75-79]

典范代表的计算与下降验证是不同的操作。`canonical_representative(vector)` 要求输入属于分子，否则返回 `NotInModTwoSubspace`；通过检查后，调用分母的 `quotient_representative` 得到代表元。`to_coordinates` 与 `ambient_representative` 则按补基的最低置位读写坐标。这些表示操作不替代下降条件验证，相关背景见 [[F₂ 商空间的确定性代表元与陪集判定]]。^[mod-two.md:72-79]

## 接口与实现边界

`ModTwoSubquotient` 刻意保持 crate 私有，因为它承载当前 Cartan-fiber 结构层使用的低主元打包坐标。公开 API 是数学层的 `CartanFiber` 包装，而非内部坐标的序列化格式。^[mod-two.md:64-67]

环境映射通过 `ModTwoAmbientMap` trait 提供，使领域层能够在稠密矩阵会造成多余分配时直接实现映射。`ModTwoLinearMap` 仅作为 `#[cfg(test)]` 下的稠密测试辅助。^[mod-two.md:80-81]
