# 线性映射下降到子商的条件验证

线性映射要从环境空间下降到子商，必须同时保持分子与分母的包含关系。`ModTwoSubquotient::validate_induced_map_to(target, map)` 通过检查两者的基向量，验证映射能否在目标子商上定义良好的映射；失败时返回 `CartanFiberMapDoesNotDescend`。^[mod-two.md:75-79]

## 子商模型与下降条件

`ModTwoSubquotient` 表示共同环境空间中两个 $\mathbb{F}_2$ 子空间的商。记源子商为 $N/D$，目标子商为 $N'/D'$，其中分子、分母分别对应 `numerator`、`denominator`。构造时检查环境维数一致、分母秩不超过分子秩，以及分母的每个基向量都属于分子；该类型还保存用于典范坐标的补基。相关坐标约定见 [[F₂ 子商的低主元坐标（ModTwoSubquotient）]]。^[mod-two.md:64-70]

对环境空间上的线性映射 $f$，验证要求为
\[
f(N)\subseteq N',\qquad f(D)\subseteq D'.
\]
实现逐一检查源分子的基向量是否映入 `target.numerator`，以及源分母的基向量是否映入 `target.denominator`。前者失败时，错误的 `relation` 为 `"numerator"`；后者失败时为 `"denominator"`。^[mod-two.md:75-79]

## 为什么不能只检查商基代表

只检查商基代表不足以验证下降条件。源码注释指出：当某个源分母向量的像在目标商中非零时，正规形选择仍可能让映射“看似”有定义。因此，分母上的检查不能由商基代表检查替代。^[mod-two.md:75-79]

典范代表与映射下降承担不同职责：`canonical_representative(vector)` 先检查向量是否属于分子，再用分母的 `quotient_representative` 取得代表元；`to_coordinates` 与 `ambient_representative` 则按补基最低置位读写坐标。这些操作提供确定性表示，而下降验证另行检查分子和分母的像。可参见 [[F₂ 商空间的确定性代表元与陪集判定]] 与 [[Ambient 映射的子商下降验证]]。^[mod-two.md:72-81]

## 实现边界

`ModTwoSubquotient` 刻意保持 crate 私有，因为它承载当前 Cartan-fiber 结构层使用的低主元打包坐标；公开 API 是数学层的 `CartanFiber` 包装，而非这些内部坐标的序列化格式。环境映射通过 `ModTwoAmbientMap` trait 提供，使领域层可以在稠密矩阵会造成多余分配时直接实现映射；`ModTwoLinearMap` 仅作为 `#[cfg(test)]` 下的稠密测试辅助。^[mod-two.md:64-67, mod-two.md:80-81]

## 证据与覆盖限制

来源记录了子商低主元坐标等测试锚点，但 `CartanFiberMapDoesNotDescend` 的两个 `relation` 分支未被覆盖，`validate_induced_map_to` 在该文件内也没有调用方。来源仅作结构性源码阅读，未执行构建、测试或原版运行，因此不能据此宣称下降验证已获得运行验收或数学验收。^[mod-two.md:85-93, mod-two.md:103-103]
