# 线性映射下降到子商的条件验证

`ModTwoSubquotient::validate_induced_map_to(target, map)` 验证环境线性映射能否下降为子商之间的映射。它同时检查源分子与源分母的基向量的像，要求分别属于目标分子与目标分母；条件不满足时返回 `CartanFiberMapDoesNotDescend`。^[mod-two.md:75-79]

## 子商模型与下降条件

`ModTwoSubquotient` 表示共同环境空间中两个 $\mathbb{F}_2$ 子空间的商，保存 `numerator`、`denominator` 和 `complement_basis`。构造时检查环境维数一致、分母秩不超过分子秩、分母的每个基向量属于分子，以及补基恰好来自分母缺少主元的位置；违反这些不变量时报 `ModTwoSubquotientInvariantViolation`。坐标约定见 [[F₂ 子商的低主元坐标（ModTwoSubquotient）]]。^[mod-two.md:64-70]

记源子商为 $N/D$、目标子商为 $N'/D'$。对环境线性映射 $f$，下降验证要求
\[
f(N)\subseteq N',
\qquad
f(D)\subseteq D'.
\]
实现通过检查源分子与源分母的每个基向量的像来验证这两个包含关系。分子条件失败时，错误为 `CartanFiberMapDoesNotDescend { relation: "numerator" }`；分母条件失败时，`relation` 为 `"denominator"`。^[mod-two.md:75-79]

## 为什么不能只检查商基代表

源码注释明确指出：只检查商基代表，可能使正规形选择“看似”定义了映射，即使某个源分母向量的像在目标商中非零。因此，商基代表的检查不能替代分母上的检查。^[mod-two.md:75-79]

典范代表与下降验证承担不同职责。`canonical_representative(vector)` 先检查向量是否属于分子，不属于时报 `NotInModTwoSubspace`，否则用分母的 `quotient_representative` 取得代表元；`to_coordinates` 与 `ambient_representative` 按补基最低置位读写坐标。这些表示操作之外，下降验证仍须检查分子和分母的像。相关表示机制见 [[F₂ 商空间的确定性代表元与陪集判定]]。^[mod-two.md:72-79]

## 实现边界

`ModTwoSubquotient` 刻意保持 crate 私有，因为它承载当前 Cartan-fiber 结构层使用的低主元打包坐标。公开 API 是数学层的 `CartanFiber` 包装，而不是内部坐标的序列化格式。^[mod-two.md:64-67]

环境映射由 `ModTwoAmbientMap` trait 提供，使领域层能在稠密矩阵会造成多余分配时直接实现映射。`ModTwoLinearMap` 则仅作为 `#[cfg(test)]` 下的稠密测试辅助。^[mod-two.md:80-81]

## 证据与覆盖限制

来源记录了子商低主元坐标等测试锚点，但未覆盖 `ModTwoSubquotientInvariantViolation` 的五处错误、`NotInModTwoSubspace`，以及 `CartanFiberMapDoesNotDescend` 的两个 `relation` 值；`validate_induced_map_to` 在该文件内也没有调用方。更多测试范围可参见 [[模二线性代数的测试锚点与验收边界]]。^[mod-two.md:85-93]

来源属于结构性源码阅读，未执行任何构建、测试或原版运行，不包含数学验收、性能或并行结论。因此，这些材料说明实现的检查规则与已识别的覆盖缺口，并不提供下降验证的运行验收结果。^[mod-two.md:9-13, mod-two.md:103-103]
