# 顶层会话事件的输出规则

`SessionFrame` 的 `execute` 层将会话事件转换为可见输出，负责值打印、报告缩进和诊断处理，并维护会话的 `clean` 状态。表达式解析位于 `syntax.rs`，执行位于 `typed.rs`；会话帧统一处理输出框架。^[atlas-core-session-frame.md:50-58, atlas-core-session-frame.md:94-95]

## 值与报告输出

`SessionEvent::Value` 的值非 void 时，打印 `Value: <display>`；void 即空元组，不产生值打印。^[atlas-core-session-frame.md:52-53]

`ReportLine` 与 `ReportBytes` 按**当前包含深度**缩进，每层增加两个空格。`ReportBytes` 经 `SessionEvent::output` 保留原始字节；定义报告的缩进统一在框架层处理。相关概念见 [[SessionEvent 与字节保留输出]]。^[atlas-core-session-frame.md:54-58]

## 诊断与会话状态

遇到 `Diagnostic` 时，若 `kind != Io`，会话被标记为 `clean=false`，当前命令进入 Abort；Io 诊断不使会话变脏。文件打开失败与 abandon 级联本身也不将 `clean` 置为 false，因此中止包含读取并不必然意味着会话不再 clean。参见 [[会话 clean 标志与诊断分流]]。^[atlas-core-session-frame.md:43-46, atlas-core-session-frame.md:56-58]

词法 warning（例如未闭合字符串提示）只报告，不使会话变脏，也不触发 abort；真正的词法错误会使会话变脏，并在包含深度大于零时触发 abandon 级联。^[atlas-core-session-frame.md:69-70]

带源码跨度的诊断由 `describe_bytes` 输出为 `{Kind} error at {origin}:{physical}:{column}: {msg}`，随后附源行和 caret 指示符。物理行号通过预处理生成的 `line_map` 换算；没有 span 的诊断只使用裸 `{Kind} error:` 头。^[atlas-core-session-frame.md:74-79]

## 单命令重定向的事件分流

`>file EXPR` 与 `>>file EXPR` 的命令体先按表达式解析，解析成功后才打开 sink，且打开早于求值。语法错误不会创建文件；求值失败仍会留下文件，并可能包含部分输出。参见 [[单命令输出重定向的执行纪律]]。^[atlas-core-session-frame.md:23-25, atlas-core-session-frame.md:59-62]

重定向将命令产生的 `Output` 和 `OutputBytes` 事件写入 sink，其余事件照常向上层传递。打开失败只输出一行裸 stderr：`Failed to open {name}`，会话保持 clean；`sink.close()` 无条件执行。^[atlas-core-session-frame.md:63-65]

## 文件包含的框架输出

实际进入文件读取时，框架打印 `Starting to read from file …`；读取返回 Finished 时，记录 completed 并打印 `Completely read file …`。因 include-once 或活动包含栈循环守卫而跳过的包含保持静默。参见 [[SessionFrame 会话帧与文件包含语义]]。^[atlas-core-session-frame.md:12-14, atlas-core-session-frame.md:36-40]

放弃读取时，框架通过 `lexer.offset()-1` 定位正在读取的行，再经 `line_map` 换算物理行号，输出 `Abandoning reading of file '{origin}' at line {physical}`。嵌套包含的各外层依次补发自己的消息，顺序为最内层在先。参见 [[嵌套包含的 abandon 级联]]。^[atlas-core-session-frame.md:66-68]

## 测试与证据边界

源文件中的 18 个测试覆盖原始字节输出、重定向字节保留、包含框架行、级联顺序、深度缩进、void 抑制及物理行报告等行为。这些属于单元级行为锚点；端到端文件命令兼容仍以 HPC 差分语料为准，结构性阅读本身不构成语言或数学验收。^[atlas-core-session-frame.md:9-16, atlas-core-session-frame.md:81-90]
