# 领域值的结构等值与属主身份

领域值的比较区分三种语义：数学对象的结构等值、实形属主的指针同一性，以及 Weyl 抽象群的身份兼容。`DomainValue` 总体采用结构等值，但 Weyl 元素还受抽象群身份约束，不能仅凭根数据结构相等判断兼容性。^[atlas-core-domain-values.md:69-85]

## 各类值的结构等值

`DomainValue` 包含 13 个变体：LieType、RootDatum、InnerClass、RealForm、KgbElement、Block、WeylElement、CartanClass、Split、KType、KTypePol、Param 和 ParamPol。其结构等值设计体现上游 memoized 句柄的可观察语义：独立构造的同一数学对象句柄可以相等。^[atlas-core-domain-values.md:69-74]

`RootDatumHandle::PartialEq` 只比较 `datum`、`lie_type`、`isogeny` 和 `prefers_coroots`，刻意忽略 Weyl 身份缓存；Debug 同样忽略该缓存。唯一构造入口 `interned` 则保证等值且仍存活的根数据共享 Weyl 身份，参见 [[RootDatum 弱驻留与规范活对象身份]]。^[atlas-core-domain-values.md:39-45]

InnerClass、CartanClass 和 KgbElement 按各自适用的内类、形式号及元素 id 比较。RealForm、KType、Param 和两个多项式变体使用 `same_real_form`，再比较严格分量；这里的实形相同要求同内类、同形式、同基余特征标和同初始环面部。Block 比较两侧实形的内类。^[atlas-core-domain-values.md:76-79]

## 实形属主身份与操作约束

`KTypeValue` 和 `ParamValue` 分别保存 `KType`、`StandardRepr` 及其实形属主。两个多项式变体保存同一实形上的有序 `(Split, KType)` 或 `(Split, StandardRepr)` 项，并合并同类项、删除零系数项。^[atlas-core-domain-values.md:64-67]

`same_real_form_owner` 检查指针同一性，供直接比较 `shared_real_form` 字段的包装使用。规范构造通过父弱缓存共享一个上下文；自定义构造即使数学上相等，也总是新建属主。因此，结构等值不等于属主身份，参见 [[实形式的规范弱缓存与属主身份]]。^[atlas-core-domain-values.md:83-85]

属主约束直接影响多项式写入。`assign_polynomial_coefficient` 只替换精确 final 键的系数，不累加或展开非 final 键；它在触碰目标项之前拒绝不兼容属主，即使零写入或丢弃写也执行校验。这是对上游未检查外来属主插入行为的有意偏离，详见 [[实形属主约束下的多项式系数契约]]。^[atlas-core-domain-values.md:97-102]

多项式读取有独立于加法和写入的校验契约：Param 的 dominant 化只修改副本，不改变调用方存储的参数，即使结果被丢弃也执行校验。`loop_terms` 借用规范非零项序，产出的键保留其实形属主，不复制多项式或以整数键替代，参见 [[容器迭代的借用与规范项序]]。^[atlas-core-domain-values.md:103-107]

## Weyl 元素的身份门控与跨坐标比较

`WeylEltContext` 包含属主局部坐标 kernel 和抽象群身份；抽象群携带内部生成元重编号，用于固定上游 canonical-word 选择。Weyl 兼容性取决于抽象群 `Arc` 的指针身份，而非结构根数据句柄或坐标 kernel。元素在构造时冻结 canonical 既约词，之后 `Display` 与 `word` 都是纯读取，参见 [[Weyl 元素值的规范词冻结]]。^[atlas-core-domain-values.md:53-58]

`weyl_elements_equal` 先检查抽象群 `Arc` 同一性，再把右元素的 canonical 外生成元词在左侧系统中重放后比较。这允许辫子等价词跨坐标相等；外来根置换永不直接比较或复合，详见 [[Weyl 元素兼容性与跨坐标词重放]]。^[atlas-core-domain-values.md:80-82]

`weyl_group_compatible` 使用 `Arc::ptr_eq(group)`。`require_weyl_compatible` 在无值门之前检查二元关系和乘积，不兼容时报告 `Weyl group mismatch`；即使调用不需要结果值，也必须检查兼容性。^[atlas-core-domain-values.md:87-91, atlas-core-domain-values.md:123-124]

## 身份共享、生命周期与预热历史

`DatumWeylIdentity` 由惰性坐标 kernel 和抽象群身份组成，两者都不回指 handle，因此没有所有权环。坐标 kernel 由同一 datum 的克隆、别名及 `root_datum(WeylElt)` 往返共享；抽象群则恰在上游共享 `WeylGroup` 指针时共享，参见 [[Rust Weyl 内核与抽象群的无环所有权模型]]。^[atlas-core-domain-values.md:24-29]

全局弱引用表 `DATUM_WEYL_IDENTITIES` 按完整内容复用活跃根数据的身份单元。强引用全部消失后，槽位过期，后续等值构造重新开始；表大小超过 4096 时才扫描失效槽位。结构内容与身份单元的存活期因此是两个需要区分的方面。^[atlas-core-domain-values.md:34-43]

对偶构造仅在目标 canonical dual 仍冷时向其共享源抽象群。已经预热的目标不会被覆盖，并与源保持不兼容；并发共享竞态只允许一个结果发布。因此，初始化历史会影响兼容性，详见 [[dual 预热历史与 Weyl 群兼容性]]。^[atlas-core-domain-values.md:30-33]
