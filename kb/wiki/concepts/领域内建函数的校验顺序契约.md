# 领域内建函数的校验顺序契约

`domain_builtins.rs` 的 `validate` 包含 46 个分支，每个领域名对应一个分支，按实现注释引用的上游顺序契约执行校验。各分支在“无值门”之前执行多少检查并不统一，校验位置与先后关系需要逐分支保留。^[atlas-core-domain-validate-print.md:14-17]

## 无值门与构造检查

`integrality_simples`、`integrality_rank`、`is_integrally_dominant` 和 `integrality_datum` 在无值门之前执行 `check_integrality_dimension`。实现引用的上游依据为 `atlas-types.w:1766`。^[atlas-core-domain-validate-print.md:22-24]

`KGB_elt` 在无值门之前完成全部构造检查，再丢弃构造结果；`KL_block` 则先执行 `test_standard`，再经过无值门。实现分别引用 `atlas-types.w:4580-4607` 与 `atlas-types.w:6868-6872`。^[atlas-core-domain-validate-print.md:30-32]

三参数形式的 `Weyl_orbit` 和 `Weyl_orbit_ws` 调用 `weyl_subgroup::validate`，采用只构造、不计算的 [[BuildAndDrop 领域内建验证策略]]。^[atlas-core-domain-validate-print.md:20-21]

## 参数检查与可观察顺序

`fundamental_weight` 与 `fundamental_coweight` 检查参数个数及半单秩索引。`W_refl` 先进行 `int_val` 收窄，再校验索引；来源明确指出，这一顺序具有可观察意义。^[atlas-core-domain-validate-print.md:19-25]

`real_form` 按参数个数分发至 `(InnerClass,int)` 或 `(InnerClass,mat,ratvec)` 形式。外部实形式编号经 `order.internal` 翻译，非法编号对应错误 `Illegal real form number: n`。^[atlas-core-domain-validate-print.md:26-28]

`KGB` 首先依据 `kgb_size` 检查元素编号边界，不存在的元素对应错误 `Inexistent KGB element: n`。^[atlas-core-domain-validate-print.md:29-29]

## 打印入口中的校验契约

`print_text` 按名称分发打印操作。`print_real_Weyl` 在分支内部按照上游包装器的措辞与顺序先执行检查，否则外来的外部实形式编号会经 `ExternalFormOrder` 静默翻译。参见 [[实 Weyl 群打印的前置检查]]。^[atlas-core-domain-validate-print.md:58-70]

`print_KGB` 的单参数形式打印全部元素；选择形式 `print_KGB_selection_wrapper` 要求所列元素属于同一实形式，跨形式时报告 `Real form mismatch when printing KGB element`。参见 [[KGB 打印与实形一致性]]。^[atlas-core-domain-validate-print.md:60-63]

来源记载，`print_X` 的上游入口没有检查，且每次调用新建 `InvolutionTable`；`print_blockstabilizer` 的上游入口同样没有检查，块仅提供它的两个实形式。^[atlas-core-domain-validate-print.md:68-72]

## 证据范围与限制

本来源覆盖 `domain_builtins.rs` 中 `validate` 的 9730–10437 行及相关打印机，属于结构性阅读，不声称数学验收。来源没有展开全部 46 个分支，完整的逐分支校验顺序契约保留在实现注释中。^[atlas-core-domain-validate-print.md:9-12, atlas-core-domain-validate-print.md:74-76]

来源引用的上游行号属于实现方的移植陈述；打印与校验的兼容性仍以 HPC 语料门为准，参见 [[HPC 验收证据链]]。字节数和哈希仅标识对应快照字节，其 Git base 为 `964f0033`。^[atlas-core-domain-validate-print.md:80-81]
