# 领域内建桥接与上下文句柄

`domain_builtins.rs` 是 `atlas-core` 语言层通往 `atlas-real-group` 的桥梁，负责派发命名函数应用。它是 [[atlas-core 语言门面与兼容契约]] 的公开模块之一；该 crate 定位为面向兼容性的 Atlas 语言运行时，公开模块围绕可观察的语言边界组织。^[atlas-core-root.md:9-20, atlas-core-root.md:52-52]

## 桥接职责

`typed.rs` 负责从解析表达式到类型化可执行表达式的转换与求值，`domain_builtins.rs` 负责领域内建的命名函数应用派发。相关概念包括 [[TypedExpr 可执行表达式树]]、[[函数调用分派与内建参数解包]] 和 [[atlas-real-group 的 crate 门面与数学值边界]]。^[atlas-core-root.md:37-37, atlas-core-root.md:52-52]

## 上下文句柄与构造时机

领域句柄采用 `Arc` 持有的上下文束。种子执行急切校验，KGB 与表示属主则采用可失败的惰性构造。相关主题包括 [[RealFormSeed 的封装与构造不变量]]、[[KGB 构造的前置门控与不变量]] 和 [[RepTableOwner 实形式资源所有者]]。^[atlas-core-root.md:52-52]

## 相等语义与打印兼容

句柄按“内类值、内部形式号、元素 id”进行结构比较。来源将其描述为对应上游 memoized 句柄的可观察相等语义，但模块地图未展开具体比较算法。^[atlas-core-root.md:52-58]

打印兼容性的陈述限定于上游形式稳定的位置：这些位置的打印串逐字节一致，可结合 [[上游兼容的值打印约定]] 阅读。这是实现文件头的角色自述，不能据此认定全部领域输出已通过兼容性验收。^[atlas-core-root.md:27-29, atlas-core-root.md:52-60]

## 相关实现

子模块 `domain_builtins/weyl_subgroup.rs` 负责反射子群轨道与 ambient Weyl 见证，相关概念见 [[反射子群轨道与生成元约束下的优势化]] 和 [[ambient Weyl 见证词与作用方向]]。^[atlas-core-root.md:53-53]

crate 私有模块 `matreduc` 提供精确整数矩阵约化，服务于 `global.w` 批内建。其实现包括 gcd、recorder 和 `column_echelon` 等操作；来源将其描述为逐操作对应钉定的上游版本 `4d3e9449`。^[atlas-core-root.md:21-22, atlas-core-root.md:51-51]

## 证据边界

本页依据 crate 门面与模块地图的结构性阅读，模块角色取自各实现文件头的自述。来源未展开 `domain_builtins.rs` 的内部实现，也不声称语言或数学验收；上游移植位置属于实现方的设计陈述，语义等值仍以 [[HPC 验收证据链|HPC 差分门]] 为准。^[atlas-core-root.md:9-13, atlas-core-root.md:27-29, atlas-core-root.md:55-61]

来源快照绑定 Git base `964f0033`，并记载工作区干净。行数和哈希只标识该快照的字节，不能证明实现正确。^[atlas-core-root.md:62-63]
