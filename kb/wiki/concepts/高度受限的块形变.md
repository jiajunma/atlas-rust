# 高度受限的块形变

高度受限的块形变由 `block_deformation_to_height` 实现，计算参数 `p` 的完整块中高度不超过 `height_bound` 的形变项。它移植自上游 `Rep_table::block_deformation_to_height`（`repr.cpp:2027-2124`），是平凡 block modifier 下的版本，遵循[[形变驱动的冻结移植契约]]。^[deformation-drivers.md:20-25, deformation-drivers.md:115-122]

## 高度界与返回结果

`height_bound` 指定高度上限；`u32::MAX` 对应上游用负界表示的 “maximal level”。函数返回 `(StandardRepr, SplitInteger)` 项，分别承载[[StandardRepr 标准表示参数|标准表示参数]]与[[SplitInteger 分裂整数系数|分裂整数系数]]，结果按向下的、反转后的块顺序排列。^[deformation-drivers.md:115-119]

函数还返回与 `accumulator` 平行的已消费项标志。上游通过 `queue.erase` 原地修改队列；由于 Atlas 值不可变，移植实现改为报告哪些项已被消费。^[deformation-drivers.md:119-120]

## 系数表示

`SplitInteger { a, b }` 表示 $a+bs$，承载形变公式 $F(z)=L(z)+(1-s)D(z)$ 中的系数，其中 `Split(c, -c)` 表示 $c(1-s)$。两个字段均为 `i32`，所有算术使用 `wrapping_*`，沿用上游的环绕语义；溢出防护不属于该类型的职责。^[deformation-drivers.md:50-59]

## KL 表填充策略

上游在高度界之上使用 `plug_hole` 处理对偶块的 KL 表，以跳过部分计算。来源说明，多项式值不依赖这些 holes，因此 Rust 移植填充整张表：高度界限制返回的形变项，KL 表的填充则不按该界截断。^[deformation-drivers.md:115-122]

## 调用前提与适用范围

`IntegralBlockScope::Full` 表示每个简单余根都与 `gamma` 整配对，此时各驱动接受 `BlockGraph`，对应带平凡 block modifier 的完整块。整配对的判据是 `coroot · gamma.numerator()` 能被 `gamma.denominator()` 整除。^[deformation-drivers.md:63-72]

对于真积分子系统，来源要求不支持相应 common-block 路径的移植接口显式失败，不能默默改用完整块计算。材料另行描述了 `common_deformation_terms` 对 `RepTable::lookup` 返回的 partial block 求形变项的路径，以及支持 partial parent 的[[形变计算的父块抽象]]；这些支持不能直接视为 `block_deformation_to_height` 已覆盖真积分子系统。^[deformation-drivers.md:73-75, deformation-drivers.md:85-93, deformation-drivers.md:112-117]

冻结契约要求调用方一次性提供所有相关形变项共享的 `lambda_rho`。同属一个完整块并不保证该值相同：在 SL(2,R) 块中，$\gamma=2\rho$ 时 compact-Cartan 元素的值为 `[1]`，split 元素的值为 `[0]`。语言层使用 `rc.lambda_rho(p)`，来源将其记为与已验证的 `deform` 分支一致。^[deformation-drivers.md:29-33]
